> 负责人：EMP_0012 (Product Architect)
> 最后更新：2026-03-03

Mason 的实验项目在这里孵化。每个实验是一个子目录，毕业后迁移到目标项目。

## 规则

1. **每个实验一个子目录**，随便起名
2. **必须有 OWNERSHIP.md**，三行就够：
   - 临时负责人
   - 目标归属
   - 毕业条件
3. **毕业时整个目录迁移到目标项目**，lab 里删掉
4. **超过 2 周没动的实验**，EMP_0012 会提醒 Mason 决定：继续 / 毕业 / 废弃

## OWNERSHIP.md 模板

```markdown
临时负责人：Mason
目标归属：[SocialMesh 模块X / mason-hub / 新项目 / 待定]
毕业条件：[什么信号说明可以迁移了]
创建日期：YYYY-MM-DD
```
