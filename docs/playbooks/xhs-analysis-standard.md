# XHS 数据分析标准 (2026-03-11, Mason 确认)

## 分析单元

**不是"评论"，是"笔记-评论对"。** 评论脱离笔记上下文没有意义。

## 分析流程

### 1. 笔记分类（先分再析，不混合）

按内容类型分组，每组独立出痛点：
- A 类：产品种草
- B 类：妆容教程
- C 类：在地信息/旅游决策

每篇笔记标注：核心产品/品类、笔记立场、目标肤质、博主核心论点

### 2. 评论逐条标注（两个必填字段）

| 字段 | 说明 |
|------|------|
| 核心诉求 | 一句话概括评论者真正想要什么 |
| 目标用户? | 是/不确定/否 + 简短理由 |

目标用户判定（Mason 目标：35+ 二三线城市务实女性消费者）：
- **是**：自报城市/年龄、价格敏感、问购买渠道、务实型反馈
- **否**：追星语言、纯情绪、太年轻信号
- **不确定**：无明确信号

### 3. 分层汇总（不打平）

每个内容类型单独出痛点，标注出现场景、评论对博主论点的态度、目标用户浓度

### 4. 选题输出

只从"是"那一列提炼选题，加风险评估

## 采集层规则

按评论总量加权：>500抓200条，100-500抓100条，<100抓40条

## 偏差自检清单

- [ ] 平台可见性偏差
- [ ] 沉默用户偏差
- [ ] 高赞代表性幻觉
- [ ] 幸存者偏差
- [ ] 时间衰减（>12月权重降低）
- [ ] 跨品类泛化
