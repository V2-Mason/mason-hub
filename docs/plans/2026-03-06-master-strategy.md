# Mason Hub 最高战略 — AI + 供应链平台

> 决策日期: 2026-03-06
> 决策人: Mason
> 状态: 已确认，作为 mason-hub 最高战略

## 一、核心定位

**方法论是鱼饵，供应链是鱼钩。**

Mason Hub = AI 内容运营 SaaS + 韩国美妆供应链平台。单独卖工具会被抄，单独卖货没壁垒，两者绑定才是护城河。

---

## 二、商业模型

### 前端：按结果抽成获客（零门槛）

- 新客户 0 元入驻，按 GMV 15% 抽成
- 客户不赚钱就不收费，降低决策门槛
- 自动筛选：做不起来的自然流失，不占精力

### 中端：月费锁客（可预测收入）

- GMV 超过 ~27,000/月时，15% 抽成 > 月费，客户主动转月费
- 用平台供应链：1,999/月（低月费，供应链赚差价）
- 自有供应链：5,999-9,999/月（纯 SaaS 高价）

### 后端：供应链赚大头

- 代销免押金（卖了再结算），小店主最怕压货
- 供货价阶梯：GMV 越高价格越好，离开损失越大
- 素材库 + 产品数据库锁定在平台内

## 三、三层客户，三种赚法

| 客户类型 | 需求 | 收费模式 | 锁定机制 |
|----------|------|---------|---------|
| 小白（无货无能力） | 货 + 方法 + 工具 | 低月费 + 供应链差价 | 锁货源 |
| 中型（有货无工具） | 工具 + 方法 | 高月费 SaaS | 锁工具 + 数据 |
| 大型（有货有团队） | 效率提升 | 年度合约 + 定制 | 锁生态 + 效率 |

## 四、护城河分层

| 层级 | 可复制性 | 防御力 |
|------|---------|--------|
| AI 内容方法论 | 极易抄 | 弱 — 不指望防住 |
| mason-hub 工具 | 中等 | 中 — 持续迭代拉开差距 |
| 清潭供应链（独家线上代理） | 难抄 | 强 — 关系 + 资质 + 账期 |
| 工具 + 供应链绑定 | 极难替代 | 最强 — 离开两头都没了 |
| 客户历史数据沉淀 | 不可复制 | 最强 — 用越久越离不开 |

## 五、清潭合作战略

### 定位转变

- 从：清潭的小客户（买 50 支回头霜）
- 到：清潭的线上社交渠道总代理

### 给清潭的价值

- 零成本多一个出货渠道（滞销品终于有人帮卖）
- 不抢现有代理商（线上社交 vs 线下/传统电商，渠道不冲突）
- 新品牌入华多一个落地方案（AI 内容 + 分销网络现成）

### 核心谈判条件

1. 代销制不压货 — 卖掉再结算，或首批免费铺货试卖
2. 线上社交渠道独家 — 至少小红书 + 微信私域不给别人（最重要）
3. 滞销品优先试卖权 — 零成本获取测品机会
4. 新品牌入华优先推荐 — 清潭介绍韩国品牌客户
5. 数据共享 — 各品各渠道销售数据，帮选品决策

## 六、扩张路径

### Phase 1: M1-12 验证模型

- 素仁轩自营打样，30 天跑出可展示的数据
- M3 加入 2 家代运营客户（按抽成）
- 同步做批发代发给散户
- 目标：M7 月薪打平，年底累计回正

### Phase 2: M12-18 横向复制

- 代运营客户扩展到 15-20 家
- mason-hub 标准化（加品牌 = 加配置文件）
- 供应链议价权随出货量增长
- 目标：月收入 160,000（~$23,000）

### Phase 3: M18-24 产品化

- mason-hub 变成 SaaS 产品
- 低端 999/月 | 中端 2,999/月 | 高端 5,999/月
- 客户从 20 家变 100 家，不需加人
- 目标：月收入 240,000（~$34,000）

### Phase 4: M24+ 供应链平台

- 从韩妆扩展到日妆、泰妆、欧洲小众
- 成为品牌进入中国市场的标准入口
- 卖的不是货，是基础设施

## 七、飞轮效应

```
更多客户
  -> 更大采购量 -> 供应商更好价格 -> 利润更高
  -> 更多数据喂 AI -> 选品/内容更准 -> 客户效果更好
  -> 客户效果好 -> 口碑转介绍 -> 更多客户
```

每一层扩张都不需要等比例加人，mason-hub 是杠杆。
