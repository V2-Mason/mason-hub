## 问题一：Phase 1 完成标准是什么？

### 定义：Phase 1 = 验证能卖出去

Phase 1 不是打平收入，是证明"这门生意成立"。

| 指标 | 毕业线 | 为什么是这个数 |
|------|--------|--------------|
| **月销量** | ≥60 单/月 (持续 2 周) | 证明不是朋友捧场，是陌生人愿意买 |
| **复购** | ≥3 个回头客 | 证明产品本身没问题 |
| **获客成本** | 单客获客成本 < ¥30 | 证明内容能带来合理成本的流量 |
| **私信→成交率** | ≥30% | 证明信任链路跑通 |

**止损线（已有）**：W4 累计询问<5 且 0 单 → 换品。W8 累计亏损>¥3,000 → 全面停下复盘。

### Phase 1 不需要达到的

- 不需要月入 ¥21,000（那是 Phase 3 的事）
- 不需要多品并行跑通（先打穿一个品）

## 问题二：打平收入的时间表

### 目标：月净利润 ¥21,000（$3,000）

### 需要什么规模？

| 假设 | 数字 |
|------|------|
| 混合 SKU 平均售价 | ¥100 |
| 平均净利率 | 35%（扣成本/平台/投流/退换） |
| 每单净利 | ¥35 |
| **月需销量** | **600 单 ≈ 20 单/天** |

### 从 0 到 600 单/月的路径

| 阶段 | 时间 | 月销量 | 月净利 | 关键动作 |
|------|------|--------|--------|---------|
| Phase 1 验证 | W1-8 (8周) | 0→60 | ¥0→¥2,100 | 单品打穿，证明能卖 |
| Phase 2 放大 | W9-16 (8周) | 60→200 | ¥2,100→¥7,000 | 爆品投流放大 + 加第二品 |
| Phase 3 规模化 | W17-28 (12周) | 200→600 | ¥7,000→¥21,000 | 5-8 品并行 + 私域复购 + 付费流量 |

**总计约 28 周 ≈ 7 个月。**

### 诚实的现实检查

600 单/月对一个小红书个人卖家意味着：
- 每天 20 单，需要日均 ~1,000 人访问店铺（按 2% 转化率）
- 纯靠内容（18-20 条/周，每条 500 曝光）最多覆盖 ~40,000 月曝光 → ~240 单/月 → ~¥8,400 净利
- **纯有机流量天花板大约是目标的 40%**
- 剩下 60% 需要：付费投流（薯条/信息流）+ 私域复购 + 可能的直播

这意味着 Phase 3 不是"继续做内容就自然到了"，需要**主动投入付费流量**，这会反过来压缩净利率。

### 半年打平的前提条件

1. Phase 1 在 8 周内跑通（不换品、不止损）
2. 投流 ROI ≥ 2（花 ¥1 广告费赚 ¥2 净利）
3. 复购率 ≥ 15%（降低获客成本）
4. Mason 全职投入，不被其他项目分散

**如果任何一个前提不成立，时间线要拉长到 9-12 个月。**
