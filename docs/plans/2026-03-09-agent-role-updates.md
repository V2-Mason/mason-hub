## 问题：两个归属真空

### 真空 1：视频管线无人负责

`skills/video-download/` 下有 14 个文件组成完整的 8 步视频管线（下载→拆解→本地化→选品匹配→分镜→故事板→VEO 生成→组装），但没有任何 agent 角色文件明确提到视频管线的维护或使用职责。

当前状态：Mason 手动触发，代码质量和 bug 修复没有归属人。

### 真空 2：分析代码决策权 vs 维护权不分

XHS 数据采集 + 分析脚本（`xhs-crawl.sh`、`xhs-analyze.sh`、`xhs-analyze-viral.py`、`_xhs_strategy_briefing.py`）分散在 `skills/` 和阿里云 `/opt/mediacrawler/`。EMP_0008 实际在定义分析规则和解读数据，但角色文件没写。EMP_0009 应该维护分析代码质量，但角色文件也没写。

## 建议变更

### EMP_0008（SocialMesh 内容运营总监）— 新增 3 项职责

**新增 1：视频管线策略决策权**

```markdown
## 视频管线策略 (新增)

- 决定什么时候用视频管线（选题判断：哪些内容适合视频 vs 图文）
- 审批分镜脚本（shooting_script.py 产出）的质量和品牌一致性
- 定义视频管线各步骤的质量标准（通过还是返工的判断标准）
- 视频成本预算管理（VEO 配额分配、veo-3.1 vs veo-3.1-fast 选择策略）
- 不写代码，不调试管线 bug（那是 EMP_0009 的事）
```

**新增 2：数据分析策略所有权**

```markdown
## 数据分析策略 (新增)

- 定义分析规则（什么指标值得看、阈值怎么设、如何解读数据）
- 定义采集策略（采集哪些关键词、频率、账号分配）
- 产出策略简报（briefing）并确保 EMP_0010 消化并执行
- 分析框架（爆帖判定、假流量过滤、互动评分公式）的规则由你定义
- 分析代码的实现和维护由 EMP_0009 负责
- 新增分析需求：你设计框架 → EMP_0009 实现 → 你验收产出
```

**新增 3：内容效果复盘闭环**

```markdown
## 发布后效果追踪 (新增)

- 定义效果评估节点（发布后 24h / 72h / 7d 的关键指标）
- 解读数据并产出优化建议给 EMP_0010
- 驱动内容策略迭代（什么 hook 有效、什么时间发布好、哪类内容转化高）
- 数据采集自动化由 EMP_0009 实现
```
