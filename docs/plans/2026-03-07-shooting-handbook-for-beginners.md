# 产品短视频拍摄执行手册 — 从零开始

**适用对象**: 完全没有拍摄经验的小白
**产品类型**: 护肤/美妆电商产品（以素仁轩为例）
**设备要求**: 一部手机 + 一个小三脚架（￥30-50）

---

## 第一步：拍摄前准备（30 分钟）

### 1.1 你需要的最小装备

| 装备 | 预算 | 说明 |
|------|------|------|
| 手机 | 已有 | iPhone 或安卓旗舰，竖屏拍摄 (9:16) |
| 手机三脚架 | ￥30 | 淘宝随便买，能固定手机就行 |
| 白色桌面/背景布 | ￥15 | 白色卡纸或白布铺桌上 |
| 一盏台灯 | 已有 | 白光 LED，放在产品左前方 45° |

**不需要**: 相机、灯光架、反光板、提词器。先用手机拍，验证内容方向再升级。

### 1.2 场景布置（5 分钟搞定）

```
窗户（自然光源）
  ↓ 光线方向
  ┌────────────────┐
  │                │
  │  台灯 ←45°    │
  │     ↘         │
  │    [产品]      │  ← 白色桌面
  │       ↑        │
  │    三脚架+手机  │  ← 距产品 20-30cm
  │                │
  └────────────────┘
```

- 白天拍：靠窗，用自然光（最好看的光）
- 晚上拍：台灯从左前方 45° 打过来，避免正面直射（会反光）
- 背景：纯白最安全。桌面铺白纸/白布，背后放白卡纸

### 1.3 手机设置

1. **画质**: 设置 → 相机 → 录制视频 → 选 4K 30fps（没有就 1080p）
2. **竖屏**: 关闭屏幕旋转锁定，竖着拍
3. **对焦**: 拍前点一下屏幕上的产品，锁定对焦
4. **稳定**: 开启防抖（设置里搜"稳定"或"防抖"）
5. **擦镜头**: 用衣角擦干净手机镜头，这步 90% 的人忘了

---

## 第二步：拍什么？（片段清单）

**核心原则**: 不要想着一次拍一条完整视频。你要拍的是一堆"素材片段"，每个片段 5-10 秒，后期让 AI 帮你剪。

### 2.1 必拍的 7 类片段

每个片段拍 2-3 遍，选最好的。每个片段 5-10 秒就够。

| # | 片段类型 | 怎么拍 | 拍几遍 |
|---|---------|--------|--------|
| 1 | **产品全貌** | 产品放桌上，手机距 20cm，从正面拍 | 2 遍 |
| 2 | **产品特写** | 手机凑近到 10cm，拍 logo/质地/瓶口 | 3 遍（不同角度） |
| 3 | **开盖/打开** | 手伸入画面，慢慢打开瓶盖/盒子 | 2 遍 |
| 4 | **取用产品** | 挤出/倒出/沾取产品到手上 | 2 遍 |
| 5 | **涂抹展示** | 把产品涂在手背/手臂上，展示质地 | 2 遍 |
| 6 | **产品摇摆/转动** | 用手慢慢转动产品，展示不同面 | 2 遍 |
| 7 | **使用场景** | 正常使用产品的过程（洗脸/涂抹/按压） | 2 遍 |

### 2.2 加分片段（有时间就拍）

| # | 片段类型 | 怎么拍 |
|---|---------|--------|
| 8 | **产品滑入** | 产品从画面右侧滑入到中间（做 hook 用） |
| 9 | **质地特写** | 精华液滴在手上的瞬间、面霜的绵密感 |
| 10 | **对比展示** | 使用前后的手背对比（干燥 vs 水润） |
| 11 | **包装细节** | 成分表、生产日期、防伪标签 |
| 12 | **多产品排列** | 多个产品整齐排在一起 |

### 2.3 拍摄顺序建议

```
1. 先拍不用手的：产品全貌、特写、排列（三脚架固定）
2. 再拍需要手的：开盖、取用、涂抹（一只手操作，一只手可能需要扶手机）
3. 最后拍使用场景（可能需要换地方，比如洗手台）
```

总共 7×2 + 5×1 = 约 20 个片段，每个 5-10 秒，拍摄时间约 15-20 分钟。

## 第三步：怎么拍好看？（8 条铁律）

### 3.1 稳

**最重要的一条**。抖的视频再好看也没用。

- 能用三脚架就用三脚架
- 手持时：双手握手机，手肘夹紧贴身体
- 拍摄中不要移动脚步

### 3.2 慢

所有动作放慢 2 倍。你觉得正常速度的动作，在镜头里看起来会很快。

- 开盖：慢慢旋开，至少 3 秒
- 挤产品：慢慢挤出，让观众看清质地
- 涂抹：慢动作推开，展示延展性

### 3.3 近

手机尽量靠近产品。新手最常见的错误是拍太远。

- 产品全貌：20cm
- 产品特写：10cm（手机能对焦的极限距离，试着拍看清不清楚）
- 质地特写：10-15cm

### 3.4 静

拍摄环境要安静，关掉空调/风扇/电视。后期可以加音乐，但杂音去不掉。

### 3.5 净

- 产品擦干净（指纹、灰尘）
- 手干净整洁（必要时涂护手霜）
- 桌面干净（只放要拍的东西）
- 背景干净（没有杂物）

### 3.6 光要柔

- 自然光 > 台灯 > 手机闪光灯（永远别用闪光灯）
- 光从侧面来，不要正面打（正面会反光、没有立体感）
- 阴天的窗边光最好看（均匀柔和）

### 3.7 每个片段前后多拍 2 秒

按下录制后等 2 秒再开始动作，动作结束后再等 2 秒再停。这给后期剪辑留余量。

### 3.8 竖屏构图：产品放中间偏上

```
┌──────────┐
│          │
│  [产品]  │  ← 产品在画面中上 1/3
│          │
│          │
│          │
└──────────┘
```

产品不要放正中间，放在画面上 1/3 处最好看（三分法构图）。

## 第四步：拍完后做什么

### 4.1 素材整理

1. 把所有视频从手机传到电脑（AirDrop/数据线/微信传文件）
2. 删掉明显糊了、抖了、曝光错误的
3. 剩下的按类型命名：
   ```
   01-全貌-1.mp4
   01-全貌-2.mp4
   02-特写-正面.mp4
   02-特写-logo.mp4
   03-开盖-1.mp4
   ...
   ```

### 4.2 交给 AI 管线

素材准备好后，交给 AutoClip 或管线处理：
- AI 根据脚本公式选择片段组合
- 自动配音、加字幕、加 BGM
- 输出适配不同平台的版本（小红书 45-60s、视频号等）

你只负责拍原始素材，剪辑交给 AI。

## 第五步：常见错误速查

| 错误 | 表现 | 解决 |
|------|------|------|
| 拍太远 | 产品在画面里很小 | 手机凑近到 20cm 以内 |
| 光太硬 | 产品有强烈反光/阴影 | 用窗边自然光或加一层纸巾柔光 |
| 手抖 | 画面晃动 | 用三脚架，或手肘贴身体 |
| 背景杂乱 | 观众注意力被分散 | 铺白纸/白布，只放产品 |
| 动作太快 | 看不清产品细节 | 所有动作放慢 2 倍 |
| 竖着拍横着拍混了 | 后期没法用 | 全部竖屏 9:16 |
| 手指挡镜头 | 画面边缘有手指 | 握手机时注意手指位置 |
| 没擦镜头 | 画面模糊发雾 | 拍前用衣角擦一下 |

## 附录 A：脚本结构公式（给 AI 用，你了解即可）

拍完素材后，AI 会按以下公式把片段组合成完整视频：

| 公式 | 片段组合顺序 | 适用 |
|------|-------------|------|
| **痛点型** | 问题场景 → 产品出场 → 使用展示 → 效果 | 功能性产品 |
| **结果型** | 效果先放 → 引发好奇 → 产品介绍 → 使用场景 | 效果明显的产品 |
| **反转型** | 争议/质疑 → 翻转 → 产品解释 → 结果 | 有话题性的产品 |
| **困境型** | 日常困扰 → 放大痛苦 → 产品解决 → 结果 | 生活场景强的产品 |

你不需要记这些公式，但拍素材时要确保每类片段都拍了，这样 AI 不管选哪个公式都有素材可用。

## 附录 B：按产品类型的拍摄重点

### 护肤品（面霜/精华/面膜）
- **必拍**: 质地特写（挤出来的样子）、涂抹延展、吸收过程
- **加分**: 水珠滴落（暗示水润）、按压回弹（暗示弹性）
- **色调**: 暖光，柔和，莫兰迪色系背景

### 彩妆（口红/眼影/粉底）
- **必拍**: 上色效果、色号对比、手臂试色
- **加分**: 包装开合（磁吸声很加分）、多色号排列
- **色调**: 干净白光，准确还原色彩

### 清洁产品（洗面奶/卸妆）
- **必拍**: 起泡过程、使用前后对比
- **加分**: 泡沫特写、水冲洗过程
- **色调**: 清爽蓝白调

---

## 一句话总结

**拍 20 个 5-10 秒的短片段，稳、慢、近，背景干净，交给 AI 剪。**
