# Content Pipeline Architecture Design

> Date: 2026-04-02
> Status: Draft
> Owner: Mason

## Context

Mason 运营三个内容号（素仁轩、先试为敬、成长备忘录），此前花了 10+ 个 session 尝试 AE → Remotion 复刻路线，发现：
1. AI 复刻的视觉效果达不到原版精致度
2. 时间 ROI 不对（直接用 AE 更快）
3. 想做的创意超出了模板复刻的范围

同时观察到 AIGC 生态（ComfyUI/libtv/tapnow）的节点式工作流正在产出高质量 AI 生成视频。

**核心问题**：该用什么工具链架构来搭建可规模化的内容生产管线？

**决策结论**：混合管线（AI 素材生成 + 传统工具精装），用成长备忘录作为全 AIGC 试验田先跑通。

## Design

### 1. 核心原则

- **AI 做"从无到有"，AE 做"精确到位"**
- 三个工具各司其职，不互相替代：
  - ComfyUI/云 API = AI 素材工厂（生成原料）
  - AE = 精装车间（精确合成）
  - PR = 终剪台（叙事节奏）
- 管线模块化：素材生成层与组装层解耦，同一批素材可用不同方式组装

### 2. AI vs AE 决策框架

判断每个视觉元素交给谁的三个问题：

```
Q1: 需要精确到像素吗？
    ├─ 是 → AE（文字动画、Logo、产品位置、品牌色）
    └─ 否 → Q2

Q2: 是从零创造还是基于现有素材加工？
    ├─ 从零创造 → AI（背景、概念图、风格化片段）
    └─ 基于现有素材 → Q3

Q3: 加工需要每帧一致的逻辑吗？
    ├─ 是 → AE（重复性特效、模板化处理）
    └─ 否 → AI（一次性风格转换、增强）
```

按元素类型的默认分配：

| 元素 | 分配 | 原因 |
|------|------|------|
| 背景/环境 | AI | 几秒出图，AE 从零做要几小时 |
| B-roll/氛围画面 | AI | 不需精确控制，要的是"感觉对" |
| 风格化处理 | AI | AI 的强项 |
| 智能抠图 | AI | 比手动快 10 倍且够好 |
| 图片放大/增强 | AI | 传统方法做不到 |
| 产品展示转场 | AE | 位置/大小/时间必须精确 |
| 文字动画/排版 | AE | 字体/间距/出场节奏需像素级控制 |
| Logo 动画 | AE | 品牌资产必须 100% 可控可复用 |
| 配色/调色 | AE | 品牌色必须精确匹配 |
| 节奏/音画同步 | AE/PR | 卡点精度 AI 做不到 |

### 3. 三层管线架构

```
┌──────────────────────────────────────────────────┐
│  第 1 层：AI 素材工厂                              │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌───────────┐      │
│  │ 文生图    │  │ 图生视频  │  │ 风格迁移   │      │
│  │ ComfyUI  │  │ Kling API│  │ ComfyUI   │      │
│  └────┬─────┘  └────┬─────┘  └─────┬─────┘      │
│       └──────────────┼──────────────┘             │
│                      ↓                            │
│           /assets/ai-generated/                   │
│  （输出：PNG/MP4 文件，统一命名约定）               │
└──────────────────────┬───────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────┐
│  第 2 层：胶水（Python 编排脚本）                   │
│  Phase 1: 仅 ffmpeg 拼接脚本                      │
│  Phase 2: 升级为全流程编排（含 AI API 调用）        │
└──────────────────────┬───────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────┐
│  第 3 层：组装（按内容形态选用）                     │
│                                                  │
│  形态 A: AE 模板合成 → 精致品牌感（素仁轩）         │
│  形态 B: PR 时间线剪辑 → Vlog/讲解（先试为敬）      │
│  形态 C: Remotion 代码渲染 → 数据驱动可视化          │
│          （注：用于程序化图表/动画，非 AE 模板复刻）   │
│  形态 D: ffmpeg/Python 直接拼 → 快速原型（实验用）  │
└──────────────────────┬───────────────────────────┘
                       ↓
                 /output/final/
```

### 4. 三个号的管线配比

| 号 | AI 占比 | 主要组装方式 | 管线阶段 |
|----|---------|------------|---------|
| 成长备忘录 | 80% AI | 形态 D（ffmpeg 快拼）→ 逐步升级 | 先跑通 |
| 先试为敬 | 50% AI | 形态 B（PR 剪辑） | 第二个 |
| 素仁轩 | 30% AI | 形态 A（AE 精装） | 最后 |

### 5. 第一条管线：成长备忘录 MVP

用成长备忘录做全 AIGC 实验，最小可行路径：

```
Step 1: 脚本大纲（手动，5min）
  └─ 写主题 + 分段 + 每段的视觉描述关键词

Step 2: AI 素材生成（手动操作 ComfyUI/Kling，30min）
  └─ 按脚本生成 5-8 张概念图 / 2-3 个短视频片段

Step 3: 音频准备
  └─ TTS 生成旁白 + 选 BGM

Step 4: Python 脚本拼接（自动）
  └─ ffmpeg 把图片序列 + 音频 + 字幕拼成视频

Step 5: 审核 & 迭代
  └─ 看成品 → 判断哪里需要升级（换更好的 AI 模型？加 AE 精修？）
```

**Phase 1 成功标准**：产出第一条可发布的视频（不限时间，重点是跑通全流程）。
**Phase 2 成功标准**：从"有主题"到"有视频" < 2 小时。

### 6. 文件结构

```
accounts/growth-memo/
  ├── content/
  │   └── {episode-id}/
  │       ├── script.md          # 脚本大纲
  │       ├── assets/
  │       │   ├── ai-generated/  # AI 生成的素材
  │       │   ├── audio/         # TTS + BGM
  │       │   └── manual/        # 手动准备的素材（如有）
  │       └── output/            # 最终输出
  ├── templates/                 # 可复用的模板/配置
  └── pipeline/
      └── produce.py             # 编排脚本（Phase 1: ffmpeg 拼接；Phase 2: 全流程编排）
```

### 7. 技术选型

| 组件 | 选型 | 原因 |
|------|------|------|
| 图片生成 | ComfyUI（本地）或 fal.ai（云端） | AMD 4800 跑 ComfyUI 可行但慢；fal.ai 按量付费无需 GPU |
| 视频生成 | Kling API / Wan via ComfyUI | 目前 AI 视频生成最成熟的选项 |
| TTS | Edge TTS / Fish Audio | Edge TTS 免费够用；Fish Audio 音质更好 |
| 视频拼接 | ffmpeg (Python subprocess) | 零依赖，最灵活 |
| 字幕 | whisper + ffmpeg ass | 自动生成 + 烧录 |
| 精修（后续） | AE + ExtendScript | 复用已有经验 |

### 8. 演进路径

```
Phase 1: 手动 + ffmpeg 脚本（现在）
  → 验证 AI 素材质量，找到内容形态

Phase 2: Python 全流程编排（验证后）
  → produce.py 一条命令出片

Phase 3: 多形态支持（管线稳定后）
  → 同一脚本可输出 ffmpeg 快版 / AE 精版

Phase 4: 自动化触发（规模化后）
  → 新主题 → 自动生成素材 → 人工审核 → 一键出片
```

## Verification

1. **管线跑通验证**：选一个成长备忘录主题，走完 Step 1-5，产出一条视频
2. **时间验证**：记录每步耗时，总时间应 < 2 小时
3. **质量验证**：视频可以发到 B 站/YouTube 不丢人（不要求精致，但要可看）
4. **可复制验证**：用同一管线做第二条视频，时间应 < 第一条的 70%

| Adobe CC 全家桶 | 已订阅 | 沉没成本 |

**止损线**：如果 3 条视频后仍觉得 AI 素材质量不可用，暂停管线搭建，回到纯 AE + Envato 路线先出内容。避免重蹈 Remotion 复刻的覆辙（10+ session 未产出可用成品）。
