# 先试为敬 — 流量号设计文档

> 状态：待审核
> 创建日期：2026-03-28
> 决策人：Mason

## 1. 基本信息

- **昵称：** 先试为敬
- **英文名：** Tried It First
- **定位：** AI时代的试毒官，帮普通人判断这件事跟你有没有关系
- **身位：** 不是专家，是"我先替你试了/看了"的普通人
- **风格参考：** 小Lin说的结构感 + 商业分析角度 + 个人体验
- **和Mason成长备忘录关系：** 完全独立，不关联，不提Mason名字

## 2. 观众痛点

| 痛点 | 具体表现 |
|------|---------|
| 看不懂 | 每天一堆AI新闻，标题都认识，内容不知道在说什么 |
| 不知道跟我有什么关系 | Claude又更新了，so what？跟我打工人有什么关系？ |
| 焦虑但不知道该做什么 | 感觉要被淘汰了，不知道从哪开始 |
| 信息过载 | 关注了50个AI号，不知道该信谁 |
| 被割韭菜的恐惧 | 到处卖AI课，哪个是真有用 |

**核心价值：** 小Lin解决"看不懂"，先试为敬解决"跟我有什么关系"。

**区别：** 小Lin是翻译官（专业变通俗），先试为敬是试毒官（我先替你试了）。

## 3. 平台策略

| 平台 | 语言 | 内容 |
|------|------|------|
| B站 | 中文 | 主平台 |
| YouTube | 英文 | 同内容AI配音 |

## 4. 内容格式

- **时长：** 5分钟固定
- **出镜：** 不出镜，纯画面+旁白+素材
- **视觉特征：** 屏幕角落常驻倒计时（5:00→0:00）
- **视觉风格：** 待定
- **每日投入：** 1-2小时

## 5. 固定话术

| 位置 | 话术 |
|------|------|
| **开头** | "5分钟，一件事，跟你有什么关系。" |
| **中间（个人体验时）** | "我自己试了一下..." |
| **结尾** | "这就是今天最值得你知道的一件事。我们下期见。" |

## 6. 内容矩阵

| 类型 | 占比 | 格式 | 示例 |
|------|------|------|------|
| **一口气了解XX** | 30% | 5分钟系统讲透 | "一口气了解Vibe Coding" |
| **热点试毒** | 30% | 热点+商业逻辑+个人体验 | "Claude能控制电脑了，跟你有什么关系" |
| **我试了一下** | 25% | 亲测+真实感受 | "所有人都在说Manus，我用了一个月" |
| **X热帖解读** | 15% | 病毒推文+背后逻辑 | "这条推文为什么炸了" |

## 7. 内容源

- AI/科技英文播客（Lex Fridman、All-In等）
- 视频播客精华（小宇宙、B站长播客）
- 商业/创业访谈
- X(Twitter)爆火推文

## 8. 分析角度

- **商业角度：** 这背后的商业逻辑是什么
- **个人体验角度：** 我试了一下，对普通人来说意味着什么
