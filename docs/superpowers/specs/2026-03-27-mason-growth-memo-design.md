# Mason的成长备忘录 — 个人IP设计文档

> 状态：待审核
> 创建日期：2026-03-27
> 决策人：Mason

## 1. 个人IP定位

### 基本信息
- **昵称：** Mason的成长备忘录
- **英文名：** Mason's Growth Memo / Mason Grows（YouTube/X）
- **Slogan：** Let's grow together
- **内核：** "如果我可以，那你也可以" — 一个普通人踩过的坑，希望你少走一步
- **赛道：** AI（80%）+ 成长感悟（20%），AI是当前载体，成长是长期主线

### 人设
- **身份：** 非技术背景，从0学AI的普通人
- **视角：** 学长型 — "我比你早走了几步，把踩过的坑告诉你"
- **调性：** 有深度、不贩卖焦虑、真实、有自己的思考
- **风格参考：** 何同学 — 叙事和视角对标，制作追求电影级
- **不是什么：** 不是AI教程博主、不是卖课的、不是技术专家

### 视觉符号
- **M面罩：** 全程不露脸，面罩上有"M"标识
- **参考：** Marshmello式的符号化人物形象
- **作用：** 极强辨识度，一眼记住"就是那个戴M面罩的人"
- **情感补偿：** 不靠表情，靠声音情绪、肢体语言、画面节奏传递情感

### 阶段策略
- **前期：** 80% AI内容 + 20% 成长感悟，立人设和涨粉
- **中期：** AI实战+方法论，开始低价变现
- **后期：** "财富自由"主题引入，阶段性公开数据

## 2. 内容板块

### 板块定义（何同学模型映射）

| 板块 | 轻重 | 频率 | 定义 | 内容示例 |
|------|------|------|------|---------|
| **B 造物实验** | 🔴重 | 月1条 | 用AI从0做一个东西，过程就是内容 | "我不懂代码，用AI做了一个网站" |
| **C 深度思考** | 🔴重 | 月1条 | 对AI时代的个人观察和反思 | "用AI之后，你多久没睡好觉了" |
| **A 体验翻译** | 🟡中 | 月2-4条 | 把AI工具/概念翻译成普通人能感受到的体验 | "Manus vs Claude，一个不懂代码的人的体验" |
| **图文碎片** | 🟢轻 | 从视频拆出 | 视频内容拆成图文/短文，填充频率 | 小红书笔记、X thread |

### 内容原则
- **每条视频独立成立：** 观众从任何一条进来都能看懂
- **每条有完整弧线：** 钩子→冲突→转变/结论
- **每条只讲一个核心观点：** 不贪多
- **由浅入深，先情感后技术：** 先让人认识你、喜欢你，再给干货
- **何同学公式：** 不是"这个东西是什么"，而是"这个东西让我感受到了什么"

### 产出节奏
- 🔴重型内容：2-3周制作周期
- 🟡中型内容：1周制作周期
- 每月产出：2条精品 + 2-4条中等 + 日常图文

## 3. 平台策略

### 双线并行

| 线 | 平台 | 语言策略 | 内容形式 |
|----|------|---------|---------|
| **视频线** | B站 + 视频号 + YouTube | 按选题定主语言，AI配另一语言版本 | 出镜（M面罩）+ 录屏 + 素材混合 |
| **图文线** | 小红书 + X | 从视频拆碎片，中英各一版 | 图文/短文 |

### 语言规则
- 中文优先的选题 → 中文录制 → AI配英文发YouTube
- 英文优先的选题 → 英文录制 → AI配中文发B站
- 图文线：小红书中文 / X英文，内容同源不同表达

### 视频形式
- 混合制：根据选题决定出镜 vs 录屏
- 深度思考类（C板块）→ 出镜为主，穿插素材
- 造物实验类（B板块）→ 录屏为主，关键节点出镜
- 体验翻译类（A板块）→ 录屏+旁白为主

## 4. 第一季内容规划（5期）

### 故事弧线
```
#001 觉醒（情感入口，认识Mason）
  ↓ "他还做了项目？"
#002 造物（看到他的行动力）
  ↓ "他怎么做到的？"
#003 工具（跟着他的路径学）
  ↓ "工具有了，但方向呢？"
#004 方法论（升华到思维层面）
  ↓ "光说不练？"
#005 再造物（用行动闭环回到#001）
```

### 逐期详情

#### #001 — "用AI之后，你多久没睡好觉了"
- **板块：** C 深度思考 🔴重
- **核心观点：** AI时代最大的陷阱不是不学，是停不下来
- **时长：** 5-8分钟
- **出镜：** 是（M面罩）
- **素材：** 凌晨屏幕截图、GitHub提交时间戳、3D网站对比图、Manus截图
- **弧线：**
  - 钩子："你有多久没睡好觉了？自从开始用AI之后。"
  - 第一幕（好奇）：23年GPT当聊天工具，不以为然
  - 第二幕（上瘾）：Manus→3D网站→通宵→焦虑循环
  - 转折：停了两天，和女朋友出去走走（空镜替代）
  - 第三幕（觉醒）：想明白三件事（目标、筛选、验收）
  - 收尾："我是Mason，这是我的成长备忘录"
- **不做的事：** 不号召观众停下来休息（留给#005），只分享自己的转变

#### #002 — "我不懂代码，用AI做了一个网站"
- **板块：** B 造物实验 🔴重
- **核心观点：** 不懂技术也能做产品，过程比结果更有价值
- **出镜：** 混合（关键节点出镜，大部分录屏+素材）
- **素材：** 3D打印网站效果对比图（粗糙→精致）、开发过程录屏
- **弧线：** 朋友的痛点 → 决定自己做 → 第一版粗糙 → 迭代上瘾 → 满足感 → 最终版展示
- **钩子到下期：** "但80%时间在debug，后来我找到了更好的方式"

#### #003 — "80%的时间都在debug，直到我换了工具"
- **板块：** A 体验翻译 🟡中
- **核心观点：** 工具选对体验天差地别，不讲参数讲感受
- **出镜：** 少（主要录屏+旁白）
- **弧线：** Manus的debug痛苦 → 两个问题（更好工具？自动开发？）→ 试了御三家 → Claude的变化 → 结论
- **钩子到下期：** "工具解决了效率，但没解决方向感"

#### #004 — "AI时代最稀缺的能力是筛选"
- **板块：** C 深度思考 🔴重
- **核心观点：** 信息越多越需要主动过滤，不是所有新东西都要追
- **出镜：** 是（M面罩）
- **弧线：** 每天新项目就往里塞 → 技术债 → 项目越来越乱 → 三个问题框架（目标/相关性/验收）→ 少即是多
- **钩子到下期：** "说到筛选，我做了个工具帮自己"

#### #005 — "我给自己做了一个睡眠打卡器"
- **板块：** B 造物实验 🔴重
- **核心观点：** 用AI反过来对抗AI焦虑 — 行为即态度
- **出镜：** 混合
- **素材：** 开发过程 + 睡眠数据变化
- **弧线：** 回到#001的问题 → 与其喊口号不如做工具 → 造物过程 → 效果 → **正式呼吁：我们都该停一停**
- **特殊：** 工具免费分享，链接在简介（涨粉利器）

## 5. 变现路径

### 阶段规划
| 阶段 | 时间 | 变现方式 |
|------|------|---------|
| 立人设期 | M1-M3 | 不变现，专注内容和涨粉 |
| 低价引流期 | M3-M6 | AI工具清单/SOP文档（9.9-49 RMB） |
| 社群期 | M6+ | 付费社群（199-399/年） |
| 课程期 | M9+ | 系统课程（999+） |
| 品牌合作 | 粉丝量达标后 | 用Mason叙事风格包装，不硬卖 |

### 变现与内容的关系
- B板块（造物）→ 产出可分享的工具/模板 → 免费引流 + 付费进阶版
- C板块（深度思考）→ 建立信任和个人品牌 → 品牌合作基础
- A板块（体验翻译）→ 搜索流量 → 持续获客

### 不做的事
- 不贩卖焦虑卖课
- 不做"不学AI就被淘汰"式营销
- 产品包装与IP调性一致：真实、有深度、不割韭菜
