# Gate 2 — 内容验收 Checklist（Layer 1 通用结构）

> 执行者：EMP_0008（内容运营总监）或 Mason
> 时机：Gate 1 机器检查通过后、发布/交付用户前
> 耗时：5 分钟内过完

## 使用方法

1. 复制此模板到项目的 release 目录
2. 逐条检查，标记 [x] 通过 / [ ] 未通过
3. 所有 Critical 项必须通过才能进 Gate 3
4. Important 项未通过需要记录原因和决定（接受风险 / 修复后重检）

---

## Critical（必须全部通过）

### 产品信息准确性
- [ ] 产品名称拼写正确（对照产品库）
- [ ] 价格信息准确（如有展示）
- [ ] 功效描述未超出 NMPA 备案范围
- [ ] 成分表无错误（如有展示）
- [ ] 品牌名称正确（中文名 + 英文名）

### 合规
- [ ] 无平台违禁词（Gate 1 已自动检查，此处人工复核上下文）
- [ ] NMPA 备案号展示正确（如平台要求）
- [ ] 品牌授权链完整（如需要）
- [ ] 未做绝对化承诺（"保证有效"、"一定见效"等）
- [ ] 跨境商品标识正确（如适用）

### 品牌一致性
- [ ] 品牌 logo/名称在正确位置露出
- [ ] 视觉风格符合品牌调性（参照 shared/brands/<brand>/brief.md）
- [ ] 口播语气符合品牌人设

## Important（应该通过，未通过需记录原因）

### 内容质量
- [ ] 开头 3 秒有吸引力（hook 有效）
- [ ] 卖点表达清晰（非行业黑话）
- [ ] 无明显 AI 感（口播自然、画面流畅）
- [ ] 字幕与口播同步（无明显偏移）
- [ ] BGM 音量不压过口播

### 平台适配
- [ ] 标题符合平台调性（小红书种草感 / 抖音抓眼球 / 视频号信息量）
- [ ] 封面图有吸引力
- [ ] 标签/话题选择合理
- [ ] 发布时间在平台活跃时段

## Minor（记录但不阻塞）

- [ ] 视频结尾有 CTA（关注/收藏/评论引导）
- [ ] 评论区预埋内容准备好
- [ ] 相关商品链接已关联
