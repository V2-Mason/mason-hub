## 三、价格表达

### 允许
- 模糊区间："百元出头""不到两百""两三百的价位"
- 对比锚定："比XX品牌便宜一半""同类产品里算中等偏低"
- 用量换算："一瓶能用两三个月，算下来一天不到两块钱"
- 价值判断："这个价位能做到这个效果，性价比确实不错"

### 禁止
- 精确价格数字："128元""¥99"
- 不提价格（35+ 客群会因不知价位而放弃）

## 五、内容结构覆盖

### 小红书（主力渠道）覆盖
素仁轩在小红书的核心策略是**不做种草做信任**：
- 真假对比（正品 vs 仿品）
- 直采证据（采购凭证、NMPA 备案）
- 正品背书（中文标签、进口文件）

这覆盖了小红书通用规则中的"种草型"结构。具体结构调整：
1. 痛点共鸣（5-8s）— 同通用规则
2. 信任证据引入（5-8s）— **素仁轩特有**：展示采购凭证/NMPA 备案
3. 产品使用演示（15-25s）— 同通用规则
4. 效果+真诚补充（8-12s）— **素仁轩特有**：主动说不足/不适合的情况
5. 收藏引导（3-5s）— 同通用规则

### 微信私域覆盖
素仁轩的微信私域是主阵地（岳阳本地 + 老客户），内容调性要比通用规则**更随意**：
- 像发给朋友看的，不需要完整结构
- 可以用碎碎念式文案
- 配图用真实手机拍摄，不需要精修

## 六、旁白风格覆盖

素仁轩所有渠道的旁白都应遵循 voice.md 的核心调性：

> 一句话定义：**懂韩妆的邻家姐姐，真诚分享自己用出来的经验。**

具体覆盖：
- **抖音**：渠道规则要求"情绪激昂"，素仁轩覆盖为"有节奏感但不亢奋"，语速可以快但不要喊
- **快手**：渠道规则要求"声音大、用家人们"，素仁轩覆盖为"声音正常，用姐妹们"
- **小红书**：渠道规则和品牌调性基本一致，不需要特别覆盖
- **视频号**：渠道规则和品牌调性基本一致，不需要特别覆盖

## 七、Hook 话术模板（品牌专属）

### 推荐模式：痛点条件句前置型
```
模板：到了[年龄/阶段]，[具体痛点描述]，[解决方案预告]

示例：
- "过了35，最明显的变化就是皮肤干到卡粉。我试了大半年，终于找到一套真管用的。"
- "换季的时候脸又红又痒，姐妹们是不是也这样？"
```

### 可选模式：经验权威型
```
模板：我[做了什么/经历了什么]，[发现/总结]

示例：
- "做韩妆三年了，真正会反复回购的其实就那么几个。"
```

### 禁止的 Hook 模式
- "家人们今天必须给我冲这个！"
- "天花板级别！封神！"
- "被种草了XXX品牌..."（暴露品牌名不符合内容策略）

## 八、视觉风格覆盖

### 封面
- 干净的产品图 + 简洁标题文字
- 色调：白/米/浅粉/淡绿——温和、有品质感
- 字体：无衬线体，中等粗细
- **不需要**真人出镜的夸张表情

### 字幕
- 不要花哨贴纸
- 不要黄底黑字的醒目标注（除非渠道强烈要求，如视频号）
- 重点信息用加粗或稍大字号即可，不用特殊底色
