# 内容策略框架

> 品牌无关的内容规划方法论。PM 内化时结合品牌定位和平台特性。

## 内容分类：两种类型

每条内容必须是以下至少一种，否则不值得发。

### 搜索型（Searchable）— 接住已有需求

用户已经在找答案，你的内容出现在搜索结果里。

特征：
- 标题含搜索关键词（"水乳推荐"/"防晒测评"/"韩国代购攻略"）
- 内容结构清晰（分点/对比/排行）
- 长尾价值高（发出去 3 个月后还有自然流量）

适合内容：测评、教程、合集、攻略、对比

### 传播型（Shareable）— 制造新需求

用户没在找，但看到了想转发/收藏/讨论。

特征：
- 情绪驱动（惊讶/共鸣/争议/实用）
- 强社交属性（"这个必须让闺蜜看到"）
- 爆发式流量（前 24 小时决定生死）

适合内容：故事、反常识观点、幕后日常、热点借势

### 怎么判断做哪种

| 信号 | 做搜索型 | 做传播型 |
|------|---------|---------|
| 竞品都在做这个话题 | ✓ 有搜索量 | |
| 评论区高频问同一个问题 | ✓ 需求明确 | |
| 最近有热点/争议 | | ✓ 借势传播 |
| 有独特经历/幕后故事 | | ✓ 差异化 |
| 用户收藏 > 点赞 | ✓ 实用型 | |
| 用户评论 > 收藏 | | ✓ 话题型 |

## 内容支柱（Content Pillars）

每个账号定 3-5 个核心主题方向，所有内容围绕这些方向。

### 怎么定支柱

1. **产品出发** — 你卖什么？每个品类一个支柱
2. **用户出发** — 他们关心什么？痛点归类
3. **竞品出发** — 别人做了什么？哪些空白没做
4. **数据出发** — 采集数据里哪些关键词互动最高

### 支柱示例（韩妆电商）

```
号 1 品牌号支柱:
├── 产品教程（使用方法/成分解析）     40%
├── 开箱/上新（新品展示）            30%
└── 客户反馈/对比（真实效果展示）     30%

号 2 种草号支柱:
├── 品类合集（"N 款 xxx 推荐"）      40%
├── 使用体验（个人测评/对比）         35%
└── 热点借势（成分争议/护肤误区）     25%

号 3 人设号支柱:
├── 代购日常（vlog/幕后）            45%
├── 韩国生活（文化/好物/见闻）       35%
└── 粉丝互动（Q&A/投票/抽奖）       20%
```

## 选题优先级

当有多个选题时，用 4 维打分排序（详见 `scoring.md`）。

快速判断法：

```
必须做: 采集数据显示该话题互动分 Top 10 + 跟你品类相关
应该做: 用户评论区反复问的问题
可以做: 竞品做了效果不错，你能做得更好
不要做: 纯蹭热点但跟品牌无关
```

## 发布节奏参考

| 账号类型 | 建议频率 | 搜索:传播 比例 |
|---------|---------|---------------|
| 品牌号 | 每周 3-5 条 | 7:3 |
| 种草号 | 每周 5-7 条 | 5:5 |
| 人设号 | 每周 3-4 条 | 3:7 |

高频不等于好 — 宁可一周 3 条高质量，不要一天 3 条凑数。

## 从采集数据到选题

```
xhs-analyze.sh 产出
  → keyword_insights（哪些关键词热度高）
  → hot_posts（爆帖长什么样）
  → fake_traffic_report（哪些不可信）

PM 判断
  → 哪些趋势跟我品牌相关？
  → 爆帖里哪些 pattern 可以复刻？
  → 竞品在做什么我没做的？

产出 weekly-direction.md
  → 本周 3 个号各自的选题方向
  → Creator 直接读取执行
```

## 复盘方法

每月 1 次，看上月内容数据：

1. **哪些帖互动最高？为什么？** — 提炼可复制的 pattern
2. **哪些帖没流量？为什么？** — 避免重复踩坑
3. **藏赞比高的帖** — 说明内容实用，加大同类产出
4. **评赞比高的帖** — 说明话题有讨论度，可做系列
5. **转化数据**（有官方 API 后）— 哪些帖真正带了单
