# 竞品分析框架

> 不是看别人做了什么就跟着做，而是找到别人没做好的地方，做得更好。

## 竞品分类

### 直接竞品 — 同产品，同渠道

卖同类韩妆、同平台（小红书）的代购/店铺。

分析重点：
- 他们卖什么品牌？跟你重叠多少？
- 他们内容怎么做？什么风格？
- 他们的爆帖长什么样？
- 他们的定价策略？

### 间接竞品 — 同品类，不同渠道

在淘宝/拼多多/抖音卖韩妆的，或线下韩妆店。

分析重点：
- 他们的价格你能不能打？
- 他们有什么你没有的优势（正品保障/发货速度/售后）？
- 你有什么他们没有的优势（韩国本土/一手货源/专业选品）？

### 替代竞品 — 不同品类，同需求

用户可能选择日系/国货/欧美护肤品来解决同一个问题。

分析重点：
- 用户为什么选韩妆而不选日系/国货？（提炼你的差异化）
- 用户从韩妆转去其他的原因？（你的弱点）

## 从采集数据做竞品分析

`xhs-crawl.sh --task 3` 自动从产品库提取品牌名采集竞品内容。

### 分析步骤

```
1. 看 weekly_analysis.json 的 hot_posts
   → 哪些帖提到了你也在卖的品牌？
   → 他们是怎么介绍这个品牌的？

2. 看 keyword_insights
   → "COSRX测评" 平均互动分多少？
   → 视频还是图文更受欢迎？

3. 对比自己的内容
   → 同品牌的帖，别人互动高你互动低，为什么？
   → 别人做了哪些你没做的内容形式？
```

## 差异化提炼

### 找到差异化的 3 个问题

1. **你有什么别人没有的？**
   - 韩国本土货源？
   - 专业选品能力？
   - 品牌官方授权？

2. **你能做到什么别人做不到的？**
   - 实地探店拍摄？
   - 成分专业解读？
   - 快速响应新品？

3. **用户为什么选你而不选别人？**
   - 问老客户（最真实）
   - 看自己的好评（提炼共性）

### 差异化落地

差异化不是想出来的，是在内容里反复强化出来的：

| 差异化点 | 怎么在内容里体现 |
|---------|----------------|
| 韩国本土 | 每周发代购日常/探店 vlog |
| 专业选品 | 发成分解析/品牌对比测评 |
| 真实体验 | 发真人使用过程/长期追踪 |
| 一手价格 | 发价格对比/代购省钱攻略 |

## 竞品监控节奏

| 频率 | 做什么 |
|------|-------|
| 每周（自动） | xhs-crawl Task 3 采集竞品关键词数据 |
| 每月（PM） | 更新竞品对标表，调整内容策略 |
| 每季度（PM） | 重新评估竞品名单，增减监控关键词 |
