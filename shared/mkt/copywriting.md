# 文案框架

> 品牌无关的通用文案方法论。PM 内化时替换示例、加入品牌调性。

## 核心原则

1. **清晰 > 聪明** — 用户 1 秒看不懂就划走了
2. **好处 > 功能** — "让皮肤喝饱水" 而不是 "含透明质酸 300mg"
3. **客户的话 > 你的话** — 用户评论区的表述比专业术语有效 10 倍
4. **具体 > 模糊** — "3 天看到变化" 而不是 "效果显著"
5. **展示 > 声明** — 对比图/使用过程 > "效果惊人！"

## 文案结构（适用于社交帖/产品页）

### 1. 钩子（Hook）— 前 2 秒

决定用户停不停留。参考 `hooks-library.md`。

### 2. 痛点共鸣 — 说出用户的处境

```
模板: 是不是也遇到过 {具体场景}？{情绪描述}。

示例: 换季脸又开始爆皮了？涂什么都搓泥，妆也上不去，出门恨不得戴面具。
```

要点：
- 描述场景而非问题（"出门恨不得戴面具" > "皮肤干燥"）
- 用情绪词（焦虑/崩溃/无语/沉默了）
- 最好用客户原话（从评论区挖）

### 3. 解决方案 — 你的产品/建议

```
模板: {发现经过}，试了 {产品}，{具体变化}。

示例: 被韩国室友安利了这瓶精华，抱着试试的心态用了一周，早上起来脸居然是滑的。
```

要点：
- 引入要自然（"被安利"/"无意间发现"/"用了 N 年的老粉"）
- 变化要具体可感知（"脸是滑的" > "皮肤变好了"）
- 避免广告感（不说"强烈推荐"/"必买"）

### 4. 信任构建 — 为什么可信

| 信任元素 | 示例 |
|---------|------|
| 使用时长 | "回购第 3 瓶了" |
| 具体数字 | "坚持用了 28 天" |
| 身份背书 | "在韩国生活 5 年" |
| 社交证明 | "韩国药妆店销量 TOP1" |
| 对比展示 | 使用前后对比图/视频 |
| 真诚让步 | "唯一缺点是瓶子太小" |

### 5. 行动引导（CTA）

| 场景 | 好的 CTA | 差的 CTA |
|------|---------|---------|
| 种草帖 | "链接放评论区了" | "快去买！" |
| 教程帖 | "先收藏，换季用得上" | "记得关注" |
| 互动帖 | "你们最怕换季哪个问题？评论区聊" | "点赞收藏" |
| 品牌号 | "想试的扣 1，私聊发小样" | "购买链接在主页" |

## 质量检查清单

写完后逐条过：

- [ ] 标题能让人停下来吗？（挡住正文只看标题，会不会点？）
- [ ] 前 3 行抓人吗？（小红书展开前只看 3 行）
- [ ] 有没有说人话？（读出来像聊天还是像广告？）
- [ ] 好处具体吗？（能感知的变化 vs 抽象形容词）
- [ ] 有信任支撑吗？（不是空口说好）
- [ ] CTA 自然吗？（不像在推销）
- [ ] 有没有品牌禁忌词？（查项目 context.md 禁忌清单）
- [ ] 字数超限吗？（小红书标题 ≤20 字，正文建议 300-800 字）
