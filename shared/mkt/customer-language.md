# 客户语言采集与应用

> 客户描述问题的原话，比你精心打磨的文案有效 10 倍。

## 为什么客户语言重要

- 用户刷到"换季脸又开始爆皮了"会停下来，刷到"肌肤屏障受损"会划走
- 搜索栏里用户打的是"脸上起皮怎么办"，不是"表皮角质层修复方案"
- 评论区的高赞评论就是最好的文案素材

## 采集方法

### 1. XHS 评论区挖掘（最直接）

从 xhs-analyze.sh 的爆帖出发，重点看：

| 采集来源 | 要采什么 | 怎么用 |
|---------|---------|-------|
| 爆帖评论区 Top 评论 | 用户怎么描述这个产品 | 直接引用到文案 |
| "求链接/怎么买"类评论 | 购买意图表述 | CTA 文案参考 |
| 吐槽/差评 | 用户的痛点原话 | 痛点共鸣段落 |
| 提问类评论 | 用户真实困惑 | 选题方向 |

### 2. 自有客户反馈

| 来源 | 采集方式 |
|------|---------|
| 微信聊天记录 | 客户咨询时用的词 |
| 售后反馈 | 客户描述使用体验的词 |
| 复购理由 | "为什么又买" 的原话 |

### 3. 竞品评论区

| 关注点 | 用途 |
|-------|------|
| 竞品好评里的共性词 | 品类通用卖点 |
| 竞品差评里的共性词 | 你的差异化机会 |

## 语言对照表

采集后整理成对照表，所有内容角色统一使用：

```markdown
## 客户语言对照表

### 用户说的 → 我们也这么说
| 用户原话 | 替代掉的专业表述 |
|---------|----------------|
| 脸上起皮 | 角质层受损 |
| 搓泥 | 产品不兼容 |
| 闷痘 | 致痘性 |
| 假滑 | 表面润滑感 |
| 糊一脸 | 厚重/不吸收 |
| 烂脸 | 皮肤过敏 |
| 维稳 | 修复屏障 |

### 用户的痛点描述（可直接用于文案开头）
- "换季脸又开始作妖了"
- "涂什么都搓泥"
- "化妆卡粉到崩溃"
- "毛孔大到能插秧"

### 用户的好评描述（可直接用于卖点）
- "用完脸滑滑的"
- "回购第 N 瓶了"
- "室友问我用了什么"
- "素颜出门被夸"

### 购买意图信号（出现这些词 = 想买）
- "求链接"
- "哪里买"
- "多少钱"
- "还有货吗"
- "能代购吗"
```

## 应用规则

1. **标题里用客户语言** — "换季维稳" 而不是 "修复肌肤屏障"
2. **痛点段落引用原话** — 加引号显得真实："有没有那种涂什么都搓泥的时候？"
3. **卖点用感知描述** — "用完脸是滑的" 而不是 "含玻尿酸成分"
4. **CTA 用用户的词** — "想要链接的扣 1" 而不是 "点击购买"
5. **每月更新** — 语言会变，定期从新评论中补充
