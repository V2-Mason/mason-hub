# 标题和开头公式库

> 通用公式 + 平台特化版本。PM 内化时删掉不适合品牌调性的，加入品牌专属变体。

## 标题公式

### 好奇型 — 让人想点进来

| 公式 | 示例 |
|------|------|
| 后悔没早知道！{话题} | 后悔没早知道！韩国药妆店隐藏的平价好物 |
| {人群}千万别买{品类}！除非… | 油皮千万别买面霜！除非你看过这篇 |
| {数字}块在{地方}能买到什么 | 200 块在韩国 olive young 能买到什么 |
| 被{来源}安利了{东西}，结果… | 被韩国室友安利了这瓶精华，结果用了一周… |
| 说真的，{反常识观点} | 说真的，大部分人防晒都涂错了 |

### 实用型 — 让人想收藏

| 公式 | 示例 |
|------|------|
| {场景}的{N}个{方案} | 换季维稳的 5 个护肤步骤 |
| {身份}{N}年经验总结 | 代购 3 年总结的韩国必买清单 |
| 手把手教你{目标} | 手把手教你看懂韩文成分表 |
| {品类}选购指南（{年份}版）| 防晒选购指南（2026 版）|
| 新手{N}步搞定{目标} | 新手 3 步搞定韩系水光肌 |

### 共鸣型 — 让人想评论

| 公式 | 示例 |
|------|------|
| 是不是只有我{经历}？ | 是不是只有我觉得韩国面膜比日本好用？ |
| {数字}年{身份}的真心话 | 做了 3 年代购的真心话 |
| {比较}到底怎么选？ | COSRX vs SKIN1004 到底怎么选？|
| 终于有人说清楚{话题}了 | 终于有人说清楚烟酰胺和 VC 能不能一起用了 |

### 紧迫型 — 让人想马上行动

| 公式 | 示例 |
|------|------|
| {品牌/品}快断货了，先码 | ANUA 鱼腥草水快断货了，先码 |
| {时间}之前一定要知道的 | 夏天之前一定要知道的防晒真相 |
| {热点}最后说一次 | 早 C 晚 A 最后说一次，这才是正确顺序 |

## 开头公式（正文前 3 行）

小红书展开前只显示前 3 行，决定用户看不看完。

### 故事型开头

```
上周去韩国进货，在 olive young 站了 2 小时，最后只买了这 5 样。
不是我选择困难，是真的每一样都经过了反复比较。
今天把我的选品逻辑分享给你们 ↓
```

### 痛点型开头

```
又到了换季烂脸的季节。
去年这时候我脸上红一块白一块，什么贵妇面霜都压不住。
直到换了这个思路，今年终于没翻车 →
```

### 数据型开头

```
测了 8 款韩国防晒，从 SPF 到肤感到成膜速度，全部实测。
先说结论：最贵的不是最好的。
详细对比看下面 ↓
```

### 反常识型开头

```
说一个可能得罪人的观点：
90% 的人水乳都白买了。
不是产品不好，是顺序用错了。
```

### 清单型开头

```
韩国代购 3 年，客人回购率最高的 10 样东西。
不是网红款，是真的好用到会复购的那种。
建议先收藏，要买的时候翻出来看 ↓
```

## CTA 公式

| 目标 | 公式 | 示例 |
|------|------|------|
| 引导收藏 | 先{动作}，{场景}用得上 | 先收藏，换季的时候用得上 |
| 引导评论 | 你们{选择题}？评论区聊 | 你们是 A 还是 B 党？评论区聊 |
| 引导私信 | 想要{东西}的扣{关键词} | 想要清单的扣"清单" |
| 引导关注 | 后续更新{系列}，不想错过就{动作} | 后续更新韩国护肤系列，不想错过就先关注 |
| 引导购买（软） | 链接放{位置}了，{让步} | 链接放评论区了，先看测评再决定 |

## 禁忌（通用）

- 不用感叹号堆砌（"太好用了！！！绝绝子！！！"）
- 不用空洞形容词（"超级好用"/"强烈推荐"/"yyds"）
- 不用虚假紧迫感（"最后 1 天"但天天说）
- 不做虚假对比（故意找差产品垫底）
- 不贬低竞品（只说自己好在哪，不说别人差）
