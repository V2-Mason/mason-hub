# 内容优先级评分

> 当有多个选题可做时，用这个公式排序。也可用于复盘已发内容的效果。

## 4 维评分法

| 维度 | 权重 | 评什么 |
|------|------|-------|
| 客户需求 | 40% | 有多少人关心这个话题？ |
| 品牌匹配 | 30% | 跟我们的产品/定位相关吗？ |
| 内容势能 | 20% | 这个话题的内容容易爆吗？ |
| 执行成本 | 10% | 做这条内容需要多少资源？ |

### 评分标准（每项 1-10 分）

#### 客户需求（40%）

| 分数 | 标准 |
|------|------|
| 9-10 | 采集数据中该关键词互动分 Top 3，或评论区反复出现的问题 |
| 7-8 | 采集数据有相关内容且互动不错，或客户有问过 |
| 5-6 | 品类相关但没有直接数据支撑 |
| 3-4 | 有一定关联但用户需求不明确 |
| 1-2 | 纯主观判断，没有数据支撑 |

#### 品牌匹配（30%）

| 分数 | 标准 |
|------|------|
| 9-10 | 直接展示我们在卖的产品，或跟核心品类强相关 |
| 7-8 | 品类相关，内容能自然提到我们的产品 |
| 5-6 | 泛品类相关，但离产品有一步距离 |
| 3-4 | 韩国/护肤大类相关，但跟具体产品关系弱 |
| 1-2 | 蹭热点，跟品牌几乎无关 |

#### 内容势能（20%）

| 分数 | 标准 |
|------|------|
| 9-10 | 竞品同话题爆帖多 + 我们有独特角度/素材 |
| 7-8 | 话题有热度，我们能做出差异化 |
| 5-6 | 中等热度话题，做法中规中矩 |
| 3-4 | 冷门话题或已经做烂的话题 |
| 1-2 | 没有热度，也没有差异化角度 |

#### 执行成本（10%，分数越高成本越低）

| 分数 | 标准 |
|------|------|
| 9-10 | 手头有素材，1 小时内能完成 |
| 7-8 | 需要拍照/录视频，半天能完成 |
| 5-6 | 需要采购新品或等物料 |
| 3-4 | 需要多人配合或等外部资源 |
| 1-2 | 需要大量投入（出差/拍摄/外包） |

## 计算方法

```
总分 = 客户需求 × 0.4 + 品牌匹配 × 0.3 + 内容势能 × 0.2 + 执行成本 × 0.1
```

### 决策阈值

| 总分 | 决策 |
|------|------|
| ≥ 8.0 | 立即做，本周排进去 |
| 6.0-7.9 | 排入下周计划 |
| 4.0-5.9 | 有空再做，或等更好的切入时机 |
| < 4.0 | 不做 |

## 评分示例

| 选题 | 需求(40%) | 匹配(30%) | 势能(20%) | 成本(10%) | 总分 |
|------|-----------|-----------|-----------|-----------|------|
| COSRX 蜗牛精华测评 | 8 | 10 | 7 | 9 | 8.5 |
| 换季护肤步骤教程 | 9 | 7 | 8 | 8 | 8.1 |
| 韩国 olive young 探店 | 7 | 5 | 9 | 3 | 6.6 |
| 护肤成分科普 | 5 | 4 | 5 | 8 | 5.0 |

## 从采集数据自动预评分

`xhs-analyze.sh` 产出的数据可以辅助评分：

| 数据字段 | 对应维度 | 怎么用 |
|---------|---------|-------|
| keyword avg_score | 客户需求 | 平均互动分 > 10000 → 需求分 8+ |
| hot_posts score | 内容势能 | 同话题有爆帖 → 势能分 7+ |
| video_ratio | 执行成本 | 视频比高 = 需要拍视频 → 成本分降低 |
| fake_traffic_flags | 需求修正 | 高互动但假流量多 → 需求分打折 |

## 复盘评分

发布后用实际数据回填，校准评分标准：

```
预估总分 8.5 → 实际互动 一般
原因分析：品牌匹配高但选题太常见，势能分给高了
校准：同类选题势能分 -2
```

每月做一次校准，让评分越来越准。
