# 五维能力评估框架

> Mason 用第一性原理拆解系统能力为五个维度，每个叶子节点都是一个可评估的能力点。

## 五维结构

1. **感知** — 广度（信息源数量）/ 深度（解析粒度）/ 时效（延迟）
2. **理解** — 模态（文本/图片/视频/结构化）/ 层次（事实→分析→洞察→策略）/ 关联（跨数据源交叉）
3. **决策** — 自主度（L1-L4）/ 速度（信息→行动延迟）/ 质量追踪（决策→结果闭环）
4. **执行** — 平台操作 / 工具调用 / 文件管理 / 通信
5. **学习** — 经验提取 / 经验应用 / 模式识别 / 自我优化

## 评估方法

每个叶子节点问四个问题：
1. 这个能力现在有吗？
2. 自动化程度？（手动 / 半自动 / 全自动）
3. 质量？（可靠 / 偶尔出错 / 经常不够用）
4. 提升一档需要什么 skill？

## 应用场景

- 识别 skill gap 时用此框架替代"凭感觉列清单"
- 每条能力线的阻力可以映射到具体叶子节点
- 新 skill 安装前先定位它填补哪个叶子节点
