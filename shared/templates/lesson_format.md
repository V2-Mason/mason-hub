# Lesson 标准格式

> 所有 Agent 写 lesson 时必须遵循此格式。
> 铁律 4 要求：不写 lesson 就不能关闭 agent。
> 本格式要求：lesson 不分类就不算写完。

## 模板

```markdown
### [日期] [Sprint/任务名]

**完成内容**：
- [做了什么，1-3 条]

**教训**：
- [发现了什么、踩了什么坑]

**Gap 类型**（必选一项）：
- [ ] 🔧 配置/参数错误 → 立刻修，不进 backlog
- [ ] 🏗️ 系统能力缺失 → 需要代码变更，**触发 EMP_0012 triage**
- [ ] 📄 规则/文档更新 → 更新对应文档（checklist/YAML/protocol）
- [ ] 🔗 集成缺失 → A 建了基础设施但 B 未接入，**触发 EMP_0012 triage**
- [ ] 📚 纯知识积累 → 留存即可，无需动作

**触发动作**（仅 🏗️ 和 🔗 类型需要填写）：
- 任务描述：[一句话说清要做什么]
- 建议 Owner：[EMP_XXXX]
- 验收条件：[怎么算做完]
```

## 规则

1. **Gap 类型是强制字段** — 不勾选就不算 lesson 写完
2. **🏗️ 系统能力缺失**和**🔗 集成缺失**两种类型，必须填写触发动作
3. 触发动作填完后，**EMP_0000（Meta Manager）负责在下次晨会检查**，并 ping EMP_0012 做 backlog 评估
4. EMP_0012 收到 ping 后，输出标准 backlog 条目（含"不做什么"负向边界），交 PM 排优先级
5. 其他三种类型（配置错误/文档更新/纯知识）由写 lesson 的 agent 自行处理，不进 EMP_0012 流程

## 处理流程

```
Agent 写 lesson → 勾选 Gap 类型
                    │
                    ├── 🔧 配置错误 → Agent 立刻修（同一个 session）
                    ├── 📄 文档更新 → Agent 更新对应文件
                    ├── 📚 纯知识 → 留存，结束
                    │
                    └── 🏗️ 能力缺失 / 🔗 集成缺失
                          │
                          ▼
                    填写触发动作（任务/Owner/验收）
                          │
                          ▼
                    EMP_0000 晨会检查 lesson 文件
                          │
                          ▼
                    Ping EMP_0012 做 triage
                          │
                          ▼
                    EMP_0012 输出 backlog 条目
                    （含归属 + 验收条件 + 不做什么）
                          │
                          ▼
                    PM 排优先级 → 分配执行
```

## 为什么需要这个格式

**根因**：2026-03-09 发现 Scout 闭环断裂——Radar Tracker 建好后写了 lesson "Scout 应该参考关注率"，但从未创建 backlog 任务，导致 Scout 脚本至今不读关注率数据。

**断裂本质**："写下来"和"被执行"是两件事。lesson 是记忆不是指令。没有强制分类，lesson 会被当作"闭环完成"，但实际的代码变更永远不会发生。
