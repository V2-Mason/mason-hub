# 付费投流决策框架（通用）
> 适用于所有品牌的中国平台付费投流决策。品牌专属参数（人群/预算/路径）见各品牌 brief.md。
> EMP_0008 做投流决策时加载此文件。
> 最后更新：2026-03-06

---

## 转化路径模型

每个品牌根据自身阶段，从以下三条路径中选择：

```
路径 A（站内闭环）：小红书内容 → 小红书小店 → 成交  ← 可直接归因
路径 B（站内闭环）：抖音内容   → 抖音小店   → 成交  ← 可直接归因
路径 C（跨平台）  ：内容种草   → 私信引导   → 微信私域 → 微信小店 ← 代理指标
```

- 未开店阶段：只有路径 C，核心指标 = 进私域成本
- 开店后：路径 A/B 可直接看站内 GMV，路径 C 继续跑私域获客

## 平台工具速查

| 平台 | 工具 | 适合场景 | 门槛 | 起投 | 开店后新增能力 |
|------|------|----------|------|------|----------------|
| 小红书 | 薯条（内容加热） | 有机内容测爆/放大 | 粉丝>=500，90天内笔记 | 75元/5000曝光 | -- |
| 小红书 | 薯条（营销推广） | 产品笔记+私信/商品组件 | 专业号，0粉丝要求 | 75元起 | 挂商品卡直接成交 |
| 抖音 | DOU+ | 内容加热/账号标签打标 | 无门槛 | 100元/5000播放 | 挂橱窗商品卡 |
| 抖音 | 巨量千川 | 大规模精准投放 | 企业账户，首充5000+ | -- | 开店后才有意义 |
| 视频号 | 视频号推广 | 35+熟人社交裂变 | 微信认证账号 | -- | -- |

未开店优先级：薯条（营销推广）> DOU+ > 薯条（内容加热）
开店后优先级：薯条营销推广（挂商品卡）> DOU+（挂橱窗）> 千川（规模化后）

## 核心决策流程

### Step 1：投前内容质量门槛检查

> 不合格的内容投了也是烧钱。先过门槛，再决定投不投。

小红书笔记：
```
自然流量表现：
  [ ] 发布 24h 内互动率 > 5%（赞+藏+评/曝光）
  [ ] 封面点击率（CTR）> 7%（平台均值），好内容能达 10%+
  [ ] 收藏/点赞比 > 0.5（收藏多=实用价值，更值得投）

内容质量：
  [ ] 前 3 秒有明确 hook（痛点型/悬念型）
  [ ] 产品在前 25% 自然出现
  [ ] 有明确 CTA（收藏/私信/评论）
  [ ] 无极限词（最、第一、治疗等），能过审

-> 3 项以上不达标：先优化内容，不要投
-> 达标：进入 Step 2
```

抖音视频：
```
  [ ] 前 3 秒完播率 > 30%（自然流数据）
  [ ] CTR > 5%
  [ ] 互动率（评+赞/播放）> 3%

-> 不达标：不投，优化 hook 和封面
-> 达标：进入 Step 2
```

### Step 2：确定投放目标

> 每次投放只选一个核心目标。目标选错，钱全打水漂。

```
我想要什么？
|
+-- 测试这条内容好不好
|       -> 目标：阅读/播放量（范围最广，数据最客观）
|
+-- 打开率够了但互动少
|       -> 目标：点赞收藏量（推给爱互动的用户）
|
+-- 账号粉丝少，需要建立基础
|       -> 目标：粉丝关注量（推给爱关注的用户）
|
+-- 产品笔记，想要私信咨询 -> 进微信私域
|       -> 目标：营销推广版薯条 + 开启私信组件
|
+-- 产品笔记，想要直接成交（开店后）
        -> 目标：营销推广版薯条 + 挂商品卡 / DOU+ + 挂橱窗商品
```

未开店目标优先级：私信引流 > 收藏量 > 阅读量
开店后目标优先级：商品点击/加购 > 私信引流 > 收藏量

### Step 3：预算分配（四段式投法）

```
阶段 1 -- 测试（75-150元，6小时）
  目的：验证封面+标题的点击率
  操作：不限人群，系统智能推荐
  判断：
    CTR > 7% -> 继续
    CTR 3-7% -> 优化封面/标题后重投
    CTR < 3% -> 停止，内容问题，不是投流问题

阶段 2 -- 扩量（100-200元，12小时）
  前提：测试期 CTR > 7% 且互动率 > 10%
  操作：加精准人群定向（见 Step 4）
  判断：互动率持续 > 10% -> 进入阶段 3

阶段 3 -- 引爆（300-500元，24小时）
  前提：阶段 2 数据持续达标
  操作：黄金时段集中投放（早 8 点、晚 8 点各投）
  注意：多个小订单优于一个大订单

阶段 4 -- 续航（50-100元/次，循环）
  适用：已经跑出爆款的笔记，延长生命周期
  周期：每 3-5 天追一次，每次不超过 100 元
```

### Step 4：人群定向逻辑

```
测试阶段 -> 不限人群（让系统找最优受众）
扩量阶段 -> 兴趣 + 年龄定向（精准但不过窄）
高价值内容 -> 达人相似粉丝（最精准，但量小）
```

具体人群参数（性别/年龄/地域/兴趣标签/达人粉丝）见各品牌 brief.md 的投流参数章节。

### Step 5：效果判断标准

通用内容质量指标（两个阶段都适用）：
```
优秀（值得追投）：CTR > 10%，互动率 > 10%，收藏率 > 5%
合格（维持或小幅追投）：CTR 7-10%，互动率 5-10%
差（停止，优化内容）：CTR < 7%，互动率 < 5%
```

未开店 -- 代理指标：
```
核心：进私域成本（每条私信获取成本）
  优秀：< 20 元/条私信
  合格：20-50 元
  差：> 50 元，优化 CTA 或内容

辅助：
  涨粉成本 <= 3 元/粉丝（美妆行业均值）
  收藏增量：每 100 元带来 50+ 收藏为合格
```

开店后 -- 直接 ROI：
```
小红书小店 ROI = 站内 GMV / 薯条花费
  目标：>= 2    底线：>= 1.2

抖音小店 ROI = 站内 GMV / DOU+ 花费
  目标：>= 1.5（抖音客单价通常低于小红书）

微信私域路径仍用进私域成本核算，与站内 ROI 分开记录
```

投后复盘清单：
```
通用：
  [ ] 花了多少钱，带来多少私信？（进私域成本）
  [ ] 收藏量增加了多少？（搜索长尾价值）
  [ ] 新增粉丝有没有进微信群/加微信？
  [ ] 这条内容的自然流量有没有被撬动？

开店后新增：
  [ ] 站内商品点击率？（商品卡吸引力）
  [ ] 加购率/转化率？（产品承接能力）
  [ ] 站内 ROI 是否达标？
  [ ] 私域路径和站内路径哪条成本更低？
```

## 各平台投放注意事项

### 小红书薯条

踩坑清单：
- 极限词（最好、第一、治愈等）-> 审核不通过，需修改内容
- 新账号（< 500 粉）只能用营销推广版，不能用内容加热版
- 商品笔记（有购买链接）需用营销推广版，会打「赞助」标
- 投放期间私信要及时回复，不然浪费投流效果

### 抖音 DOU+

踩坑清单：
- 裸露、夸大功效词 -> 审核失败
- 初期打标签用旧版 DOU+ 效果更稳，不要一开始就用升级版
- DOU+ 流量不计入自然流量赛马机制，互动数据相对干净
- 完播率不到 30% 的视频坚决不投

DOU+ 四种使用场景：
```
场景 1 新账号打标签：投 3-5 条，目标「达人相似粉丝」，让系统认识你的账号类型
场景 2 潜力视频放大：自然流量 2h CTR > 5%，立刻追投 100-200 元，选「智能推荐」
场景 3 私域引流视频：口播提到「私信我」的视频，测试私信率，高于 1% 值得追投
场景 4 带货视频（开店后）：挂橱窗商品，目标选「商品点击」，商品点击率 > 3% 再追投
```

## 投流 x 内容管线协作节点

```
内容生产（shooting_script + EDL）
    | 发布
自然流量观察 48 小时
    | 检查 CTR / 互动率
投前质量门槛检查（Step 1）
    | 合格
薯条/DOU+ 测试（75-150元，Step 3 阶段1）
    | CTR > 7%
扩量投放（Step 3 阶段2-3）
    | 投后
效果复盘（Step 5）-> 数据反馈给内容选题
```

EDL 版本与投流匹配（通用指导）：
```
种草版 -> 薯条内容加热
产品聚焦版 -> 薯条营销推广
促销版 -> DOU+ 智能推荐
信任版 -> 视频号推广
私域复购版 -> 不投流，只做老用户复购
```

## 快速参考：投还是不投？

```
不要投：
  x CTR < 3%（封面/标题问题，先改）
  x 完播率 < 30%（内容无吸引力）
  x 笔记含极限词（过不了审）
  x 纯粹想靠投流起号（没有内容基础）
  x 开店后商品页面不完整（没评价/主图差）-> 投了也不转化

值得投：
  v 自然流量已有小爆迹象（互动率 > 5%）
  v 内容质量高，只是初始曝光不足
  v 特定节点内容（换季/节日）需快速放大
  v 有明确私信引导 CTA，测试私域获客成本
  v 开店后：商品页面完整，测试站内转化 ROI

最值得投的内容类型：
  -> 产品使用对比（前后效果明显）
  -> 信任型背书（备案特写 + 直采证据）
  -> 干货型收藏笔记（多步骤教程，收藏率天然高）
  -> 开店后加：价格锚点明确的促销型内容
```
