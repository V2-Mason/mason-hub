## 行业判断经验

### 小红书开放平台规则 (2026-02-28)
- 注册需中国企业主体，境外用户需指定境内代理人
- 类目选择不可更改：自研（商家后台系统）和 SaaS（跨境企业 ERP）是两个不同类目的应用实例
- 自研→SaaS 过渡：代码可复用（多租户架构），但需要新主体、新 appKey、新类目申请 + 保证金（~1万/类目）
- 合规红线：不可跨平台合并客户数据、XHS 界面不可引导去其他平台、用户退订必须删数据
- 第三方数据平台（蝉妈妈/新红/千瓜）均无正式开放 API，暂不可用

### 爆品数据来源判断 (2026-02-28)
- 小红书 API 只提供自己店铺数据，不提供全平台爆品数据
- 合规的爆品数据来源：(1) 自己店铺的热销分析 (2) 小红书广告后台（聚光平台）(3) Scout 轻量趋势监测
- 不合规/不可行：大规模爬虫抓取、第三方平台原始数据转售给终端用户

### XHS 开放平台 API 能力边界
- ✅ 有: 商品CRUD、订单管理、售后管理、物流/电子面单、数据加解密、库存同步、跨境清关、发票
- ❌ 没有: 笔记/内容发布 API、评论管理、粉丝管理、数据分析（全平台）、广告投放
- 注意: 开放平台只覆盖电商（商品/订单/库存/售后），内容侧零覆盖

### 微信小店 API 能力边界
- ✅ 有: 商品管理（含赠品/限时抢购）、订单管理、售后管理、物流管理、资金管理、品牌资质、营销（优惠券）、优选联盟（达人带货）、数据分析（罗盘）、客服、主页管理、小程序连接
- ✅ 独有优势: 优选联盟（达人分销体系）、罗盘数据分析、小程序+小店联动、礼物功能
- ❌ 没有: 视频号内容管理、直播管理

### 决策参考
- 如果做达人分销，微信小店的优选联盟体系比 XHS 更成熟（有完整的 API 支持）
- 微信小店有罗盘数据分析 API（带货数据/店铺人群），XHS 开放平台没有数据分析接口

- 理由：选题本质是"卖什么/怎么卖"的市场判断，不是通用内容平台决策

### 分析方法论（已验证）
- 详细标准见 `~/.claude/projects/-home-hangn-mason-hub/memory/xhs-analysis-standard.md`
- 核心：分析单元是"笔记-评论对"，按内容类型 A/B/C 分组，每条评论标注核心诉求+目标用户匹配

### 首次分析结论（10 篇爆帖 / 412 条评论）
- B 类（妆容教程）目标用户浓度最低，35+ 女性不是妆教受众
- C3（省2万变美攻略）目标用户浓度最高（B+C+D 类评论 93-100%），信号是"韩国医美服务需求"
- A2/A3（OY 产品推荐）评论区购买意向最强，卡在"不知道怎么买"

### 选题优先级（数据验证后）
1. OY 产品实话实说 — 去魅型真实测评（C1 的 859 赞评论验证）
2. 韩国购物回国指南 — 纯工具型（物流问题出现 7 次）
3. 韩国医美项目价格表 — C3 的 200 条评论强力验证（15 条价格追问 + 32 条求店铺）
4. 按肤质的韩妆避雷+推荐 — 油皮痛点真实但人群匹配待验证

### 关键发现
- search_id bug（非账号软封）导致搜索失败 — 2026-03-11 修复，采集已恢复
- 评论采样需按共鸣强度加权，不平均分配（C3 的 2312 条评论 vs 其他笔记 22-28 条）
