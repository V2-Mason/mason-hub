## 爆文拆解方法论 (2026-03-06, 从 xiaohongshu-content-intelligence skill 内化)

### 五层拆解框架
> 拿到一条爆帖（链接或描述），按以下五层拆解，产出复刻方案

**1. 封面层**
- 主视觉类型：人物 / 产品 / 对比图 / 文字海报
- 标题公式：痛点词+解决方案 / 数字+承诺 / 疑问句
- 颜色调性：是否符合 35+ 女性审美（莫兰迪 / 自然光 / 简洁）

**2. Hook 层（前 3 秒 / 前 50 字）**
- 痛点共鸣型："换季皮肤暗沉干燥？"
- 稀缺信息型："99% 的人不知道这个用法"
- 身份绑定型："35岁后我终于找到..."
- 对比悬念型："用了一个月，左脸和右脸的区别"

**3. 内容层**
- 信息密度：干货密集型 vs 情绪共鸣型
- 产品露出时机：前 25% 自然带出 vs 后段才提
- 信任背书：NMPA 备案 / 韩国直采 / 使用效果对比

**4. 结尾层**
- CTA 类型：收藏引导 / 评论互动 / 私域引流
- 互动钩子：提问 / "评论区告诉我"

**5. 搜索优化层**
- 标题关键词：主词 + 长尾词
- 正文关键词自然植入密度
- 话题标签选择（1-2 大流量 + 3-5 精准长尾）

### 拆解输出模板
```
【为什么能爆】核心原因 1-2 句
【结构公式】封面 / Hook类型+文案 / 内容骨架 / CTA
【素仁轩复刻版】适配产品 / 修改建议 / 搜索词 3-5 个
```

### 复刻判断原则
- 素人爆帖比大号爆帖更值得复刻（说明内容本身有力量，不是粉丝基数撑的）
- 复刻结构不复刻文案（抄框架不抄句子）
- 每次复刻必须标注差异化点（不能原样搬）
