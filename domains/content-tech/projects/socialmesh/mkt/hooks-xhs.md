# XHS 标题和开头公式库

> 内化自 shared/mkt/hooks-library.md，针对小红书平台特化。
> Creator (EMP_0010) 写 XHS 内容时参考本文件。
> 品牌特定的变体和禁忌词从 context.md 获取。

## 平台限制

- XHS 标题上限 **20 字**（含标点、空格）
- 展开前只显示正文前 **3 行**，决定用户看不看完
- 不能放外链，引导私信/评论区

## 开头公式（正文前 3 行）

### 故事型开头

```
{具体时间/地点}，{发生了什么}。
{一句内心独白或反转}。
今天把{什么}分享给你们 ->
```

### 痛点型开头

```
又到了{痛点场景}的季节。
{曾经的糟糕经历}。
直到{转折}，{结果} ->
```

### 数据型开头

```
测了{N}款{品类}，{测试维度}，全部实测。
先说结论：{最关键的发现}。
详细对比看下面 ->
```

### 反常识型开头

```
说一个可能得罪人的观点：
{反常识结论}。
不是{常见误解}，是{真正原因}。
```

### 清单型开头

```
{身份}{N}年，{什么东西}的{N}样东西。
不是{常见误区}，是{真实标准}。
建议先收藏，{使用场景}翻出来看 ->
```

## CTA 公式

| 目标 | 公式 |
|------|------|
| 引导收藏 | 先{动作}，{场景}用得上 |
| 引导评论 | 你们{选择题}？评论区聊 |
| 引导私信 | 想要{东西}的扣{关键词} |
| 引导关注 | 后续更新{系列}，不想错过就先关注 |
| 引导购买（软） | 链接放评论区了，{让步句} |

**XHS 特别注意**：CTA 不能直接放链接，只能引导到评论区、私信、或主页。

## 禁忌（通用 + XHS）

通用禁忌：
- 不用感叹号堆砌
- 不用空洞形容词（"超级好用"/"强烈推荐"/"yyds"）
- 不用虚假紧迫感
- 不做虚假对比
- 不贬低竞品

XHS 平台禁忌：
- 不用明显引流词（"淘宝搜""拼多多"等跨平台引流）
- 不用医疗功效宣称（"治痘""祛斑"等）
- 避免被判定为广告的标记词

品牌禁忌：见 context.md（待品牌 PM 填写）

## 与策略简报的对接

Creator 写标题时，可参考策略简报中 hot_posts 的 top3_titles 了解当前爆帖标题风格，再套用上述公式改写。不要照搬爆帖标题，用公式产出自己的版本。
