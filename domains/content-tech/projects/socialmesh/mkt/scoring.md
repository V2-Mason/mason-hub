# 内容优先级评分

> 内化自 shared/mkt/scoring.md。
> PM 用此公式对选题排序。也可用于复盘已发内容的效果。

## 4 维评分法

| 维度 | 权重 | 评什么 |
|------|------|-------|
| 客户需求 | 40% | 有多少人关心这个话题？ |
| 品牌匹配 | 30% | 跟品牌产品/定位相关吗？ |
| 内容势能 | 20% | 这个话题的内容容易爆吗？ |
| 执行成本 | 10% | 做这条内容需要多少资源？ |

### 评分标准（每项 1-10 分）

#### 客户需求（40%）

| 分数 | 标准 |
|------|------|
| 9-10 | 策略简报中该关键词 avg_score Top 3，或评论区反复出现的问题 |
| 7-8 | 策略简报有相关内容且互动不错，或客户有问过 |
| 5-6 | 品类相关但没有直接数据支撑 |
| 3-4 | 有一定关联但用户需求不明确 |
| 1-2 | 纯主观判断，没有数据支撑 |

#### 品牌匹配（30%）

| 分数 | 标准 |
|------|------|
| 9-10 | 直接展示在卖的产品，或跟核心品类强相关 |
| 7-8 | 品类相关，内容能自然提到产品 |
| 5-6 | 泛品类相关，但离产品有一步距离 |
| 3-4 | 大类相关，但跟具体产品关系弱 |
| 1-2 | 蹭热点，跟品牌几乎无关 |

**注意**：品牌匹配评分需参照 context.md 中的品牌定位和核心产品。context.md 未填写时，此维度暂按品类相关性粗评。

#### 内容势能（20%）

| 分数 | 标准 |
|------|------|
| 9-10 | 策略简报同话题有爆帖（且非假流量）+ 我们有独特角度 |
| 7-8 | 话题有热度（keyword trend_direction = rising），能做差异化 |
| 5-6 | 中等热度话题（stable），做法中规中矩 |
| 3-4 | 冷门话题（declining）或已经做烂的话题 |
| 1-2 | 没有热度（无采集数据），也没有差异化角度 |

#### 执行成本（10%，分数越高成本越低）

| 分数 | 标准 |
|------|------|
| 9-10 | 手头有素材，Creator 1 小时内能完成图文 |
| 7-8 | 需要拍照/录视频，半天能完成 |
| 5-6 | 需要采购新品或等物料 |
| 3-4 | 需要多人配合或等外部资源 |
| 1-2 | 需要大量投入（出差/拍摄/外包） |

**SocialMesh 补充**：当前内容生产通过 Creator agent (EMP_0010) 完成，图文类执行成本通常为 9-10，视频类需 Mason 参与拍摄则降到 5-6。

## 计算方法

```
总分 = 客户需求 x 0.4 + 品牌匹配 x 0.3 + 内容势能 x 0.2 + 执行成本 x 0.1
```

### 决策阈值

| 总分 | 决策 |
|------|------|
| >= 8.0 | 立即做，本周排进去 |
| 6.0-7.9 | 排入下周计划 |
| 4.0-5.9 | 有空再做，或等更好的切入时机 |
| < 4.0 | 不做 |

## 从策略简报自动预评分

xhs-strategy-briefing.sh 产出的数据可以辅助评分：

| 简报字段 | 对应维度 | 怎么用 |
|---------|---------|-------|
| keyword_insights[].avg_score | 客户需求 | avg_score > 10000 -> 需求分 8+ |
| hot_posts[].score | 内容势能 | 同话题有爆帖 -> 势能分 7+ |
| keyword_insights[].video_ratio | 执行成本 | 视频比高 = 需要拍视频 -> 成本分降低 |
| hot_posts[].fake_traffic_flags | 需求修正 | 高互动但假流量多 -> 需求分打折 |
| keyword_insights[].trend_direction | 内容势能 | rising -> 势能分 +1, declining -> 势能分 -2 |

### 假流量修正规则

参考长期记忆中的假流量过滤信号：
- 评赞比异常低（1 万赞 < 20 条评论）-> 需求分减半
- 评论质量低（全水评）-> 势能分 -2
- 藏赞比异常低（刷量帖点赞高但收藏低）-> 需求分 -3
- 粉互动不匹配（50 万粉常年几百赞）-> 该帖不计入评分

## 复盘评分

发布后用实际数据回填，校准评分标准：

```
预估总分 8.5 -> 实际互动 一般
原因分析：品牌匹配高但选题太常见，势能分给高了
校准：同类选题势能分 -2
```

每月做一次校准，让评分越来越准。发布后有转化数据时（官方 API 接通后），优先用订单数据而非互动数据校准。
