## L3a/L3b 拆分（2026-03-12 Mason 确认）

原四层模型 L0-L3 按信任梯度划分，但 L3 混了两种不同性质：

- **L3a 决策型** — agent 需要 Mason 的判断力（选方案、确认架构）。核心约束：认知。解法：agent 成长，经验积累后可降级。
- **L3b 执行型** — agent 需要 Mason 的手（注册账号、拿授权书）。核心约束：物理/身份。解法：做一次就清掉，是一次性门槛队列。

**Why:** backlog 61 个阻塞任务中大量是 L3b（一次性外部动作），不是持续性瓶颈。区分后可以按耗时排序快速清队列。

**How to apply:**
- backlog 任务标记 L3a/L3b
- L3b 按耗时从短到长排，Mason 批量清
- L3a 按任务类型区分降级条件

## 降级条件按类型区分（Mason 指出）

- **可观测结果**（部署、清洗、格式转换）→ 成功率自动降级
- **主观判断**（内容审核、策略选择）→ 置信度 + 抽检模式：agent 标置信度，低的上报，高的定期抽查

**Why:** "连续成功"在主观判断类任务中无法自我评估（自己给自己打分）。

**How to apply:** 降级提议机制设计时，先分类任务性质再定条件。
