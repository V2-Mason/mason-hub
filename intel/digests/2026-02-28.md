### 1. Claude Agent SDK v0.1.44 发布（2026-02-26）— 重大功能更新
- 来源：[PyPI](https://pypi.org/project/claude-agent-sdk/) / [GitHub Releases](https://github.com/anthropics/claude-agent-sdk-python/releases)
- 新增功能：
  - **Extended Thinking 精细控制**：ThinkingConfig 三档（Adaptive/Enabled/Disabled）+ effort 参数（low/medium/high/max）
  - **MCP Tool Annotations**：@tool 装饰器支持 readOnlyHint/destructiveHint 等元数据
  - **文件检查点回退**：enable_file_checkpointing + rewind_files() 可回退文件变更
  - **自定义工具 = 进程内 MCP server**：不需要额外进程，Python 函数直接注册为工具
  - **修复大 agent 定义静默失败**（ARG_MAX 限制）
- 影响：Agent SDK 功能已相当成熟，自定义工具 + 文件检查点回退是 Mason Hub 当前 `run-agent.sh` 不具备的能力。迁移优先级应提升。
- 建议分配给：EMP_0002 (Platform Dev)，评估 `run-agent.sh` → Agent SDK 迁移路径
