# 重要通知：3月底必须切换新版电子面单

致亲爱的小红书开放平台合作伙伴：

   **2025年2月14日** 起平台将全量开启商家切换新版电子面单强提醒引导，目前已面向全部商家发送切换通知。

【重要提醒】平台将于**2025年3月31日** 起全面下线旧版电子面单，不再支持旧版电子面单取号，请按时引导商家完成切换，如超时未切换的，将影响商家正常发货。

注意事项：旧版电子面单账号中余额怎么处理：

  * 方案一、旧版余额较少，全部使用完再切换新版
  * 方案二、旧版余额较多，联系快递网点，先将旧版账户余额清退，然后重新充值到新开通的新版电子面单账号
