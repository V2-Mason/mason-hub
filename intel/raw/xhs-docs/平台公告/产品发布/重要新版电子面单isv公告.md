# 新版电子面单isv公告

**致亲爱的小红书开放平台合作伙伴：**

       小红书新版电子面单功能已上线，平台将于**2024年12月04日** 对所有平台开发者开放新版电子面单对接。请ISV和自研商家尽快完成小红书新版电子面单对接，**2025年1月31日** 前必须完成对接，并且从**2025年2月1日** 起引导历史商家切换新版电子面单，否则旧版电子面单下线将影响商家发货，感谢支持与理解。

【重要提醒1】平台将于**2025年2月1日** 起电子面单订购页面全量切换为新版电子面单订购页面，为避免商家订购错误，请ISV务必按照节奏完成新版对接和切换引导。

【重要提醒2】平台将于**2025年3月31日** 起全面下线旧版电子面单，不再支持旧版电子面单取号，请按时完成对接和切换，如超时未切换的，将影响商家正常使用。
