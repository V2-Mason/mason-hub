# 授权回调地址核对公告

亲爱的平台开发者：

您好！

根据安全管理部门的最新要求，为进一步提升平台的应用接入安全性，我们将对应用授权流程进行规范升级。请您务必确保授权时的跳转地址（redirect URI）与平台后台配置地址保持完全一致。

平台将于 【2025年4月28日】 起，对存在不一致情况的应用实施分阶段比例授权拦截。该调整可能会对应用正常授权登录流程造成影响，请您务必提前排查并完成整改，以确保业务稳定运行。

为避免服务中断，建议您立即检查当前应用的授权跳转地址与平台配置地址是否一致。如发现不符，请尽快进行修改并重新配置。

  


感谢您的理解与支持。如您在整改过程中遇到任何问题，欢迎随时联系平台技术支持团队。

  


小红书电商开放平台平台技术团队

【2025年4月25日】
