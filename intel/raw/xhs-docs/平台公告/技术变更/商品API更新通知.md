亲爱的小红书开放平台开发者：您好！为了提升开放平台发布商品的质量及后续交易表现，开放平台商品发布API功能新增支持了尺码表及规格大图的设置。

本次具体新增的功能点有：

1、类目查询接口新增返回叶子类目是否支持各类型尺码表&规格大图

2、创建/更新Item支持设置各类型尺码表&启用规格大图

3、查询Item接口新增返回各类型尺码表&是否启用规格大图字段。

  


您可以前往开平台-API文档 https://open.xiaohongshu.com/document/api 查看详情感谢您对小红书开放平台的支持！
