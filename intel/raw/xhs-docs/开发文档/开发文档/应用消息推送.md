## 应用消息推送指南

### 概述

消息推送取代轮询API的方式，可提升数据传输效率。本页面介绍如何使用OpenAPI消息推送功能， 当前支持包括商品、订单、售后关键业务节点的消息推送。

### 一、消息类型（2022年5月25日更新）

#### 1、订单消息

消息事件名称| msgTag| 触发场景  
---|---|---  
订单状态变更| msg_fulfillment_status_change| 用户下单  
用户支付后，订单触发风控

用户支付后，订单走完风控，等待操作  
卖家对部分商品发货  
卖家对全部商品发货

售后完成，订单关闭  
买家收货信息变更| msg_fulfillment_receiver_change| 收货信息被商家修改  
收货信息被买家修改

### 二、消息类型（2024年11月15日更新）

1、进入小红书开放平台控制台，进入相关应用的应用管理界面（满足下列条件，才会推送）

  * 开启推送服务开关，表示接受已订阅的消息推送
  * 点击修改推送地址（注意带上https://或http://），可将已订阅的相关消息推送到该地址。目前一个应用仅支持配置一个地址
  * 推送地址填写完毕后，返回状态检测结果。为保证消息推送正常，请确保推送地址的检测状态为**正常**
  * 推送地址请保证手动检测的post请求返回httpcode=200，**测试推送post数据：{“test”:true}  若推送地址非正常返回则会展示异常状态**
  * 推送时请保证拥有对应的店铺授权且accessToken在有效期内
  * 在消息列表中，选择需要订阅的消息类型

### 消息生成

消息由业务方事件触发，开放平台接收消息之后，对消息进行处理，然后通过HTTP方式发送给应用  
必须在应用管理中配置消息回调地址，应用使用同一个回调地址接收消息，根据消息中的消息类型区分不同业务场景

#### 加签（代码示例请见文档末尾）

##### 1.对除sign外的系统参数和所有请求参数进行排序

将url的所有**请求参数** 以及除sign外的**系统参数** 按照**字母** 进行排序（如果参数包含中文，中文保持原文即可，无需对其单独转码），并使用&连接， 请求body不参与排序。见如下示例：
    
    
    请求url为：
    /open_api/msg?canshu=test
    系统参数有:
    timestamp: 1625475843
    app-key: xhs
    
    则参与排序的参数如下：
    timestamp=1625475843
    app-key=xhs
    排序连接后的结果为 app-key=xhs& timestamp=1625475843  (因展示问题，&后空格实际不存在，下同)
    
    拼接 url+参数+app-secret
    假设app-secret=9a539709cafc1efc9ef05838be468a28
    拼接之后的结果为 /open_api/msg?app-key=xhs& timestamp=16254758439a539709cafc1efc9ef05838be468a28    (因展示问题，&后空格实际不存在)
    
    MD5计算签名
    上述字符串的MD5签名结果为 a7b7430de338783293443133ab9b9357
    
    Header中数据:（这里的header现阶段是在http中body中的key为headers的结构，后续会调整）
    timestamp: 1625475843
    app-key: xhs
    sign: a7b7430de338783293443133ab9b9357

### 消息重试

现阶段消息推送重试已上线。应用满足推送条件后，平台会发起正常推送流程，若符合推送条件前提下首次推送失败，后续会重试3次。在前一次失败的30s、5m、30m后推送。

### 超时时间

当前对于开发者服务端响应超时时间设置为2秒，建议开发者接收到消息后立即返回200的httpcode以及对应数据结构body（超时也会认为推送失败，会触发重试推送），再异步去处理自己的业务逻辑。

**注意：** 服务商反馈消息丢失绝大多数由于对应店铺AT过期，请各服务商对接消息推送后务必保证AT在有效期内！

    public static boolean verifySign(String appKey, String timestamp, String url, String providedSign, String appSecret) {
        TreeMap<String, String> params = new TreeMap<>();
        params.put("timestamp", timestamp);
        params.put("app-key", appKey);
        StringBuilder signBuilder = new StringBuilder(url);
        if (!params.isEmpty()) {
            signBuilder.append("?");
            String queryString = params.entrySet().stream()
                    .map(entry -> entry.getKey() + "=" + entry.getValue())
                    .collect(Collectors.joining("&"));
            signBuilder.append(queryString);
        }
        signBuilder.append(appSecret);
        String calculatedSign = Hashing.md5()
                .newHasher()
                .putString(signBuilder.toString(), Charsets.UTF_8)
                .hash()
                .toString();
        return StringUtils.equals(calculatedSign, providedSign);
    }
