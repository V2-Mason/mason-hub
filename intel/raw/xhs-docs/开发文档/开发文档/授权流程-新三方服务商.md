## 授权流程（软件服务商）

### 背景条件

  * 三方isv应用上线且注册服务；
  * 完成测试店铺授权，确保应用的授权回调地址可以正常接收code；



### 一、填写/确认授权回调地址

确认服务列表中对应的服务的授权回调地址与应用中一致

![](https://qimg.xiaohongshu.com/odin/1041017g31r1d885ong06bbea2o90000000000168kmiu8)

### 二、获取授权码

**2.1****Web端获取授权码**

需要确认注册服务时“展示范围“选择的是”仅分享链接可见“还是”服务市场公开可见“

**仅分享链接可见方案** ：需要拼接授权地址给到商家用户
    
    
    组装格式：
    https://ark.xiaohongshu.com/ark/authorization?appId=xxx&redirectUri;=xxx&state;=xxx
    
    
    组装示例：
    https://ark.xiaohongshu.com/ark/authorization?appId=4b6*******672e4c9a&redirectUri;=http%3A%2F%2Fwww.xiaohongshu.com&state;=1234

授权页组装参数如下

参数名称| 是否必须| 示例值| 参数释义  
---|---|---|---  
appId| 必须| 27d***b081e7| 第三方使用小红书开放平台的appId（同appKey，下同）  
redirectUri| 必须| http%3A%2F%2Fwww.xiaohongshu.com| 授权回调地址字段decode后的值，在用户完成授权后，code值将回调至该地址中  
state| 可选| 1234| 标识位，返回时将原值返回，可用于标识商家  
  
**服务市场公开可见方案** ：引导商家用户前往服务市场搜索对应服务名称。进入详情页后点击”前往获取“按钮即可跳转至授权界面。也可使用上述拼接方案。

![](https://qimg.xiaohongshu.com/odin/1041017g31r1di6ah0a06bbea2o9000000000012fds99m)
    
    
    引导用户跳转到授权页面后会判断当前商家主账号是否登录，若登录则点击直接授权，若未登录则登录后再跳转授权。
    
    注意事项：
            1）店铺类型及账号限制：只允许店铺主账号才可以授权成功。
            2）允许取消授权：授权应用后，可以在账号应用管理处查看授权应用信息，并取消授权
    
    用户完成「授权登录」后，授权码code将返回到回调地址中，以参数code形式组装至回调地址中，应用可以获取并使用该code去换取accessToken。
    
    注意事项：code有效期10分钟，10分钟后code过期则需要重新授权，短时间内多次使用code换取accessToken是一样的，返回数据展示如下

![](https://qimg.xiaohongshu.com/odin/1041017g31r1e5nstno06bbea2o9000000000011e0kkju)

**2.2****移动端获取授权码**

服务商在自己应用中生成授权二维码，保存到手机相册，打开小红书千帆APP，登录需要授权的店铺，扫一扫相册中的二维码，会跳转到授权页面，商家完成授权操作后，平台会将授权码code回调到回调地址中
    
    
    授权二维码组装格式：
    https://ark.xiaohongshu.com/thor/open/authorization?fullscreen=true&appId;=xxx&sellerId;=xxx&redirectUri;=xxx
    
    
    授权二维码组装示例：
    https://ark.xiaohongshu.com/thor/open/authorization?fullscreen=true&appId;=4b6*******672e4c9a&sellerId;=60e*******0120feed&redirectUri;=https://www.xiaohongshu.com

授权规则与web端一致

### 三、获取访问令牌（accessToken）

点击授权按钮后，平台会生成code，并将界面重定向到应用对应的回调地址中，贵方需要接收code并使用code调用平台授权接口换取accessToken。
    
    
    调用接口： https://ark.xiaohongshu.com/ark/open_api/v3/common_controller

请求参数说明：

参数名称| 是否必须| 示例值| 参数释义  
---|---|---|---  
appId| 必须| 27d***b081e7| 第三方使用小红书开放平台的appId  
version| 必须| 2.0| 网关版本判定参数目前授权流程使用2.0  
sign| 必须| 6a76602***68400| 输入参数的签名结果，签名方法参见sign签名算法  
timestamp| 必须| 171***379| 接口调用时的时间戳  
method| 必须| oauth.getAccessToken| 调用的具体方法，获取AT的方法固定为”oauth.getAccessToken“  
code| 必须| code-17ec0*****5ad92| 授权code  
      
    
    参数示例：
    {
        "sign":"6a76602***68400",
        "appId":"27d***b081e7",
        "timestamp":"171***379",
        "version":"2.0",
        "method":"oauth.getAccessToken",
        "code":"code-17ec062d187248bcbb7e5ba4e10f1c22-df1802306a064b5e95fe38b11cc5ad92"
    }

响应参数说明

参数名称| 示例值| 参数释义  
---|---|---  
accessToken| token-2d22cd***3c1b55bc7-e83e919***a3504b398| 访问令牌  
accessTokenExpiresAt| 1712239430773| 访问令牌过期时间(ms)  
refreshToken| refresh-72df8ba***7e1387407ac-944badaf***268294df5ae1| 刷新令牌  
refreshTokenExpiresAt| 1712844230773| 刷新令牌过期时间(ms)  
sellerId| 5a151****ee832| 商家编码  
sellerName| 开放平台测试店1专卖店| 商家名  
      
    
    响应示例
    {
        "error_code": 0,
        "data": {
            "accessToken": "token-2d22cd***3c1b55bc7-e83e919***a3504b398",
            "accessTokenExpiresAt": 1712239430773,
            "refreshToken": "refresh-72df8ba***7e1387407ac-944badaf***268294df5ae1",
            "refreshTokenExpiresAt": 1712844230773,
            "sellerId": 5a1***ee832,
            "sellerName": "开放平台测试店1专卖店"
        },
        "success": true
    }

### 四、刷新访问令牌（刷新accessToken）
    
    
    调用接口： https://ark.xiaohongshu.com/ark/open_api/v3/common_controller

请求参数说明：

参数名称| 是否必须| 示例值| 参数释义  
---|---|---|---  
appId| 必须| 27d***b081e7| 第三方使用小红书开放平台的appId  
version| 必须| 2.0| 网关版本判定参数目前授权流程使用2.0  
sign| 必须| 6a76602***68400| 输入参数的签名结果，签名方法参见sign签名算法  
timestamp| 必须| 171***379| 接口调用时的时间戳  
method| 必须| oauth.refreshToken| 调用的具体方法，更新AT的方法固定为”oauth.refreshToken“  
refreshToken| 必须| refresh-abe******9c2b9f9| 用于刷新的refreshToken  
      
    
    参数示例：

        "sign":"6a76602***68400",
        "appId":"27d***b081e7",
        "timestamp":"171***379",
        "version":"2.0",
        "method":"oauth.refreshToken",
        "refreshToken":"refresh-06ca049***b77ac4493697-3251618c7***ebfffd7e"
    }

参数名称| 示例值| 参数释义

accessTokenExpiresAt| 1712239430773| 访问令牌过期时间(ms)  
refreshToken| refresh-72df8ba***7e1387407ac-944badaf***268294df5ae1| 刷新令牌

sellerId| 5a151****ee832| 商家编码

    响应示例
    {
        "error_code": 0,
        "data": {
            "accessToken": "token-2d22cd***3c1b55bc7-e83e919***a3504b398",
            "accessTokenExpiresAt": 1712239430773,
            "refreshToken": "refresh-72df8ba***7e1387407ac-944badaf***268294df5ae1",

### 

### 注意事项

  1. accessToken有效期为7天，refreshToken有效时间为14天
  2. accessToken未过期且剩余有效时间大于30分钟，使用refreshToken进行刷新后accessToken和refreshToken均不会刷新
  3. accessToken未过期且剩余有效时间小于30分钟，使用refreshToken进行刷新后会得到新的accessToken和refreshToken，且旧accessToken有效期变为5分钟
  4. accessToken过期后使用refreshToken进行刷新后会得到新的accessToken和refreshToken
  5. refreshToken过期后需要通过用户重新授权
  6. 获取accessToken和刷新accessToken的参数均通过body传输
  7. 后续所有业务接口的url和刷新token的url保持一致
