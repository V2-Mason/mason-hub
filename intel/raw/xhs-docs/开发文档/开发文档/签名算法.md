## 签名算法

本页内容为采用oauth2授权后新版系统的sign签名算法

目前参与加密的均为系统参数和appSecret。系统参数有：appId,timestamp,version,method

#### 示例：

以创建商品接口为例。

##### 1.参数拼接(拼接字段空格为格式，实际中不存在)
    
    
    加密参数有:
    appId:21d6***748be8de0
    timestamp: 1612518379
    version：2.0
    method:product.createItem
    按照路以下规则method?appId=xxx& timestamp=xxx&version=xxx组合得到
    product.createItem?appId=21d6***748be8de0& timestamp=1612518379&version=2.0
    

##### 2.拼接appSecret
    
    
    将appSecret连接在最后
    此处appSecret为429a***a3aee9ef9e4a858210
    得到
    product.createItem?appId=21d6***748be8de0& timestamp=1612518379&version=2.0429a***a3aee9ef9e4a858210
    

##### 3.MD5计算签名（计算逻辑可参考文档下方代码示例）
    
    
    上述字符串的MD5签名结果为 aa4c59****50632d80dc4

##### 4.http调用

以测试环境为例：
    
    
    Request url：
    http://ark.sit.xiaohongshu.com/ark/open_api/v3/common_controller

    body内容(json格式)：

Java
    
    
    public static String generateSign(String appId, String timestamp, String method, String appSecret) {
        List<String> params = new ArrayList<>();
        params.add("appId=" + appId);
        params.add("timestamp=" + timestamp);
        params.add("version=2.0");
        params.sort(Comparator.naturalOrder());
        String queryStr = String.join("&", params);
        String signSource = method + "?" + queryStr + appSecret;
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            md.update(signSource.getBytes());
            byte[] digest = md.digest();
            StringBuilder sign = new StringBuilder(digest.length * 2);
            for (byte b : digest) {
                sign.append(String.format("%02x", b));
            }
            return sign.toString();
        } catch (Exception e) {
            throw new RuntimeException("generate sign error...", e);
        }
    }
    

Python
    
    
    import hashlib
    
    def generate_sign(app_id, timestamp, method, app_secret):
        params = [
            f"appId={app_id}",
            f"timestamp={timestamp}",
            "version=2.0"
        ]
    
        params.sort()
        query_str = "&".join(params)
        sign_source = f"{method}?{query_str}{app_secret}"
    
        md5 = hashlib.md5(sign_source.encode("utf-8")).hexdigest()
        return md5
    

Go
    
    
    package main
    
    import (
    	"crypto/md5"
    	"encoding/hex"
    	"fmt"
    	"sort"
    )
    
    func generateSign(appId, timestamp, method, appSecret string) string {
    	params := []string{
    		"appId=" + appId,
    		"timestamp=" + timestamp,
    		"version=2.0",
    	}
    
    	sort.Strings(params)
    
    	queryStr := ""
    	for i, p := range params {
    		if i > 0 {
    			queryStr += "&"
    		}
    		queryStr += p
    	}
    
    	signSource := method + "?" + queryStr + appSecret
    
    	hash := md5.Sum([]byte(signSource))
    	return hex.EncodeToString(hash[:])
    }
