# 授权流程（自研商家）

### 前提条件

  * 应用必须处于上线状态;
  * 完成测试店铺授权，确保应用的授权回调地址可以正常接收code;



### 授权规范

  * 商家自研开发者所申请的APPKEY不得转让给他人使用；
  * 商家自研开发者所创建的应用，只能授权给同一主体、主体存在关联关系的最多10个企业店铺使用，且店铺必须处在正常经营状态；（如有多个请提工单申请白名单，工单中请附带应用ID和要授权的店铺ID）
  * 一个商家针对一个类目的自研应用只能授权一个（单个商家可以授权多个不同类目的自研应用）。
  * 商家授权应用时必须用店铺主账号。



## **授权流程**

### 一、添加店铺ID到应用的授权管理并复制授权链接

  1. 依次点击“「控制台」-「应用管理」-「授权管理」”可进入下图中所示界面；
  2. 输入框中输入要授权的店铺id，即sellerId(店铺id可以在「千帆」→「店铺」→「店铺账号信息」中找到，必须是”非个人/个体“类型的店铺)；
  3. 点击“添加授权店铺”，并复制授权链接。



![](https://qimg.xiaohongshu.com/odin/1041017g31r1acljt7u06bbea2o9000000000016heg02s)

### 二、在浏览器中打开此链接并授权。

若店铺和应用分开管理，请将复制的授权链接发送给要授权的店铺主账号持有人员，并在浏览器中打开完成授权。若统一管理，直接在浏览器中打开点击授权即可。

![](https://qimg.xiaohongshu.com/odin/1041017g31r1aljcrga06bbea2o9000000000016uohd94)

### 三、获取访问令牌（accessToken）

点击授权按钮后，平台会生成code，并将界面重定向到应用对应的回调地址中，贵方需要接收code并使用code调用平台授权接口换取accessToken。
    
    
    调用接口： https://ark.xiaohongshu.com/ark/open_api/v3/common_controller

请求参数说明：

参数名称| 是否必须| 示例值| 参数释义  
---|---|---|---  
appId| 必须| 27d***b081e7| 第三方使用小红书开放平台的appId  
version| 必须| 2.0| 网关版本判定参数目前授权流程使用2.0  
sign| 必须| 6a76602***68400| 输入参数的签名结果，签名方法参见sign签名算法  
timestamp| 必须| 171***379| 接口调用时的时间戳  
method| 必须| oauth.getAccessToken| 调用的具体方法，获取AT的方法固定为”oauth.getAccessToken“  
code| 必须| code-17ec0*****5ad92| 授权code  
      
    
    参数示例：
    {
        "sign":"6a76602***68400",
        "appId":"27d***b081e7",
        "timestamp":"171***379",
        "version":"2.0",
        "method":"oauth.getAccessToken",
        "code":"code-17ec062d187248bcbb7e5ba4e10f1c22-df1802306a064b5e95fe38b11cc5ad92"
    }

refreshTokenExpiresAt| 1712844230773| 刷新令牌过期时间(ms)  
sellerId| 5a151****ee832| 商家编码  
sellerName| 开放平台测试店1专卖店| 商家名  
      
    
    响应示例
    {
        "error_code": 0,
        "data": {
            "accessToken": "token-2d22cd***3c1b55bc7-e83e919***a3504b398",

### 五、取消授权

如果当前授权状态为「未授权」时，开发者可以在授权管理界面中操作将授权记录删除。

如果当前授权状态为「授权中」时，商家可以前往「千帆」→「服务」→「我的服务」取消授权。开发者可以也在「授权管理」页面中取消授权，授权记录将消失。

  


### 授权管理规则声明

商家创建自研应用后，出现以下情况的，平台将在2023年3月31日起，收回商家自研的接入权限

1、商家自研应用并非商家自行开发；  
2、商家自研应用的授权方与自研开发者自身非同一主体，或主体间不存在关联关系；  
3、一个商家授权给多个自研应用的。

### 授权说明

平台授权流程遵循Oauth2.0协议，服务商可查阅相关资料了解细节。每当商家用户点击授权之后，平台会生成code重定向发送给isv，isv使用appId和code换取token完成代表授权完成。平台会返回：accessToken(有效期7天，后称AT)，refreshToken(有效期14天，后称RT)，店铺sellerId。

  1. AT代表可以调用平台API接口的唯一标识，若AT过期则不能再调用平台接口
  2. RT代表授权标识，有效期代表授权有效期，若RT过期则需要商家用户重新授权（若过期没有其他途径，必须重新授权）
  3. AT过期前30分钟至RT过期前，都可以使用RT换取AT，换取成功则会获取新的AT和RT并重置授权有效期。
  4. 只要RT不过期则均可以使用RT换取新的AT。但AT过期前30分钟之前使用RT换取均会获得原有AT和RT，不会重置授权有效期，若调用次数过多会被限流，因此不要在AT失效前30分钟前过度频繁调用刷新AT。
