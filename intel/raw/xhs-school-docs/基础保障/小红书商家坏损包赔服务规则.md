服务内容</span></h1><h2>第2条 服务概述</h2><p>坏损包赔是指，消费者在小红书平台购买<span style="color: rgba(0, 0, 0, 0.8);">带有“坏损包赔”服务标识的商品后</span><span style="color: rgb(0, 0, 0);">，发现商品存在腐烂变质、缺斤少两、商品破损、漏液等坏损问题，且在</span><span style="color: rgb(204, 48, 48);">服务</span><span style="color: rgb(204, 48, 48);">有效期</span><span style="color: rgb(204, 48, 48);">内申请售后</span><span style="color: rgb(0, 0, 0);">，并提供有效举证材料的。</span>商家承诺在24小时内有效响应消费者的售后申请，并根据本服务规则进行赔付<span style="color: rgb(0, 0, 0);">。（商家与消费者就处理方案达成一致协议则视为有效响应；小红书有权基于用户申请、用户投诉和店铺售后等因素主动介入处理消费者的售后申请，且有权从商家保证金及/或货款中扣划相应退款和赔付金额给消费者。）</span></p><h2>第3条 服务条件</h2><p>3.1 商家履行“坏损包赔”服务的条件包括：</p><p>（1）<span style="color: rgba(0, 0, 0, 0.8);">订单商品带有“坏损包赔”服务标识；</span></p><p>（2）消费者收到的商品发生破损、变质、腐烂等<span style="color: rgba(0, 0, 0, 0.85);">具体类目商品售后争议规则</span>规定的情形；</p><p>（3）消费者在服务有效期内发起售后申请，服务有效期自签收时间开始计算，签收时间以物流官网显示的签收时间为准；</p><p>a.水果生鲜食品等易腐烂商品的服务有效期为48小时（含）内；</p><p>b.非水果生鲜食品等不易腐烂商品的服务有效期为最短7天（含）内；</p><p>（4）消费者需提供有效的图片凭证，具体凭证规范以<span style="color: rgba(0, 0, 0, 0.85);">具体类目商品售后争议规则</span>为准。</p><p>3.2 消费者可通过以下路径发起“坏损包赔”服务申请：</p><p>（1）消费者通过订单详情页，从“坏损包赔”标签一键申请服务；</p><p>（2）消费者可通过订单页面，以<span style="color: rgb(64, 64, 64);">“</span>包装/商品破损/污渍/裂痕/变形，质量问题，商品变质/发霉/有异物，实物与商品描述不符，<span style="color: rgb(23, 43, 77);">做工粗糙/有瑕疵，收到商品少件（含少配件）</span><span style="color: rgb(64, 64, 64);">”</span>等理由发起售后服务。</p><h2>第4条 服务限制</h2><p>4.1 当消费者提出“坏损包赔”服务申请时，若小红书判断或商家证明消费者属于以下行为场景时，小红书有权驳回消费者的申请：</p><p>（1）消费者非以生活消费为目的生成的订单；</p><p>（2）消费者申请退款的金额上限超过订单实付价格（包含商品优惠后的价格、运费、税费）；</p><p>（3）消费者恶意利用此服务牟利的；</p><p>（4）依据消费者提供证据，其他平台难以认定商家需要履行“坏损包赔”服务承诺的情形。</p><p>4.2 因不可抗力因素造成的未履行服务，商家不承担因此而导致的服务未履行责任。“不可抗力”指不可预见、不可避免或不可克服的客观情况以及其他影响服务履行的客观情况，包括自然灾害、战争、罢工、骚乱、恐怖事件、政府行为、公共卫生事件等。</p><p>4.3 双11、618、春节期间的24小时商家响应时效可能适时延长，具体延长时间见相关公告或通知。</p><h1>第三章 争议处理</h1><h2>第5条 服务内容细则</h2><p>5.1 消费者在规定时间内以第3.2条规定的订单页面相关售后理由提交售后申请的，商家应在消费者发起该申请的24小时内进行审核，逾期未审核的，视为商家审核同意消费者申请，平台将直接退款给消费者。如商家拒绝消费者售后申请，平台将自动介入。若平台判定为商家责任，即商家应履行“坏损包赔”服务但实际未履行的，<span style="color: rgba(0, 0, 0, 0.85);">商家应当根据本服务规则向消费者进行赔付</span>，具体赔付金额参考下述赔付标准。</p><p>5.2 如遇促销活动、特定节假日或不可抗力的，处理时效要求以平台另行通知或公告为准。</p><p>5.3 消费者在发起售后申请及平台介入时均有举证义务，所有凭证需未经涂改、未有增删、未经任何编辑，否则视为无效凭证。</p><p>5.4 如小红书认定商家违背或未按时履行本规范规定的服务承诺的，小红书有权直接自商家保证金及/或货款中扣划相应退款和赔付金以赔付给消费者。</p><h2>第6条 赔付标准</h2><p>6.1 消费者提供有效凭证，商家应当履行“坏损包赔”服务但实际未履行，且经平台判定为商家责任的，小红书有权要求商家作出合理解释或提交相应的凭证。如小红书认定商家违背或未履行本规范规定的“坏损包赔“服务的，小红书有权支持消费者的售后申请，要求商家履行退货退款、换货、补发，并额外要求商家按照坏损包赔商品实付金额30%的标准向消费者承担赔付责任，且赔付金额最高不超过100元，最低不少于5元（不足人民币5元的，以人民币5元计，赔付金额四舍五入精确到分）。实付金额包含商品优惠后的价格、运费及税费。 如实付金额低于或等于5元的，则不赔付。赔付将<span style="color: rgb(0, 0, 0);">以无门槛薯券方式发放。</span></p><p>6.2 如商家和消费者双方对赔付另有约定，按双方约定处理。</p><h1>第四章 特别说明</h1><h2>第7条 商家责任与服务展示</h2><p><span style="color: rgba(0, 0, 0, 0.85);">（1）为保障用户消费体验，经营易腐烂类目商品的商家应当自动开通“坏损包赔”服务。针对本次规则修订前经营带有坏损包赔服务标签商品的商家，商家授权平台代其继续开通本服务保障。商家需要根据本规则及相关平台协议的规定向消费者提供本服务，具体类目及生效条件以商家后台相应面显示为准。</span></p><p><span style="color: rgba(0, 0, 0, 0.85);">，即承诺就带有“坏损包赔”服务标识的商品根据本服务条款的规定向消费者提供本服务。</span></p><p><span style="color: rgba(0, 0, 0, 0.85);">（2）商家可根据自身情况自行停用坏损包赔服务，但应继续就服务停用前消费者已下单的订单提供本服务。</span></p><p><span style="color: rgba(0, 0, 0,
