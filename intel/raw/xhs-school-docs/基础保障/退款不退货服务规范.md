<h1><strong>第一章 概述</strong></h1><p>第一条 适用范围</p><p>本规则适用于<span style="color: rgba(0, 0, 0, 0.85);">消费者在小红书平台购物时申请退款不退货</span>服务的售后处理。</p><p>第二条 效力级别</p><p><span style="color: rgba(0, 0, 0, 0.85);">本规则是针对商家与消费者就退款不退货问题发生的售后服务的特殊规定，本规则已有规定的事项，适用本规则，本规则未规定的事项，适用《</span>小红书第三方商家售后服务管理规则<span style="color: rgba(0, 0, 0, 0.85);">》或其他平台规则。</span></p><h1><strong>第二章 受理范围</strong></h1><p>第三条 退款不退货：指特定情形下，消费者在收到商品后要求取消订单或申请售后，要求获得该订单商品全额退款且不需要履行退回商品义务的情形。</p><p>第四条 消费者收到商品或接受服务后申请全额退款的，如符合以下情形的，消费者可以在接受全额退款时无需承担退货义务：</p><p>（一）经消费者与商家协商一致的；</p><p>（二）由于商家不履行法定或者商家承诺的退货、保修、换货等售后义务，导致消费者在无过错的情况下，既无法退还商品又完全无法实现消费目的的；</p><p>（三）交易标的为无法退回或者无需退回的虛拟商品或者服务，消费者在无过错的情况下完全无法实现消费目的的。</p><p>第五条 <span style="color: rgba(0, 0, 0, 0.85);">除外场景：消费者收到商品或接受服务后申请全额退款的，如发生以下情形且按照法律法规、平台规则有关规定或者商家承诺应当对消费者进行全额退款时，消费者可以申请全额退款，但不直接适用退款无需退货。</span></p><p>（一）物流成本较高，退回不便的情形；</p><p>（二）退回后商品价值可能贬损较大的情形；</p><p>（三）商家存在违法违规行为的情形；</p><p>（四）不符合物流规定导致退回不便的情形</p><p><span style="color: rgba(0, 0, 0, 0.85);">如商家要求商品退回的，消费者应当退回商品。同时，商家应当明确商品退回的物流要求，并为消费者退货提供必要的协助，退货成本以及相应风险按照相关法律规定由责任方承担。如商家无法提供有效协助导致商品无法退回，依照有关法律法规和部门规章、平台规则对双方责任进行划分，有关损失和相应风险由责任方承担。</span></p><h2><strong>第三章 处理原则</strong></h2><p>第六条 平台将平等保护商家、消费者的合法权益，充分尊重商家自主经营权，遵循“退款需退货”的基本原则，按照法律法规和部门规章有关规定制定、执行相关规则。<strong>“退款时无需退货”属于“退货退款”的例外情形，仅在个别情形下适用。</strong></p><p><span style="color: rgba(0, 0, 0, 0.85);">本规则及其他平台规则中关于退货退款以及退款无需退货规则的适用，不排除消费者依法寻求其他救济的权利，不免除商家依法应当承担的责任。</span></p><h2><strong>第四章 举证标准</strong></h2><p>第七条 如果消费者申请退款不退货售后，需要提供商品无法满足使用需求相关依据，以便核实处理。</p><h2><strong>第五章 判责标准</strong></h2><p>第八条 若买卖双方就退款不退货售后服务产生争议，且商品为消费者基于生活消费所需购买的，申请平台介入的，平台将根据本规则及双方的举证情况进行判定。</p><h2><strong>第六章 附则</strong></h2><p>第九条 申请售后时间，发生在本规则生效之日或修订之日以前的，适用当时的规则，发生在本规则生效之日或修订之日以后的，适用本规则 。</p>
