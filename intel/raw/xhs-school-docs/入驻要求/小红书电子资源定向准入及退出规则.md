小红书电子资源定向准入及退出规则(现类目)
**第一章 概述**
**第一条 制定目的**

为规范小红书电商平台运营秩序，保障用户的合法权益， 规范服务商经营者的入驻及退出，特制定本规则。

**第二条 适用范围**

2.1 本规范适用于经营以下类目的商家及推广类目商品的买手，若后续平台类目名称变更，但商品性质属于电子资源类，则仍适用本规则

2.2 若后续平台调整类目名称，但商品性质属于电子资源类，则仍适用本规则；若商家将性质属于电子资源类的商品发布在其他类目下，则平台有权依据规则对相应商品进行管理。

|---|---|
| 电子资源 | PPT/简历/其他模版 |
|  | 课件/教案/手抄报 |
|  | 头像壁纸 |

**第二章 入驻规则**
**第三条 入驻方式**
对于不同的类目，平台目前有不同的入驻要求，即普通销售或定向准入。

（1）普通销售：即开放招商，商家无需经过平台邀请，可直接进行入驻。

（2）定向准入：指在平台对一些特定品牌或类目商品，实行先接收商家入驻申请，并经平台审核通过后才可入驻经营。目前电子资源定向准入类目如下：

**第四章 退出规则**
第九条 到期退出
（1）退出条件

合同到期且商家无续签申请或者在续签流程中。

（2）退出等待

1）自合同到期起30天，店铺放置退出公告，30天后，平台关闭店铺；

2）自关闭店铺之日起60天且无未确认事项，平台在扣除相应退款以及违约金之后退还剩余保证金。

（3）退出处理

1）商家应确认未处理的对账单；

2）在关店之日前，商家仍应处理客诉或者订单，若商家超时未处理，由平台客服统一接待，平台将按照平台规则对订单进行相应处理，产生的客服咨询费用以及订单的赔付、退款等费用由商家承担；

3）商家需确认入驻协议状态，若商家未处理，平台在关闭店铺超60天后将无法退还保证金，直至入驻协议归档；

4）店铺退出公示期间，若消费者进行咨询，由平台客服统一接待，平台将按照平台规则对订单进行处理，产生的客服咨询费用以及订单的赔付、退款等费用由商家承担。

第十条 自主退出
（1）退出条件

商家在满足以下条件后向平台申请自主退出：

1）无未确认的对账单；

2）无未处理客诉；

3）无上架商品；

4）无待发货/退款的订单；

5）入驻协议已寄回平台进并行归档；

6）无正在进行中或者即将参加的平台活动；

（2）退出申请材料

关闭店铺申请书。

（3）退出等待

1）自商家发起退出且经平台确认无误后，平台保留店铺并冻结所有商品，30天后，平台关闭店铺；

2）自关闭店铺之日起超60天且无确认事项，平台在扣除相应退款以及违约金之后退还剩余保证金。

（4）退出处理

店铺退出公示期间，若消费者进行咨询，由平台客服统一接待，平台将按照平台规则对订单进行处理，产生的客服咨询费用以及订单的赔付、退款等费用由商家承担。

**第十二条 退出后业务处理规范**
（1）商家因上述任何原因退出的，平台有权根据实际需要对商家及其商品采取隐藏、下架、商服解绑等措施。退出期间，商家不得私自停止处理纠纷或中断已经签署的合作协议或私自停止服务，导致用户权益受损，由商家承担责任；

（2）商家因上述任何原因退出的，由于商家责任产生的用户问题或投诉，商家需配合平台处理直至问题或投诉被解决。

**第十三条 退出限制**
13.1 商家自主申请退出或者合同到期退出后，180天内不得重新入驻。

13.2 因平台清退的商家，永久禁止其入驻。

**第五章 附则**
第十四条 规则适用

本规则生效以前已经营相应类目的商家，应当及时根据本规则调整经营行为。本规则生效之日起，所有经营相应类目的新老商家及已发布的相应类目商品均适用本规范。
