小红书消费者隐私信息加密调整公告
一、推进节奏
2023年10月16日已关闭商家后台用户姓名，电话，收货地址信息查看明文功能、待发货导出明文功能，并对用户姓名，电话，收货地址信息进行加密限制，同时所有的订单接口解密额度将遵守平台统一限制。

**2025年6月30日**起已陆续**下线无限额解密申请功能，不支持直接导出用户信息**，除大件商品、虚拟商品、跨境订单支持小眼睛逐单解密外，其他部分要求正常密文下发，不再支持解密操作，特殊情况商家可以按照额度进行提额解密。

二、 对不同

三、订单解密管理
3.1 订单解密规则
**2025年6月30日**起，不再支持解密无限额申请，最新规则如下：

| **订单类型/订单状态** | **解密规则** |
|---|---|
| 大件商品订单 | 符合大件类目商品订单，支持逐单点击小眼睛进行解密，解密不消耗额度 |
| 虚拟商品订单 | 符合虚拟类目商品订单，支持逐单点击小眼睛进行解密，解密不消耗额度 |
| 跨境进口 | 符合跨境进口模式订单，支持逐单点击小眼睛进行解密，解密不消耗额度（另：仅直邮和行邮订单支持导出明文） |
| O2O | 符合O2O模式订单，支持逐单点击小眼睛进行解密，解密不消耗额度 |
| 订单状态：待支付；已取消；已关闭；已完成14天后 | 不支持解密 |
| 订单有关联售后单且在售后中 | 支持解密，且解密不消耗额度 |
| 其他订单状态 | 支持解密，且解密消耗额度 |

注： 当天同一笔订单重复解密，只消耗一次解密额度

**3.2 订单解密额度限制**
为防止商家不当使用解密功能，平台对店铺订单解密额度（即查看次数）进行了限制：

（1） 平台将在每日0点为店铺赋予基础解密额度，基础解密额度=店铺当日所有待发货订单*动态系数，该额度将正常满足店铺日常解密需求，具体额度以商家后台【店铺】-【店铺管理】-【隐私保护】页面展示为准。

（2） 如当日基础解密额度不能满足商家业务需求时，可申请临时提升解密额度，额度上限以商家后台【店铺】-【店铺管理】-【隐私保护】页面展示为准。

（3） 申请临时提额时请如实填写申请理由，随意或虚假填写会影响后续提额申请结果。若申请单一直未审核，则会在当日23:59:59自动失效，解密额度将在次日0点重新计算；若审核不通过，具体原因以审核单页面展示为准。

（4） 如当日基础解密额度未使用完，**不得使用提额工具申请临时额度**，请将当日剩余额度使用完再申请额度。

（5）如店铺当日的所有解密次数（包含基础解密额度+临时解密额度）用尽，订单解密功能将受到限制直至当日24点，次日0点将重新开启。

**3.3 订单解密行为规范**
（1）商家需在平台内规范使用解密功能，不得通过第三方违规解密订单，否则，平台将永久关停该商家的订单解密功能。

（2）针对待支付、已取消、已关闭、已完成14天后、交易完成且已评价状态订单禁止解密，商家不得违规解密以上状态的订单，否则，平台有权永久关停该商家的订单解密功能。

（3）若店铺出现侵害消费者信息安全的，如代拍行为，平台有权限制对商家的解密额度进行限制。

（4）若商家店铺（含同一主体店铺）历史出现较严重引导私下交易、电话骚扰/辱骂、刷单改好评、线下欺诈等违规行为的，平台将永久关停该商家的订单解密功能。

（5）若商家店铺（含同一主体店铺）历史出现较严重订单信息泄漏情况的，平台将永久关停该商家的订单解密功能。

3.4 解密提额申请流程
如当日基础解密额度不能满足商家业务需求，可进入商家后台【店铺】-【店铺管理】-【隐私保护】页面申请临时提升解密额度。点击“提额申请”，并如实填写申请理由、申请额度以及详细申请说明，进行申请。

提交申请后，平台的审核时效通常为2小时，请耐心等待。

五、常见问题
**Q：特殊情况下，商家需要电话联系收件人怎么办？**

A：商家可以在小红书商家后台点击小眼睛查看收件人相关信息；使用第三方软件的商家可在软件上点击小眼睛查看收件人相关信息。

**Q：厂家如何在无店铺的情况下快速注册电子面单？**

A：厂家去注册电子面单（无需开通店铺），小红书无店铺订购电子面单入口：

https://ebill.xiaohongshu.com/login?from=%2Febill%2Faddress-store%2Flist

，然后在erp进行授权。

**Q：开通电子面单后为何仍无法查看信息？**

A：电子面单开通是解决需要解密发货问题，减少额度消耗作用，并不会给到查看信息权限。

**Q：加密后是否允许导出订单明细信息？**

A：加密后允许商家导出订单明细信息，其中收货信息会被加密。

**Q：对于商品漏寄，商品破损，商品换货，发送赠品等需要给买家再次补发商品的场景，怎么处理？**

A：补发商品场景无需解密发货，支持在「打单发货-手工打单」页面手工录入订单，获取原订单密文信息重新打单发货。
