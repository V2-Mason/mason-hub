电商规则中心-结算规则 0204
第一章 概述
第一条 为保障小红书平台及商家店铺的正常经营秩序，根据相关法律法规的规定，以及《小红书店铺服务协议》、《小红书店铺服务协议（仅适用于跨境商家）》（下称“店铺协议”）等平台协议及管理规则，制定本规则。

第二条 本规则适用于入驻小红书平台开展电子商务经营活动的商家。

第三条 定义

3.1 销售款：指商家在小红书平台销售商品或服务（以下统称“商品”）的订单产生的收入，包括商品货款、运费、平台补贴等。 

3.2 入账款项：指订单的销售款扣除技术服务费以及增值服务、带货服务等服务费用后的结算入账款项。

第二章 结算规范
第四条 订单确认收货后满一定周期（即“结算账期”）且未发生售后的，系统将自动结算入账，商家可自行提现。订单确认收货是指，买家在小红书平台内主动操作确认收货，或订单根据平台规则发货满一定期间后系统自动确认收货。订单结算账期根据商家店铺分情况确定并动态调整，具体如下表所示，当发生商家违规、争议纠纷等情况，小红书判断商家存在信用风险、可能危及消费者合法权益或交易安全时，有权视情况适当延长账期。

| **商家类型** | **店铺分** | **结算账期** | **其他说明** |
|---|---|---|---|
| 有店铺分商家 | 店铺分>=4.7分的店铺 | 订单确认收货后4天 | 1、小红书每月1号、16号根据前一日更新的店铺分分值对商家结算账期进行调整，调整后即时生效，店铺内所有未结算订单将执行新的结算账期；  2、当商家店铺分跌至4.5分以下时，小红书有权在次日即调整结算账期为确认收货后7天。 |
|  | 店铺分<4.7分的店铺 | 订单确认收货后7天 |  |
| 无店铺分商家 |  | 订单确认收货后7天 |  |

【特别说明】 如订单结算账期内发生售后、维权，则该订单按售后完结时间与结算账期结束时间，二者取晚进行结算入账。

第五条 商家可在千帆后台【账单管理】页面查看店铺的待结算款项，小红书平台在每个月的前五个工作日内推送上一个自然月的月度结算单给商家。 

第六条 商家可以针对账户余额进行提现，每日有**三**次提现机会。商家申请提现后的1个工作日内，由小红书平台合作支付服务机构向商家提现账户支付款项。款项到账时间以银行实际到账时间为准，如遇节假日则顺延（跨境商家遇到的节假日期与境内有所不同）。

第七条 跨境商家提现最低限额为300元人民币，境内商家无最低限额。

第八条 跨境商家提现手续费取决于商家绑定的境外银行的手续费标准，由商家承担。境内商家无提现手续费。

第九条 境内商家结算币种为人民币，跨境商家结算币种商家可自行选择（仅限于小红书系统内可选项）。

第十条 跨境交易款项将由小红书合作的且具备跨境支付结算能力和资质的支付机构/银行为商家提供相应支付结算服务，结算汇率以上述支付机构/银行实际业务处理时适用的汇率为准。

第十一条 为保证消费者申请退款时，能够及时将款项退给消费者，以提升消费者的购物体验，同时为保证物流仓储等有序进行，平台有权在商家账户中冻结部分金额，显示为【冻结金额】，冻结状态解除后将恢复至可提现账户余额。 

【特别说明】 

（1）冻结金额=退款冻结+物流冻结 

（2）退款冻结：预留部分结算款，用于用户订单退款。该金额每周更新，关店时解冻。 

（3）退款冻结不足500元时，将不冻结金额。举例：14日的日均退款金额小于500元人民币时，则退款冻结为0元。 

（4）物流冻结：预留部分结算款，用于支付物流仓储费用。该金额每周更新，关店时解冻。

第十二条 商家应在结算单生成之日起90个自然日内确认，商家超期未进行确认的，系统将自动确认结算单。如商家对结算单有异议的，应自结算单生成之日起90个自然日内进行申诉并结束流程，商家超期未申诉或申诉不通过的，将视为商家同意结算单内的结算金额，小红书将不再接受对该账单的申诉。

第十三条 结算单的实际结算金额仅保留小数点后两位（采取四舍五入法）。

第十四条 跨境商品计税价格规则：商品计税价格=商品原价-促销优惠价格（如满减、限时购、特价优化等，但不含店铺券、平台券等券类优惠，该券类优惠需要参与商品计税）。

第十五条 商家因参加平台各类活动而获得的小红书平台补贴，包括但不限于各类优惠券、代金券、现金抵用券补贴，小红书平台将以平台券等形式提供。小红书平台将在商家确认结算单后，根据商家申请开票的顺序，依次向商家开具与小红书平台收取的费用（包括但不限于技术服务费、物流费、支付渠道费、客服费、快递费、短信推广费、退货增值服务费等）抵减补贴后的等额增值税发票或形式发票（可向跨境贸易商家开具形式发票）。

如小红书平台提出要求，商家应就其提供的推广服务向小红书平台开具合法有效的发票。

第十六条 若商家应支付的任意款项无法从商家账户余额中扣除，商家需另行向小红书平台支付的，商家应当按照小红书平台要求及时进行支付，若未按时支付的，小红书平台有权采取包括但不限于冻结商家款项、直接从保证金中扣除相应款项及违约金、限制店铺交易等措施，直至商家完成该等款项及违约金的支付。

第十七条 平台商家的相关行为，发生在本规则修订生效以前的，适用当时的规则，发生在本规则修订生效之日以后的，适用本规则。
