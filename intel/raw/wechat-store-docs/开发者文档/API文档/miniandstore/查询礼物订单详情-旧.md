查询礼物订单详情-旧

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：get_present_order

通过该接口查询小店授权送礼订单详情。

小店近期对查询礼物单详情接口进行了优化，请使用最新版「查询礼物单详情」

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/presentorder/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用
本接口不支持第三方平台调用。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token
请求体 Request Payload
参数名	类型	必填	说明
present_order_id	number	是	礼物单id
openid	string	是	用户openid

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息
present_order_info	object	礼物单详情

Res.present_order_info Object Payload

礼物单详情

参数名	类型	说明
ecsgift	object	礼物详情信息
cannot_receive	number	能否收礼
cannot_receive_tips	string	不能收礼tips

Res.present_order_info.ecsgift Object Payload

礼物详情信息

参数名	类型	说明	枚举
gifts	object	礼物列表	-
wishmessage	string	祝福语	-
user_type	number	用户视角	枚举值

Res.present_order_info.ecsgift.gifts Object Payload

礼物列表

参数名	类型	说明
gift	objarray	礼物信息列表

Res.present_order_info.ecsgift.gifts.gift(Array) Object Payload

礼物信息列表

参数名	类型	说明	枚举
orderid	number	礼物单id	-
giftstatus	number	礼物状态	枚举值
expired_time	number	礼物过期时间	-

4. 枚举信息

Res.present_order_info.ecsgift.user_type Enum

用户视角

枚举值	描述
0	第三者
1	赠礼者
2	收礼者

Res.present_order_info.ecsgift.gifts.gift(Array).giftstatus Enum

礼物状态

枚举值	描述
0	待领取
1	已领取
2	已超时
3	已领取待填地址
4	礼物已领完
5	未填地址超时
6	未抽中

5. 注意事项

本接口无特殊注意事项
