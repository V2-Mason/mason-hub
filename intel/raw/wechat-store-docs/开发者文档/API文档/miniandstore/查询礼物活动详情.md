查询礼物活动详情

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：get_activity

通过该接口查询小店授权送礼活动详情。

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/b2c/activity/info/promoter/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用
本接口不支持第三方平台调用。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token
请求体 Request Payload
参数名	类型	必填	说明
shop_appid	string	是	小店appid
activity_id	number	是	小店活动id

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息
activity	object	活动信息

Res.activity Object Payload

活动信息

参数名	类型	说明	枚举
activity_id	number	活动id	-
info	object	活动信息	-
status	number	活动状态	枚举值

Res.activity.info Object Payload

活动信息

参数名	类型	说明
basic_info	object	活动基础信息
prize_info	object	活动礼物商品信息

Res.activity.info.basic_info Object Payload

活动基础信息

参数名	类型	说明
activity_start_time	number	活动开始时间，单位为秒
activity_end_time	number	活动结束时间，单位为秒
shop_info	object	小店信息

Res.activity.info.basic_info.shop_info Object Payload

小店信息

参数名	类型	说明
nickname	string	小店昵称
appid	string	小店appid

Res.activity.info.prize_info Object Payload

活动礼物商品信息

参数名	类型	说明
product_info_list	objarray	商品信息列表

Res.activity.info.prize_info.product_info_list(Array) Object Payload

商品信息列表

参数名	类型	说明
product_id	number	商品spuid
sku_id	number	商品skuid
product_img_url	string	商品图片url
product_name	string	商品名称
price	number	售卖单价，单位为分
sku_name	string	商品sku名称
stock_num	number	活动sku总库存
can_use_stock_num	number	活动sku剩余库存

4. 枚举信息

Res.activity.status Enum

活动状态

枚举值	描述
1	未开始
2	进行中
4	已开奖
5	失效

5. 注意事项

本接口无特殊注意事项
