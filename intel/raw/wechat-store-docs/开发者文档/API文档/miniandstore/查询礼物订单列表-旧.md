查询礼物订单列表-旧

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：list_present_order

通过该接口查询小店授权送礼订单列表。

小店近期对查询礼物单列表接口进行了优化，请使用最新版「查询礼物单列表」

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/presentorderlist/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用
本接口不支持第三方平台调用。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token
请求体 Request Payload
参数名	类型	必填	说明
shop_appid	string	是	小店appid
openid	string	否	用户openid
create_time_range	object	否	订单创建时间范围
update_time_range	object	否	订单更新时间范围
page_size	number	是	订单数量(1~100)
next_key	string	否	分页参数，上一页请求返回，首次置空即可

Body.create_time_range Object Payload

订单创建时间范围

参数名	类型	必填	说明
start_time	number	是	开始时间
end_time	number	是	结束时间

Body.update_time_range Object Payload

订单更新时间范围

参数名	类型	必填	说明
start_time	number	是	开始时间
end_time	number	是	结束时间

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息
present_order_list	objarray	礼物单列表
next_key	string	分页参数

Res.present_order_list(Array) Object Payload

礼物单列表

参数名	类型	说明
present_order_id	number	礼物单id
order_id	array	订单id列表

4. 注意事项

本接口无特殊注意事项
