创建并发送礼物

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：create_present_order

通过该接口创建并发送小店授权送礼商品给指定用户

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/presentorder/create?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用
本接口不支持第三方平台调用。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token
请求体 Request Payload
参数名	类型	必填	说明
activity_id	number	是	活动id
openid	string	是	用户openid
shop_appid	string	是	合作小店appid
wishmessage	string	是	礼物祝福语信息，最大100字符
product_id	number	是	指定活动商品
sku_id	number	是	指定活动sku
idempotent_id	string	否	幂等id

3. 返回参数
返回体 Response Payload
参数名	类型	说明
present_order_id	number	礼物单id
errcode	number	错误码
errmsg	string	错误信息

4. 注意事项

本接口无特殊注意事项

5. 代码示例

请求示例

{
    "activity_id": "22123",
    "openid": "oDiTs6x9ccP19TfQH5OvKOWeXAeo",
    "shop_appid": "wxxxxxxxxxxxxxxxxx",
    "wishmessage": "祝福你",
    "product_id": "10000239729501",
    "sku_id": "3623160014"
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "present_order_id": "4226341196275658752"
}


6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述	解决方案
0	成功	
40097	参数错误	请求参数不符合规范
108001	库存不足	检查商品活动库存
108002	商品状态异常	下架/非正常在售/被治理不可购买
608010	平台风控校验未通过	触发平台风控规则
608016	该商品不在礼物池	商品未加入活动送礼池
608021	商品送礼价格过高	超过2万元限制
6011100	活动类型错误	检查商家创建活动渠道
6011102	祝福语长度过长	小于100字符
6011103	活动侧全sku库存不足	未传入skuid检查全sku库存
6011104	请求处理中，请稍后重试	存在相同幂等id的并发请求
6080060	送礼份数超出预设活动库存	超出活动库存限制
6080061	送礼商品非预设活动商品	商品与活动配置不匹配
