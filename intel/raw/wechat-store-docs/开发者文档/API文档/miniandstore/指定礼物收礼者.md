指定礼物收礼者

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：set_present_receiver

通过该接口可以指定使用当前小程序发放的小店礼物单的收礼者。

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/presentorder/receiver/set?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用
本接口不支持第三方平台调用。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token
请求体 Request Payload
参数名	类型	必填	说明
present_order_id	string	是	礼物单ID
sub_order_list	objarray	是	礼物单子单列表

Body.sub_order_list(Array) Object Payload

礼物单子单列表

参数名	类型	必填	说明
order_id	string	是	礼物单子单订单ID
openid	string	是	收礼者openid

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息

4. 注意事项

本接口无特殊注意事项

5. 代码示例

请求示例

{
  "present_order_id": "4232433395290081234",
  "sub_order_list": [
    {
      "order_id": "3732433407897635328",
      "openid": "omT_t0BEynCijuylUpZCaAAZp0a6"
    }
  ]
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}


6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述	解决方案
6080073	礼物单状态错误	请检查礼物单状态
6080074	当前礼物单暂不支持此操作	请检查礼物单号
6080075	子单号错误	请检查礼物单子单单号
6080076	当前子单已经指定过收礼者	请检查礼物单子单单号
6080077	礼物单号错误	请检查礼物单号
6080078	子单列表为空	请检查sub_order_list
6080079	多笔子单指定了同样的收礼者	请检查子单单号和openid
