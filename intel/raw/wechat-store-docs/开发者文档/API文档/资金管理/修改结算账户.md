修改结算账户

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：setbankacct

可通过该接口修改结算账户

相关事件通知：结算账户变更回调

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/funds/setbankacct?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.funds.setbankacct

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：138

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
account_info	object	是	account_info

Body.account_info Object Payload

account_info

参数名	类型	必填	说明	枚举
bank_account_type	string	是	账户类型,企业类型只能绑定对公账户，个体工商户可以绑定对公或者对私账户	枚举值
account_bank	string	是	开户银行（获取开户银行, 搜索银行列表)	-
bank_address_code	string	是	开户银行省市编码（获取城市列表）	-
bank_branch_id	string	否	开户银行联行号(获取支行联号)	-
bank_name	string	否	开户银行全称（若开户银行为“其他银行”，则需二选一填写“开户银行全称（含支行）”或“开户银行联行号”）(获取支行信息))	-
account_number	string	是	银行账号	-
account_bank4show	string	否	开户银行名称前端展示值（为空时默认用account_bank字段）	-
account_name	string	否	账户名称，需要修改结算账户名称的时候传入，对公账户需要与公司名称一致，对私账户需要与法人姓名一致	-

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息

4. 枚举信息

Body.account_info.bank_account_type Enum

账户类型,企业类型只能绑定对公账户，个体工商户可以绑定对公或者对私账户

枚举值	描述
ACCOUNT_TYPE_BUSINESS	对公银行账户
ACCOUNT_TYPE_PRIVATE	经营者个人银行卡

5. 注意事项
每天允许修改结算账户的次数为5次；
结算账户需要与店铺的主体一致（对公为公司名称，对私为法人名称）。

bank_account_type账户类型

值	描述
ACCOUNT_TYPE_BUSINESS	对公银行账户
ACCOUNT_TYPE_PRIVATE	经营者个人银行卡

6. 代码示例

请求示例

{
{
    "account_info":{
        "bank_account_type" :"ACCOUNT_TYPE_PRIVATE",
        "account_bank":"招商银行",
        "bank_address_code":"100000",
        "account_number":"1234567890"   
    }
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}


7. 错误码

此接口没有特殊错误码，可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

8. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
