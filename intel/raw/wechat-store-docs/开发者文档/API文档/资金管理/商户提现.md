商户提现

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：submitwithdraw

可通过该接口进行商户提现

相关事件回调：

提现回调
提现二维码回调

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/funds/submitwithdraw?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.funds.submitwithdraw

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：138

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明
amount	number	是	1	提现金额（单位：分）
remark	string	否	sss	提现备注
bank_memo	string	否		银行附言

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
withdraw_id	string	wd16240447585462408433	二维码ticket,可用于获取二维码和查询二维码状态
qrcode_ticket	string	xxxxx	提现单号

4. 注意事项

每天最多允许提现一次。

5. 代码示例

请求示例

{
    "amount": 1,
    "remark": "sss",
    "bank_memo": ""
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "withdraw_id": "wd16240447585462408433",
    "qrcode_ticket": "xxxxx"
}


6. 错误码

此接口没有特殊错误码，可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
