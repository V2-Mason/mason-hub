获取资金流水列表

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getfundsflowlist

可通过该接口获取资金流水列表。当日资金流水出账时间为次日16点后，先用后付订单需用户确认收货自动付款后才会产生资金流水。

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/funds/getfundsflowlist?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.league.funds.getfundsflowlist

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：138、141

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明
page	number	否	1	页码，从1开始
page_size	number	否	10	页数，不填默认为10
next_key	string	否	CAAQABgBIhExMDAwMDA0MTU3MzIyMTEwOSiflq+bBg==	分页参数，翻页时写入上一页返回的next_key(page为上一页加一，并且page_size与上一页相同的时候才生效)，page * page_size >= 10000时必填
start_time	number	否	1668008734	流水产生的开始时间，uinx时间戳
end_time	number	否	1668008737	流水产生的结束时间，unix时间戳。当日资金流水出账时间为次日16点后，因此16点前end_time最大值为前1天的0点0分0秒，16点后end_time最大值为当天0点0分0秒。如果end_time超过最大值将按最大值进行查询。
transaction_id	string	否	4200001619202211090964182530	支付单号

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
flow_ids	array		流水单号列表
has_more	boolean	true	是否还有下一页
next_key	string	CO0GEGQY2vQFIhI1MTAwMDAxNDQ3NDgyMTEwMjEo7rfFiwY=	分页参数，深翻页时使用

4. 注意事项

本接口无特殊注意事项

6. 错误码

此接口没有特殊错误码，可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
