获取资金流水详情

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getfundsflowdetail

可通过该接口获取资金流水详情

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/funds/getfundsflowdetail?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.funds.getfundsflowdetail

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：138、141

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明
flow_id	string	是	10000057741221110	流水id，可通过获取资金流水列表获取

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
funds_flow	object		流水信息

Res.funds_flow Object Payload

流水信息

参数名	类型	说明	枚举
flow_id	string	流水id	-
funds_type	number	资金类型	枚举值
flow_type	number	流水类型, 1 收入，2 支出	-
amount	number	流水金额	-
balance	number	余额	-
related_info_list	objarray	流水关联信息	-
bookkeeping_time	string	记账时间	-
remark	string	备注	-
funds_type_desc	string	资金类型描述	-

Res.funds_flow.related_info_list(Array) Object Payload

流水关联信息

参数名	类型	说明
related_type	number	关联类型, 1 订单， 2售后，3 提现，4 运费险， 5 服务保障， 6 送礼物, 7 群送礼关联订单号列表, 8 同城配送门店 id
order_id	string	关联订单号
aftersale_id	string	关联售后单号
withdraw_id	string	关联提现单号
bookkeeping_time	string	记账时间
insurance_id	string	关联运费险单号
transaction_id	string	关联支付单号
guarantee_id	number	关联保障单号
present_id	number	关联礼物单号
group_present_sub_order_id_list	string	群送礼关联订单号列表（群礼物与订单之间是一对多关系，因此多个订单号通过","来分隔）
intra_city_shop_id	number	同城配送门店 id
