查询城市列表

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：ecgetcity

可通过该接口查询省份的所有城市

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/shop/funds/getcity?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：85、138

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
province_code	number	是	省份编码

3. 返回参数
返回体 Response Payload
参数名	类型	说明
data	objarray	城市信息列表
total_count	number	总数
errmsg	string	错误信息
errcode	number	错误码

Res.data(Array) Object Payload

城市信息列表

参数名	类型	说明
city_name	string	城市名称
city_code	number	城市编号(获取支行参数)
bank_address_code	string	开户银行省市编码

4. 注意事项

本接口无特殊注意事项

5. 代码示例

请求示例

{
  "province_code": 1,
}




返回示例

{
  "data": [
    {
      "bank_address_code": "110000",
      "city_code": 10,
      "city_name": "北京市"
    }
  ],
  "total_count": 1,
  "errmsg": "ok",
  "errcode": 0
}
