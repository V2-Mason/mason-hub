获取库存流水

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getstockflow

通过该接口可以获取视频号小店的商品库存流水

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/product/stock/getflow?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

查询参数 Query String Parameters

库存流水

参数名	类型	说明	枚举
amount	number	操作数量	-

Res.data.stock_flow_info_list(Array).ext_info Object Payload

额外信息

参数名	类型	说明	枚举

move_to_stock_sub_type	number	分配的目标库存子类型，枚举值参考下文，该字段仅对仅对op_type=6生效	-
upload_source	number	操作来源，该字段仅对op_type=1/2/3生效	枚举值

limited_discount_id	number	限时抢购任务id，该字段仅对stock_sub_type=2生效	-
finder_id	string	达人的视频号finder_id，该字段仅对move_to_stock_sub_type=4和unmove_from_stock_sub_type=4生效	-

5. 注意事项
最多可以查今天往前180天内的数据。
库存回滚目前只会发生在以下场景：
下单后支付前取消订单
礼物单送出后未收下退款
售后换货取消

8. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
