删除商品

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：deleteproduct

可通过该接口删除微信小店商品（包括赠品）。审核中的商品（包括赠品）无法删除

删除在售赠品不会影响原商品。

相关事件推送：

商品更新事件通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/product/delete?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.product.delete

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
product_id	string	是	商品ID（赠品ID）

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息

4. 注意事项

本接口无特殊注意事项

5. 代码示例

请求示例

{
    "product_id": "324545"
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}


6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述
10020049	商品正在审核中，无法编辑或删除，请先调用撤回商品审核接口
10020050	无权限调用该api，请获取权限后再试
10020051	参数有误，请按照文档要求传参
10020052	商品不存在

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
