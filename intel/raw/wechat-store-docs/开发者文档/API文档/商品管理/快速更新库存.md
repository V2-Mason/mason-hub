快速更新库存

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：updatestock

可通过该接口快速更新微信小店商品的库存

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/product/stock/update?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.product.stock.update

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
product_id	string	是	内部商品ID
sku_id	string	是	内部sku_id
diff_type	number	是	修改类型。1: 增加；2:减少；3:设置。
建议使用1或2，不建议使用3，因为使用3在高并发场景可能会出现预期外表现
num	number	是	增加、减少或者设置的库存值。

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息

4. 注意事项
该接口仅对曾经上架成功过的商品，且商品草稿状态为非审核中（edit_status != 2 ）适用。本地生活商品不受此规则约束。
调用后立即生效。
库存回滚目前只会发生在以下场景：
下单后支付前取消订单
礼物单送出后未收下退款

5. 代码示例

请求示例

{
    "product_id": "324545",
    "sku_id": "9328425",
    "diff_type": 1,
    "num": 10
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}


6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述
10020050	没有商品权限，请获取权限后再试
10020051	参数错误，请开发者按照文档传参
10020052	商品不存在
10020054	更新库存失败
10020055	参数有误，请开发者按照文档传参
10020091	不支持该类型的商品
10020091	本接口暂不不支持此类型的商品
10020112	更新该sku库存频率超限
10020217	当前商品状态不允许直接更新库存
10020218	增加减少数量为0
10020219	库存不足以减扣
10020220	设置库存超过券码数量（本地生活商品）
10020289	该商品从未曾经上架成功过，不允许直接更新库存

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
