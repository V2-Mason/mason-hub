获取商品H5短链

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getproducth5url

通过该接口可以获取微信小店的商品H5短链，支持传入企业微信参数。通过带企业微信参数的短链下单的订单会在成交来源展示该企业。

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/product/h5url/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
product_id	string	是	商品ID
wecom_corp_id	string	否	小店通过关联账号绑定的企业微信id，获取方式见获取关联账号企微id
wecom_user_id	string	否	小店通过关联账号绑定的企业微信下的成员id，获取方式见获取关联账号企微id

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息
product_h5url	string	商品H5短链

4. 注意事项

本接口只支持对上架销售中的小店自营商品调用。

5. 代码示例

请求示例

{
    "product_id": "10000438718054"
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "product_h5url": "https://store.weixin.qq.com/shop/a/aZcJxBmsAw3BI6C"
}

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
