上架商品

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：listingproduct

通过该接口可将商品（包括非卖赠品）上架到微信小店。

相关事件推送：

商品审核事件通知
商品上下架事件通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/product/listing?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.product.listing

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明
product_id	string	是	1234234	商品ID（赠品ID）；

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息

4. 注意事项

商品上架查看：

商品有2份数据，草稿和线上数据 调用接口新增和修改商品数据后，影响的只是草稿数据，要调上架接口，并审核通过，草稿数据才会覆盖线上数据正式生效;

频繁调用上架接口，会被封禁。建议先检查下商品状态，如果在审核中就不要重复提交了;

当商品处于上传中的状态，即edit_status==7时，调用本接口会返回10020067错误码;

每个小店调用接口新增、更新商品次数会合并计算，限额可通过 获取商品提审限额 查询（频次将随着店铺经营表现动态提升，商家可前往“微信小店-店铺管理-店铺信息-成长陪伴”查看成长信誉的最新分值，了解店铺最新经营表现）。

商品新增或更新后撤回均会消耗次数;
已上架的商品仅更新“库存”，不消耗次数。

非卖赠品查看：

非卖赠品有2份数据，草稿和线上数据 调用接口新增和修改商品数据后，影响的只是草稿数据，要调上架接口，并审核通过，草稿数据才会覆盖线上数据正式生效;

频繁调用上架接口，会被封禁。建议先检查下商品状态，如果在审核中就不要重复提交了;

每个小店调用接口新增、更新商品次数会合并计算，限额可通过 获取商品提审限额 查询（频次将随着店铺经营表现动态提升，商家可前往“微信小店-店铺管理-店铺信息-成长陪伴”查看成长信誉的最新分值，了解店铺最新经营表现）。

赠品新增或更新后撤回均会消耗次数;
已上架的商品仅更新“库存”，不消耗次数。
