撤销类目审核

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：cancelauditcategory

该接口可通过审核id来对类目的审核进行撤销

相关事件通知：类目审核结果通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/shop/ec/category/audit/cancel?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.category.audit.cancel

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：85、129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
audit_id	string	是	提交审核时返回的id，申请类目接口获得

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息

4. 注意事项

本接口无特殊注意事项

5. 代码示例

请求示例

{
    "audit_id": "123456"
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}


6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述
10020006	不合法的审核id

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
