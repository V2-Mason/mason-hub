获取店铺的类目审核单详情

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getbizcatflowdetail

获取店铺的类目审核单详情

相关事件通知：类目审核结果通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/shop/ec/category/getbizcatflowdetail?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：85、129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明
audit_id	number	是	1234	审核单id

3. 返回参数
返回体 Response Payload
参数名	类型	说明
info	object	类目审核单详情
errcode	number	错误码
errmsg	string	错误信息

Res.info Object Payload

类目审核单详情

参数名	类型	说明
cat_id	number	类目id
status	number	审核单状态，1审核中，2审核驳回，3审核成功，4取消审核单
audit_id	number	审核单id
qua_id	number	资质id
create_time	number	创建时间
update_time	number	更新时间
audit_info	object	审核材料
audit_time	number	审核时间
audit_reason	string	驳回原因

Res.info.audit_info Object Payload

审核材料

参数名	类型	说明
level3	number	类目id
certificate	array	资质资料
brand_list	objarray	brand_list
baobeihan	array	报备函
jingyingzhengming	array	经营证明
jingyingpingtai	string	经营平台
zhanghaomingcheng	string	帐号名称
ruzhuzhizhi	array	入驻证明
daihuokoubei	array	带货口碑
jingyingliushui	array	经营流水
buchongcailiao	array	补充材料
license_group_list	objarray	证照信息
commitment_letter_list	array	承诺函
account_link	string	账号链接
is_new_apply_cat	boolean	是否为新版证照组申请流程

Res.info.audit_info.brand_list(Array) Object Payload

brand_list

参数名	类型	说明
brand_id	number	品牌id

Res.info.audit_info.license_group_list(Array) Object Payload

证照信息

参数名	类型	说明
license_group_id	number	证照组id
license	object	证照详细材料

Res.info.audit_info.license_group_list(Array).license Object Payload

证照详细材料

参数名	类型	说明

Res.info.audit_info.license_group_list(Array).license.license_field_listObject Payload

license_field_list
