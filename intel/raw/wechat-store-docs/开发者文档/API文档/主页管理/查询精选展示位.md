查询精选展示位

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getbanner

通过该接口可查询当前生效的精选展示位和流程中的申请。

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/basics/homepage/banner/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：129、131

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload

无

4. 枚举信息

Res.banner.scale Enum

当前生效的展示位的展示样式

以下参数使用相同枚举：

Res.apply.scale ： 展示位的展示样式
枚举值	描述
1	小图模式
2	大图模式

Res.apply.state Enum

申请状态

枚举值	描述
1	审核中
2	审核驳回

Res.banner.banner(Array).type Enum

展示位类型

枚举值	描述
1	商品
3	视频号
4	公众号

Res.apply.banner(Array).audit_state Enum

审核状态。具体参数内容可参考：1-审核中；2-审核驳回

枚举值	描述
1	审核中
2	审核驳回

Res.apply.banner(Array).banner.type Enum

展示位类型

枚举值	描述
1	商品
3	视频号
4	公众号

本接口无特殊注意事项

7. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述
268549675	既无生效中的精选展示位，也无流程中的申请。
268555516	无权限，仅供微信小店使用。

8. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
