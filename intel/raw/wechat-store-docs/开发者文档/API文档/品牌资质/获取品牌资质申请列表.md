获取品牌资质申请列表

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getbrandlistlogic

通过该接口可以获取品牌资质申请列表

相关事件通知：品牌资质事件通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/brand/list/get?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.brand.list.get

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：85、129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）

4. 枚举信息

Body.status Enum

审核单状态, 不填默认拉全部商品

枚举值	描述
0	默认值, 获取全部
1	审核中
2	审核失败
3	审核通过(包括即将过期和已过期)
4	已撤回

5. 注意事项
接口返回的是商家当前提交的品牌资质申请记录（草稿数据），如果要获取线上生效中的品牌资质，请使用获取生效中的品牌资质列表接口；
该接口返回的资质文件为file_id格式，开发者需自己维护file_id和文件的映射关系。

入参status取值说明

枚举值	描述
0	默认值, 获取全部
1	审核中
2	审核失败
3	审核通过(包括即将过期和已过期)
4	已撤回
