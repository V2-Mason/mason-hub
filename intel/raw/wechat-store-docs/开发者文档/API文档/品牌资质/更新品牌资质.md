更新品牌资质

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：updatebrandlogic

通过该接口可以更新品牌资质

相关事件通知：品牌资质事件通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/brand/update?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：85、129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息
audit_id	number	审核单ID, 提交审核成功后返回

4. 注意事项
调用该接口会进行提交审核，处于“审核中”状态的品牌不可重复提交，需要先调用撤回品牌资质审核接口撤销审核；
所有资质文件需要先调用上传资质图片接口上传资质图片。
授权品牌建议使用分级结构，通过use_split_grant_info字段区分，新旧结构区别详见结构中（旧结构）、（分级结构）标记。

7. 适用范围
