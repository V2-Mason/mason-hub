获取拒绝售后原因

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getaftersalerejectreason

通过该接口可以获取微信小店的拒绝售后原因

相关事件通知：售后单更新通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/aftersale/rejectreason/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：131

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload

无

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errmsg	string	错误信息
errcode	number	错误码
reason_list	objarray	售后拒绝原因列表

Res.reason_list(Array) Object Payload

售后拒绝原因列表

参数名	类型	说明	枚举
reject_reason_type	number	售后拒绝原因枚举	-
reject_reason_type_text	string	售后拒绝原因说明	-
reject_reason	string	售后拒绝原因默认描述	-
reject_scene	number	售后拒绝原因适用场景	枚举值

4. 枚举信息

Res.reason_list(Array).reject_scene Enum

售后拒绝原因适用场景

枚举值	描述
1	拒绝用户仅退款申请
4	拒绝用户退货退款申请
5	拒绝用户换货申请
6	拒绝换货发出新商品
7	商家处理极速换货收货

5. 注意事项

调用接口时传空的json串即可。

7. 错误码

此接口没有特殊错误码，可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

8. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
