电子面单取消下单

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：ewaybill_cancelorder

可通过该接口取消已取号的电子面单

相关文档： 微信小店「电子面单操作」使用指南

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/logistics/ewaybill/biz/order/cancel?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：130、159、192

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
ewaybill_order_id	string	是	电子面单订单id，全局唯一id
delivery_id	string	是	快递公司id
waybill_id	string	是	快递单号

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息
delivery_error_msg	string	快递公司错误码

4. 注意事项

本接口无特殊注意事项

5. 代码示例

请求示例

{
   "ewaybill_order_id":"1212",
   "delivery_id":"xxx",
   "waybill_id":"xxxx"
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "delivery_error_msg":"xxxx"
}


6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述
10025006	取消下单失败，具体原因参考delivery_error_msg字段
10025010	电子面单不存在
10025011	更新冲突，请稍后重试
10025012	快递公司ID错误,请检查delivery_id
10025020	EWaybill Order ID 的数据内容是Uint64,用字符串传递参数,请确认是否正确
10025030	取消请求快递公司接口超时，可稍后重试
10025031	快递公司接口异常，可稍后重试
10025032	快递公司接口异常，可能存在故障，可稍后重试
10025033	快递公司接口繁忙，可稍后重试
10025035	快递公司的接口不可用，可稍后重试
