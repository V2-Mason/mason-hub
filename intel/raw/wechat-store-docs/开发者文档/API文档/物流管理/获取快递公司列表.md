获取快递公司列表

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getdeliverycompanylistnew

可通过该接口获取快递公司列表

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/deliverycompanylist/new/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：131、192

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明
ewaybill_only	boolean	是	false	是否仅返回支持电子面单功能的快递公司

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
company_list	objarray		快递公司列表

Res.company_list(Array) Object Payload

快递公司列表

delivery_name	string	顺丰速运	快递公司名称	-
