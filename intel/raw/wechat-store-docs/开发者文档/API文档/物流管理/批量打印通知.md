批量打印通知

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：ewaybill_batchprintorder

商家电子面单调用打印组件成功出单后，批量通知平台出单结果

相关文档： 微信小店「电子面单操作」使用指南

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/logistics/ewaybill/biz/order/batchprint?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：130、159、192

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
req_list	objarray	是	订单信息

Body.req_list(Array) Object Payload

订单信息

参数名	类型	必填	说明
ewaybill_order_id	string	是	电子面单订单id，全局唯一id
delivery_id	string	是	快递公司id
waybill_id	string	是	快递单号
re_print	number	是	1 补打单成功 0 首次打单成功

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息
succ_ewaybill_order_id	array	成功的单号
fail_ewaybill_order_id	array	失败的单号

4. 注意事项

本接口无特殊注意事项

5. 代码示例

请求示例

{
	"req_list": [{
		"ewaybill_order_id": "1212",
		"delivery_id": "xxx",
		"waybill_id": "xxxx",
		"re_print": 0
	}]
}


返回示例

{
	"errcode": 0,
	"errmsg": "ok",
	"succ_ewaybill_order_id": ["1111", "222"],
	"fail_ewaybill_order_id": ["1111", "222"]
}
