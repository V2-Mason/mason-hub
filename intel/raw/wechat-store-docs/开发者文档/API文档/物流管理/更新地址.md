更新地址

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：updateaddress

可通过该接口更新地址

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/merchant/address/update?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.merchant.address.update

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：130、192

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
address_detail	object	是	地址信息

Body.address_detail Object Payload

地址信息

参数名	类型	必填	说明
address_id	number	是	地址id
name	string	是	联系人姓名
address_info	object	是	地区信息
landline	string	否	座机
send_addr	boolean	是	是否为发货地址
default_send	boolean	是	是否为收货地址
recv_addr	boolean	是	是否为默认发货地址
default_recv	boolean	是	是否为默认收货地址
create_time	number	是	创建时间戳（秒）
update_time	number	是	更新时间戳（秒）
address_type	object	是	线下配送地址类型

Body.address_detail.address_info Object Payload

地区信息

参数名	类型	必填	说明
user_name	string	是	收货人姓名
postal_code	string	是	邮编
province_name	string	是	国标收货地址第一级地址，可调用获取地址编码获取
city_name	string	是	国标收货地址第二级地址，可调用获取地址编码获取
county_name	string	是	国标收货地址第三级地址，可调用获取地址编码获取
detail_info	string	是	详细收货地址信息
national_code	string	否	收货地址国家码
tel_number	string	否	收货人手机号码
lat	number	是	纬度
lng	number	是	经度
house_number	string	否	门牌号

Body.address_detail.address_type Object Payload

线下配送地址类型

参数名	类型	必填	说明
same_city	number	否	1:表示同城配送
pickup	number	否	1:表示用户自提

3. 返回参数
返回体 Response Payload
参数名	类型	说明
errcode	number	错误码
errmsg	string	错误信息

4. 注意事项

本接口无特殊注意事项
