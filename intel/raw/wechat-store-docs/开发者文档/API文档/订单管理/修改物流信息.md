修改物流信息

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：changedeliveryinfo

可通过该接口修改物流信息。

注：订单未完成状态下调用changedeliveryinfo接口最多可以允许修改三次物流信息

相关事件通知：订单其他信息更新

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/deliveryinfo/update?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.order.deliveryinfo.update

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：131

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

查询参数 Query String Parameters

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息

4. 注意事项
发货完成的订单可以修改，最多修改1次；
拆包发货的订单暂不允许修改物流；
虚拟商品订单暂不允许修改物流。

5. 代码示例

请求示例

{
	"order_id": "12345",
	"delivery_list": [{
		"delivery_id": "EMS",
		"waybill_id": "1234",
		"deliver_type": 1,
		"product_infos": [{
			"product_cnt": 1,
			"product_id": "112233",
			"sku_id": "445566"
		}]
	}]
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}


6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述
40097	请求体参数不正确，请检查各个参数是否按规范填写，具体原因请查看errmsg
47001	请求体格式不正确，请检查请求体中各个参数的类型是否正确
48001	无权调用本api，请开发者获取权限后再试
100002	 订单不存在
100003	订单更新过于频繁，更新订单失败，请重试
101100	 当前订单状态不允许发货，请检查订单状态
606004	delivery_id不合法，请使用获取快递公司列表接口获取delivery_id
606005	waybill_id不合法，请检查waybill_id是否填写有误

606040	拆单发货暂不支持修改物流
606041	修改物流次数已达上限
606042	商品信息有误，请检查商品id，商品数量是否正确
6060479	快递单号与物流公司提供的正则表达式不匹配 

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
