解密订单中的详细收货信息

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：decodesensitiveinfo

为保护用户隐私（如收货人昵称、电话号码、详细收货地址），平台订单的收货信息进行了部分隐藏。通过本接口操作订单后，可以获取到这些信息的完整数据。

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/sensitiveinfo/decode?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：131

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters

access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）

参数名	类型	必填	示例	说明

4. 注意事项

当订单处于以下状态时不可申请解密：①订单未满足履约条件（包括但不限于：订单待付款、“一起买”待成团）；②订单已取消；③订单已完成且不在售后期。

解密操作对订单数量有严格限制，请合理调用，避免不必要的重复请求。超出限制将导致接口报错。对同一订单的多次调用，系统仅计算一次额度。

平台结合商家的过往经营及风险情况等，赋予商家解密额度，解密额度每日0点更新。若当日解密额度无法满足商家的合理使用需要，可通过微信小店商家后台申请临时额度。详情见订单信息解密功能使用指引。

解密后将默认下发虚拟号，通过virtual_number_info字段返回。虚拟号规则详情见微信小店「虚拟号码」使用指南。为满足各类使用场景，提供虚拟号延期、再次申请虚拟号、申请查看真实手机号等能力，请按需接入和使用：①订单虚拟号延期，②订单再次申请虚拟号，③申请查看订单真实号码。

应监管要求，在拨打虚拟号前，主叫号码需前往运营商完成实名认证，认证后即可拨打。未认证将呼叫失败。详情见微信小店「虚拟号」主叫号码实名认证指引。采用虚拟号时，请务必适配认证的相关接口：①获取短信验证码，②添加待认证的手机号，③获取小店手机号认证状态。

6. 错误码

以下是本接口的错误码列表，其他错误码可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

错误码	错误描述
10020123	订单解码数达到当月限制
10020124	未完成支付的订单不支持API解码操作
10020198	订单敏感信息解密过快，请稍后重试
10020248	礼物订单不支持查看详细收货信息
10020501	基于用户隐私保护，无法解密
10020502	解密失败, 根据微信小店订单信息解密规则，当前无法查看用户收货信息，详情可前往违规中心进行查询。请使用官方发货工具完成发货
10020503	当前订单状态不支持解密（如订单待付款 / 已取消 / 已完成且不在售后期）
10020503	订单不存在，请检查订单id与token是否正确
10020506	质检订单不支持查看详细收货信息

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
