修改订单地址

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：changeorderaddress

可通过该接口对订单地址进行修改，提交修改后将进入「协商」流程，需要买家同意后方可修改成功，具体规则详见：微信小店「代改址协商」使用指南。用户协商结果将以事件推送通知。

相关事件通知： 订单其他信息更新

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/order/address/update?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.order.address.update

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：131

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
order_id	number	是	订单id，可通过获取订单列表接口获取
user_address	object	是	新地址

Body.user_address Object Payload

新地址

参数名	类型	必填	说明
user_name	string	否	收货人姓名，订单deliver_method=0必填
postal_code	string	否	邮编
province_name	string	否	省份，订单deliver_method=0必填
city_name	string	否	城市，订单deliver_method=0必填
county_name	string	否	区
detail_info	string	否	详细地址，订单deliver_method=0必填
national_code	string	否	国家码
tel_number	string	否	普通订单联系方式，订单deliver_method=0必填
house_number	string	否	门牌号码
virtual_order_tel_number	string	否	虚拟商品订单联系方式，虚拟商品订单必填(deliver_method=1)

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息

4. 注意事项

未发货的订单可以修改，次数限制为5次。

5. 代码示例

请求示例

{
    "order_id": "123456",
    "user_address": {
        "user_name": "陈先生",
        "postal_code": "2435245",
        "province_name": "广东",
        "city_name": "广州",
        "county_name": "海珠区",
        "detail_info": "大塘",
        "national_code": "234234",
        "tel_number": "24534252"
    }
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
