获取店铺人群数据

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getshopsaleprofiledata

通过该接口可获取店铺人群数据。（仅历史数据，暂无当日数据）

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/compass/shop/sale/profile/data/get?access_token=ACCESS_TOKEN

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：175

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明	枚举
ds	string	是	20240520	日期，格式YYYYMMDD	-
type	number	是	1	用户类型	枚举值

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
data	object		店铺人群数据

Res.data Object Payload

店铺人群数据

参数名	类型	说明
field_list	objarray	维度列表

Res.data.field_list(Array) Object Payload

维度列表

参数名	类型	说明
field_name	string	维度类别名
data_list	objarray	指标

Res.data.field_list(Array).data_listObject Payload

指标

参数名	类型	说明
dim_key	string	维度指标名
dim_value	string	维度指标值

4. 枚举信息

Body.type Enum

用户类型

枚举值	描述
1	商品曝光用户
2	商品点击用户
3	购买用户
4	首购用户
5	复购用户

5. 注意事项

本接口无特殊注意事项
