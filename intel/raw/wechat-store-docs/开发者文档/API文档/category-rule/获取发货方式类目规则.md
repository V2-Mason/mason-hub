获取发货方式类目规则

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：get_delivery_method_category_rule

获取类目规则。

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/shop/ec/category/getcategoryrule?access_token=ACCESS_TOKEN&rule_id=2

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：85、129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
rule_id	number	是	2	规则id，发货方式为2
请求体 Request Payload
参数名	类型	必填	示例	说明
category_id	number	是	123	类目id

3. 返回参数
返回体 Response Payload
参数名	类型	说明
list	objarray	-
errcode	number	-
errmsg	string	-

Res.list(Array) Object Payload
参数名	类型	说明	枚举
deliver_type	number	发货方式	枚举值
acct_type	numarray	支持的账号类型	枚举值

4. 枚举信息

Res.list(Array).deliver_type Enum

发货方式

枚举值	描述
0	快递
1	教培类
3	卡券类
4	游戏角色
5	游戏帐号
6	同城配送

Res.list(Array).acct_type Enum

支持的账号类型

枚举值	描述
1	微信号
2	QQ
3	手机号
4	邮箱

5. 注意事项

本接口无特殊注意事项

6. 代码示例

请求示例

{
    "category_id": 123
}


返回示例

{
    "list": {
        "deliver_type": 0,
        "acct_type": [
            0
        ]
    },
    "errcode": 0,
    "errmsg": ""
}


7. 错误码

此接口没有特殊错误码，可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

8. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
