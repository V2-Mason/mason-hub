获取保证金类目规则

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：get_category_rule

本接口用于获取保证金类目规则

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/shop/ec/category/getcategoryrule?access_token=ACCESS_TOKEN&rule_id=1

云调用
本接口不支持云调用。
第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：85、129

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
rule_id	number	是	1	规则id，保证金填1
请求体 Request Payload
参数名	类型	必填	示例	说明
category_id	number	是	10001	类目id

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
deposit	number	1000000	保证金，单位：分

4. 注意事项

获取店铺在这个类目下的保证金，rule_id请填写1

5. 代码示例
5.1 请求示例

请求示例

{
    "category_id": 10001
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}

5.2 请求示例

请求示例

{
    "category_id": 10001
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "deposit": 1000000
}


6. 错误码

此接口没有特殊错误码，可参考 通用错误码；调用接口遇到报错，可使用官方提供的 API 诊断工具 辅助定位和分析问题。

7. 适用范围

本接口支持「微信小店」账号类型调用。其他账号类型如无特殊说明，均不可调用。
