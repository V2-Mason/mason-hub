批量新增联盟商品

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：batchadditem

可通过该接口批量新增联盟商品

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/league/item/batchadd?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.league.item.batchadd

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：141

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明	枚举
type	number	是	获取商品推广类别	枚举值
list	objarray	是	商品列表	-
finder_ids	array	否	推广达人列表，不超过30个，待废除后续以promoter_ids为准（类别为特殊推广商品时和promoter_ids二选一填）	-
begin_time	number	否	推广开始时间戳	-
end_time	number	否	推广结束时间戳	-
is_forerver	boolean	否	是否永久推广	-
promoter_ids	array	否	达人带货id列表，不超过30个（类别为特殊推广商品时和finder_ids二选一填）	-

Body.list(Array) Object Payload

商品列表

参数名	类型	必填	说明
product_id	number	是	商品id，不可重复数量不超过20
ratio	number	否	推广佣金[0, 90]%，操作为编辑时必填

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
result_info_list	objarray		信息

Res.result_info_list(Array) Object Payload

信息

参数名	类型	说明
errcode	number	单个商品添加错误码
errmsg	string	单个商品错误信息
info_id	number	特殊推广商品计划id
product_id	number	商品id
fail_finder_ids	array	推广失败视频号达人列表
fail_promoter_ids	array	推广失败达人列表

4. 枚举信息

Body.type Enum

获取商品推广类别

枚举值	描述
1	普通推广商品
2	定向推广商品
3	专属推广商品

5. 注意事项

本接口无特殊注意事项
