更新联盟商品信息

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：upditem

可通过该接口更新联盟商品信息

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/league/item/upd?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.league.item.upd

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：141

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明	枚举
type	number	是	获取商品推广类别	枚举值
product_id	number	否	商品id，可从获取联盟商品推广列表接口中获取，type为普通推广商品时必填	-
info_id	number	否	特殊推广商品计划id，type为特殊推广商品时必填	-
operate_type	number	是	更新操作类别	枚举值
ratio	number	否	推广佣金[0, 90]%，操作为编辑时必填	-
exclusive_info	object	否	特殊推广信息，类别为特殊推广商品且操作为编辑时必填	-

Body.exclusive_info Object Payload

特殊推广信息，类别为特殊推广商品且操作为编辑时必填

参数名	类型	必填	说明
begin_time	number	否	推广开始时间戳
end_time	number	否	推广结束时间戳
add_finder_ids	array	否	用于新增推广视频号达人列表，不超过30个
del_finder_ids	array	否	删除推广视频号达人列表，不超过30个
is_forerver	boolean	否	是否永久推广
add_promoter_ids	array	否	用于新增推广达人列表，不超过30个
del_promoter_ids	array	否	删除推广达人列表，不超过30个

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
info_id	number	134	特殊推广商品计划id

4. 枚举信息

Body.type Enum

获取商品推广类别

枚举值	描述
1	普通推广商品
2	定向推广商品
3	专属推广商品

Body.operate_type Enum

更新操作类别

枚举值	描述
1	编辑并上架
2	下架
4	上架

5. 注意事项

type获取商品推广类别

枚举值	描述

operate_type更新操作类别

枚举值	描述
1	编辑并上架
2	下架
3	上架

6. 代码示例

请求示例

{
    "type": 2,
    "info_id": 123,
    "operate_type": 1,
    "ratio": 60,
    "exclusive_info": {
        "begin_time": 1100,
        "end_time": 3000,
        "add_finder_ids": [
            "finder_id_01"
        ],
        "del_finder_ids": [
            "finder_id_02"
        ]
    }
}


返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "info_id": 134
}

8. 适用范围

本接口支持「微信小店（需申请）」账号类型调用。其他账号类型如无特殊说明，均不可调用。
