获取联盟商品详情

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getitem

可通过该接口获取联盟商品详情

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/league/item/get?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.league.item.get

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：141

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	说明
type	number	是	获取商品推广类别
product_id	number	否	商品id,，ype为普通推广商品时必填
info_id	number	否	特殊推广商品计划id，type为特殊推广商品时必填
need_relation	boolean	否	是否获取特殊推广商品绑定的达人列表， type为特殊推广商品时有效
page_index	number	否	need_relation为真时有效，页面下标，下标从1开始，默认为1
page_size	number	否	获取达人数 不超过50，need_relation为真时必填
need_total_num	boolean	否	need_relation为真时有效，是否需要返回该计划绑定达人总数

3. 返回参数
返回体 Response Payload
参数名	类型	示例	说明
errcode	number	0	错误码
errmsg	string	ok	错误信息
item	object		推广商品信息

Res.item Object Payload

推广商品信息

参数名	类型	说明	枚举
product_id	number	商品id	-
type	number	商品推广类别	枚举值
status	number	商品推广状态	枚举值
ratio	number	推广佣金[0, 90]%	-
exclusive_info	object	特殊推广信息	-
ext_info	object	扩展信息	-

Res.item.exclusive_info Object Payload

特殊推广信息

参数名	类型	说明
info_id	number	特殊推广商品计划id
finder_num	number	推广达人数量
finder_info_list	objarray	推广达人视频号列表信息，待废除后续以promoter_id为准
promoter_info_list	objarray	推广达人列表信息

Res.item.exclusive_info.finder_info_list(Array) Object Payload

推广达人视频号列表信息，待废除后续以promoter_id为准

参数名	类型	说明
finder_id	string	推广达人视频号id
begin_time	number	推广开始时间戳
end_time	number	推广结束时间戳
is_forerver	number	是否永久推广

Res.item.exclusive_info.promoter_info_list(Array) Object Payload

推广达人列表信息

参数名	类型	说明
promoter_id	string	推广达人带货id
begin_time	number	推广开始时间戳
end_time	number	推广结束时间戳
is_forerver	boolean	是否永久推广

Res.item.ext_info Object Payload

扩展信息

参数名	类型	说明
is_sale_forbidden	boolean	是否类目禁售
is_banned	boolean	是否被官方封禁

4. 枚举信息

Res.item.type Enum

商品推广类别

枚举值	描述
1	普通推广商品
2	定向推广商品
3	专属推广商品

Res.item.status Enum

商品推广状态

枚举值	描述
1	已上架推广
2	已下架推广
4	已删除
5	未达到准入标准
10	待生效

5. 注意事项

本接口无特殊注意事项
