获取用户优惠券详情

接口应在服务器端调用，不可在前端（小程序、网页、APP等）直接调用，具体可参考接口调用指南。

接口英文名：getusercoupon

通过此接口可获取用户优惠券详情。

相关事件通知：

用户优惠券过期通知
优惠券返还通知
优惠券核销通知

1. 调用方式
HTTPS 调用
POST https://api.weixin.qq.com/channels/ec/coupon/get_user_coupon?access_token=ACCESS_TOKEN

云调用

调用方法：channels.ec.coupon.getUserCoupon

出入参和 HTTPS 调用相同，调用方式可查看 云调用 说明文档。

第三方调用

本接口支持第三方平台代微信小店商家调用。第三方服务商调用模式介绍

该接口所属的权限集 id 为：132

服务商获得其中之一权限集授权后，可通过使用 authorizer_access_token 代微信小店商家进行调用，具体可查看 第三方调用 说明文档。

2. 请求参数
查询参数 Query String Parameters
参数名	类型	必填	示例	说明
access_token	string	是	ACCESS_TOKEN	接口调用凭证，可使用 access_token（微信小店商家）、authorizer_access_token（服务商代调用）
请求体 Request Payload
参数名	类型	必填	示例	说明
user_coupon_id	string	是	109694341	用户优惠券ID
openid	string	是	OPENID	用户openid

3. 返回参数
返回体 Response Payload
参数名	类型	说明
user_coupon_list	objarray	user_coupon_list
errcode	number	错误码
errmsg	string	错误信息，errcode为0不返回
openid	string	openid
unionid	string	用户unionid，小店接入open平台后生成的用户券会返回

Res.user_coupon_list(Array) Object Payload

user_coupon_list

参数名	类型	说明	枚举
user_coupon_id	string	用户优惠券ID	-
coupon_id	string	优惠券ID	-
status	number	优惠券状态	枚举值
create_time	number	优惠券派发时间	-
update_time	number	优惠券更新时间	-
end_time	number	优惠券失效时间	-
ext_info	object	ext_info	-
start_time	number	优惠券生效时间	-
order_id	string	优惠券使用的订单id	-
discount_fee	number	优惠券金额	-

Res.user_coupon_list(Array).ext_info Object Payload

ext_info

参数名	类型	说明
use_time	number	优惠券核销时间

4. 枚举信息

Res.user_coupon_list(Array).status Enum

优惠券状态

枚举值	枚举字段	枚举解释
100	COUPON_USER_STATUS_VALID	生效中
101	COUPON_USER_STATUS_EXPIRED	已过期
102	COUPON_USER_STATUS_USED	已使用

5. 注意事项

本接口无特殊注意事项
