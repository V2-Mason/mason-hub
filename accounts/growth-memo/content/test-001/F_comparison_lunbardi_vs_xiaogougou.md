# F 对比 | 伦巴第宝姐 vs 狗勾 — 真正对称的双样本 Grid 分析

**对比基础**：两个创作者都走完了完整的 `creator-hit-factor-grid` skill 流程（29 × 6 和 93 × 6 两张网格），每条视频都按 6 个 check 打 PASS/FAIL，所以这次对比是数据对称的，不是"一边数据一边二手归纳"。

## 2. 爆款公式对比

### 伦巴第宝姐（29 视频）
```
爆款 = (C5 题材已出圈) ∧ (C4 争议开场)

必要条件 2 个，都必须满足。
C2 具名 + C6 数据密度是她的底层能力（每条必用），不是 differentiator。
```

### 狗勾（93 视频）
```
爆款 = (路径 A 故事型) OR (路径 B 长尾型)

路径 A：C2 具名主角 ∧ 故事开场 (恰饭方法论的网红甲乙丙 / 特厨随坡事件)
路径 B：系列名 ∧ 常青平台查询词 (preset 当前测不到)

C5 题材出圈不是关键，C4 争议感只是弱相关。
```

## 3. 两个"唯一强规律"截然相反

| 创作者 | 唯一强规律 | Δ | 含义 |
|---|---|---|---|
| 伦巴第宝姐 | C5 题材已出圈 | **+83%** | 必须蹭大众热点 |
| 狗勾 | C2 具名主角 | **+47%** | 必须锚定具体人物/案例 |

**这不是细微差异，是两种完全不同的创作操作系统**：
- 伦巴是**事件响应型**：每周盯热点，把当期出圈的题材变成 10 分钟快速拆解
- 狗勾是**知识沉淀型**：把行业深度洞察写成系列方法论，让观众反复回来查

---

## 4. C1 反差开场：为什么在两人身上是相反信号

### 伦巴
- 前财经记者，习惯用"极端数据 + 反差对比"开场（符合财经媒体标准做法）
- 爆款 100% PASS C1，但 BOT 也 67% PASS，所以只是弱正相关
- 她的爆款开场**模板**：
  - "人口只有 5000 万，活跃股票账户超过 9000 万个"
  - "仅凭是或否两个简单的选项，硬生生造就出了一个新市场"

### 狗勾
- 前 MCN 商业化岗位，习惯用"系列锚点 + 故事开场"
- TOP 只有 26% 用反差数据开场，反而 MID/BOT 更多尝试
- 爆款**模板**：
  - "大家好我是网红小狗狗，欢迎来到第一期恰饭方法论"（系列锚点）
  - "朋友们，有一说一啊，在 MCN 待久了你真的觉得网红们的世界很魔幻，先给大家八卦三个行业故事吧"（故事开场）

**解读**：**两人的开场工具箱完全不同**。伦巴的工具箱里"反差数据"是必须用的老工具；狗勾的工具箱里"系列名+故事"才是核心，反差数据只是偶尔用。

## 5. C2 具名主角：对伦巴是 baseline 对狗勾是 differentiator

### 伦巴 29 视频里 C2 100% PASS
她是前财经记者，天生会用"合肥/白银/美联储/Polymarket/老铺黄金/Pyzer/Hyperliquid"这种具名实体开场。**这是她的肌肉记忆**，不是爆款因子。

### 狗勾 93 视频里 C2 只有 56% PASS
她有两类视频：
- **具名型**（56%）：网红甲乙丙 / 章小蕙董洁 / 刘畊宏 / 奥迪 / 中血糕 / 特厨隋坡
- **抽象型**（44%）：话疗系列 / vlog / 直播回放 / "如何做恰饭" 这种纯方法论

→ 具名型就在 TOP，抽象型就在 BOT，分化明显。
→ **对狗勾**，有没有具名是**她是不是在认真做这条视频**的信号。对伦巴，那是入场券。

## 6. C5 题材出圈：两人的最大战略差异

### 伦巴（+83%，最强规律）
- TOP 6 条全部是"发布前 2 周大众视野有的事"
- 合肥（春晚）/ 白银牛市 / 美联储换人 / 国产 GPU / 韩国赌徒 / 合法赌场
- **她的爆款完全由当期热点驱动**

### 狗勾（+16%，弱规律）
- TOP 19 里只有 4 条蹭大众热点
- 百大入驻抖音 / 刘畊宏 / MBTI / 中血糕
- **其他 15 条爆款都不蹭热点**，靠行业深度 + 系列长尾爆

**这个差异最有启发意义**：
- 如果你是**热点响应型创作者**（伦巴路线），选题阶段必须问"前 2 周这事大众知道吗"
- 如果你是**知识沉淀型创作者**（狗勾路线），完全不需要蹭热点，靠系列名+常青查询词+具名案例爆

## 7. 两人的 TOP outliers

### 伦巴 BV15wEXzqE6d 特朗普币（1,434 views, C1-C6 全 PASS）
- 发布 2025-05（账号早期）
- hook 质量满分但 views 1.4k
- **原因**：早期粉丝基数 + 可能的算法启动量不足

### 狗勾 BV1nB4y1K7yj 中血糕（4,127 views, C4+C5 都 PASS）
- 发布 2021-07（账号最早期）
- hook 质量超高（争议感+热点+数据密度都有）但 views 4k
- **原因**：早期粉丝基数不足

**两个 outlier 结构完全相同**：账号早期 hook 满分但因粉丝基数不够被压制。这验证了：

> **Hook 质量是爆款的必要非充分条件，还需要足够的粉丝基数/算法权重做放大器**

## 8. 这次对比对 `creator-hit-factor-grid` skill 的反思

### preset 层面
当前 `bilibili-creator.md` preset v0.1 **过度偏向财经型创作者**：
- C1 反差（偏向数据开场）
- C4 争议
- C5 热点出圈
- C6 数字密度

这 4 个对伦巴都有效，但对狗勾**大部分都弱或反向**。

### 需要的新 check
- **C7 系列索引**：标题是否含"第 X 期 / 一口气说完 / 深度观察 / 方法论 / 深扒"这种系列标记
- **C8 常青长尾查询**：标题是否含"平台名 + 如何/为什么/怎么"这种常青查询词
- **C9 具体案例锚点**：开场 60 秒有没有引入一个**具体人物/品牌**的故事（和 C2 重叠但更严格）

### 分型 preset
或许需要多个 preset：
- `bilibili-creator-heat-chase.md`（热点响应型，伦巴风格）
- `bilibili-creator-knowledge-base.md`（知识沉淀型，狗勾风格）
- 先用**分类器 check**（创作者更偏哪种）选 preset

## 9. 对 Mason / Growth Memo 的可抄手法清单

你的 Growth Memo 本质上是"独立开发者的方法论沉淀"，**更像狗勾，不像伦巴**。基于双样本网格的结论：

### 应该抄狗勾的（因为你走的是同一路线）

1. **起系列名**：起 2-3 个固定系列名（例如"独立开发复盘"/"副业数据周报"/"产品拆解案例"），每期视频打系列 tag
2. **用具名案例开场**：不是"最近独立开发越来越难"，而是"我朋友 XX 做了 3 个月 AI 工具，赚了 X 元，但他踩了 3 个坑..."
3. **常青长尾查询词放标题**：标题里必须含"独立开发 / 副业 / 个人项目 / AI 工具"这种未来几年都会被搜的词
4. **不要做话疗/vlog/闲聊**：狗勾的话疗 6 期全部 BOT
5. **每条视频锚定 1 个具体人/项目**：不要"一般来说" / "大多数"
6. **不需要蹭热点**：狗勾 TOP 79% 不蹭热点

### 不应该抄伦巴的（虽然她的数据很漂亮）

1. ~~反差数据开场~~（对你的赛道不是强信号）
2. ~~题材必须蹭大众热点~~（你的观众不来找热点）
3. ~~争议立场开场~~（你的赛道没那么多争议）

### 两人都验证的底层要求

1. **粉丝基数是 hook 质量的放大器**：早期视频即使 hook 满分也可能扑。需要熬 6-12 个月积累粉丝基础
2. **开场 60 秒决定生死**：两位创作者的爆款/非爆款分化都在开场
3. **具名 > 抽象**：对任何创作者来说，具体案例都比空泛概念转化率高

## 10. 对伦巴第宝姐旧 A/B 分析的修正

之前只用伦巴 29 视频做 A/B 时得出的结论**不能直接泛化**到所有 B 站创作者。那份结论的正确表述应该是：

> **"财经型/热点响应型的 B 站创作者"** 的爆款必要条件是 C4（争议）+ C5（出圈）

而不是：

> ~~"B 站创作者"的爆款必要条件~~

**这是 93 视频网格给出的关键修正**。没跑狗勾那张网格之前，我根本想不到同一个 preset 在不同赛道的创作者身上结论会**如此相反**。

1. **起草 Growth Memo 的固定系列名**（2-3 个候选）
2. **选 3-5 个常青长尾查询词放在未来视频标题里**
3. **把"话疗/vlog/闲聊"格式从 Growth Memo 的选项里划掉**

### 需要 skill 迭代
1. **扩 bilibili-creator preset**：加 C7（系列索引）+ C8（常青查询）
2. **或写 `bilibili-creator-knowledge-base.md` 新 preset**：专门给狗勾这类知识沉淀型用
3. **以后跑第三个创作者**（如 小 Lin 说 / 饭统戴老板 / 半佛仙人）再跑一张网格，验证这个双样本结论的普遍性

### 对 creator-hit-factor-grid skill 本身的教训
1. **N=29 的结论不能泛化**。双样本跑完才发现单样本结论的 preset 偏差
2. **preset 需要按创作者分型**，不是"B 站 = 一个 preset"
3. **首次用 preset 跑网格时必须做对照组验证**，否则结论可能把 preset 的偏差当成创作者的特征
