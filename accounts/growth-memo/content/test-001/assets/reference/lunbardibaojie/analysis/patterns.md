# 规律提炼 | 伦巴第宝姐 (29 videos, 6 checks)

## 强规律（Δ ≥ 0.5）

### 规律 1：C5 题材已出圈（最强，Δ=0.83）

**表述**：伦巴第宝姐的 hit（>16k）必须选"发布前 2 周内已进入大众视野"的题材。如果题材只在 Crypto/AI/专业圈内热，大众零认知，基本打不到 hit 量级。

**证据**：
- TOP 6/6 PASS: 合法赌场 71k / 合肥春晚 45k / 白银 24k / 美联储 23k / 国产 GPU 18k / 韩国赌徒 17k
- BOT 1/6 PASS: 只有 BV15wEXzqE6d 特朗普币（2025-05 outlier，见 hit_rate.md）
- BOT FAIL 5/6: x402、GEO、AI 优化（抽象）、金条美债（太远）、鸣鸣很忙（她自己承认"你可能没听过"）

**中腰区的检验**：
- MID 5 条 PASS: 十五五、内存涨价、比特币、伊朗、Polymarket
- 这 5 条没有一条突破 10k
- → 说明"题材出圈"是**必要条件**（不出圈必扑），但不是**充分条件**（出圈还得有其他）

**边界条件**：
1. 题材的"出圈度"有时效性。同一题材早发晚发结果差很多（比特币常年热但只拿到 3.7k，因为她当时角度没蹭到新闻钩子）
2. 题材在同一账号里**不能重复蹭**——BV1a51NB7E6r Polymarket 2025-10 发了 2k，BV1WfyVBxEB8 合法赌场 2025-11 再讲 Polymarket 反而 72k，中间一条 Polymarket 已经用过一次出圈红利
3. "出圈"不等于"标题里有热点词"。真正的判据是观众"前 2 周刷过这个题材"

### 规律 2：C4 争议感/反直觉（强，Δ=0.67）

**表述**：伦巴第宝姐的 hit 必须在开场 60 秒内表达至少一个"和常识不同 / 有人反对 / 二元选择"的立场或疑问。平铺叙事式开场基本不可能击中 hit。

**证据**：
- TOP 6/6 PASS:
  - "国产 GPU 到底行不行"（选边）
  - "比黄金涨得更疯... 历史会不会重演"（反直觉+疑问）
  - "美联储百年一遇的权力变局"（冲突）
  - "合肥小透明省会 → 中国硬科技之都"（反转）
  - "合法赌场 vs 博彩... Polymarket 坚决否认"（对立）
  - "韩国全民皆赌徒 vs 发达国家形象"（反直觉）
- BOT 2/6 PASS（不足以解释 BOT 低表现）
- BOT 4/6 FAIL: x402、金条美债、AI 优化、鸣鸣很忙——全陈述式开场

**中腰区的检验**（这条规律的强项）：
- MID C4 PASS 6 条 → mean views 5,672
- MID C4 FAIL 11 条 → mean views 3,254
- **差 1.7 倍**，在 MID 内部也有二次区分力
- → 争议感是"全量级可用"的规律，不只是突破门槛，也能让腰部多拿 1-2k 流量

**边界条件**：
1. 争议感 ≠ 吐槽 ≠ 爆粗。它是**对立立场的陈述**，而不是情绪表达
2. "我们今天来聊" "为什么 XX" 这种主持人套话不算
3. 有效的争议感句式：
   - "X 到底行不行"
   - "A 还是 B"
   - "为什么 XX 却 YY"
   - "是不是...的时候了"
   - "颠覆 / 反转 / 其实"

## 弱规律（0.33 ≤ Δ < 0.5，不够强，仅作观察）

### C1 反差/极端开场（Δ=0.33）
- TOP 100% / BOT 67%
- 太多 mid 和 bot 也有反差（伦巴大部分视频都会做反差开场），差值不够大
- **不作为独立规律**，但 C1 可以作为 C4 的子组件

### C3 你/我代词（Δ=0.33）
- TOP 83% / BOT 50%
- 中腰 65%，差值不清
- **不作为独立规律**。但注意：BOT 里 C3 FAIL 的 3 条都是全第三人称冰冷陈述

## 无信号（基线项，该创作者全部通过）

### C2 具名主角（baseline）

- 对本创作者不是 differentiator
- 但换一个泛娱乐型创作者，C2 可能会立刻变强

### C6 数字密度（baseline）
- 27/29 PASS（仅 2 条 FAIL，都在极边缘）
- 同样是前财经记者的 baseline
- 对本创作者不是 differentiator

## 重要 outlier：BV15wEXzqE6d 特朗普币

- 6/6 PASS
- Views 1,434（BOT zone）
- 发布 2025-05

**这条 outlier 揭示了 preset 的边界**：本 preset 只测 hook 质量，不测粉丝基数/封面/标题党/发布时段/历史权重。即使 hook 6/6 满分，也可能因为发布时机、粉丝基数等外部因素扑掉。

→ **下一版 preset 应加入时间维度**（考虑她当时的粉丝基数和 channel momentum）
→ **或者**：把 outlier 从 BOT 剔除，作为"hook 满分但被其他因子压制"的独立类别

### 关于 A/B/F 分析的修正

**我之前的 7 条规律里有几条需要撤回或降级**：

| 之前说的 | 网格事实 | 处置 |
|---|---|---|
| "爆款 = 具名主角 × 数字密度 × ..."（乘法公式） | C2/C6 是 baseline 不是 differentiator | **撤回公式** |
| "自曝陌生感 = 立即关掉" | 样本只有 1 条（鸣鸣很忙）支撑 | **降级为 n=1 观察** |
| "直接抛英文 = 送命开场" | 只有 GEO/x402 支撑，没有反例验证 | **降级为弱相关** |
| "熟悉度是强信号" | 这条是对的（= C5 出圈）✓ | **保留，升级为强规律** |
| "争议感是信号" | 这条是对的（= C4）✓ | **保留，升级为强规律** |
| "第一句反差 = 强规律" | C1 Δ 只有 0.33 | **降级为弱相关** |
| "你/我代词 = 强信号" | C3 Δ 只有 0.33 | **降级为弱相关** |

**真实的爆款必要条件（伦巴第宝姐）**：
- **题材已出圈**（C5）
- **开场有争议感**（C4）

**不是爆款必要条件（伦巴的底层能力，与她hit/flop分化无关）**：
- 具名主角 — 她永远在用
- 数据密度 — 她永远在用

### 对 Growth Memo 的具体动作建议

1. **选题阶段**：列候选题材后先问 "前 2 周这个题材是否在大众微博热搜 / 朋友圈 / 新闻头条出现过"。没有就换
2. **开场撰写**：强制第一段内至少一个"X 到底 Y" / "A 还是 B" / "为什么 XX 却 YY" 句式
3. **禁用开场**："今天我们来聊" "最近这个话题大火" "X 是一种 Y"
4. **次级加分项**（弱相关但多多益善）：数据反差、你/我代词、具名主角、≥3 数字锚
5. **承认极限**：即使上面全部做对，hook 也只能解释 ~70% 的爆款概率，剩下 30% 是封面/标题/时机/粉丝基础——本 preset 无法覆盖
