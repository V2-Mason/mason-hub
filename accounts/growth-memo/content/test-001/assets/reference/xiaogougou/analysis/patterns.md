# 规律提炼 | 狗勾 (93 videos, 6 checks)

## 一句话总结

**狗勾的爆款不靠热点反差，靠"具名案例+系列长尾"。** 唯一的强规律是 C2（具名主角 Δ=+47%），其他 5 条 check 都是弱规律或反向规律。

## 强规律（Δ ≥ 0.4）

### 规律 1：C2 具名主角（Δ=+47%，唯一强规律）

**表述**：狗勾的爆款（>25k）开场 60 秒必须锚定一个具体的**人名/品牌/案例/数据源**，不能只有"达人/MCN/品牌方/行业"这种抽象概念。

**证据**：
- TOP 19 中 15 条 PASS（79%）
- BOT 19 中 6 条 PASS（32%）
- Δ +47% 是全部 6 个 check 中最大
- 典型案例：
  - 网红甲/乙/饼的三个行业故事（BV1Ua411n7DW 24k）
  - 章小蕙&董洁直播首秀（BV12m4y1j7LE 22k）
  - 特厨隋坡 vs MCN（BV1xvJHzqE28 8k）
  - 奥迪抄袭北大满哥（BV1yU4y127J7 5k）
  - 中血糕虚假宣传案（BV1nB4y1K7yj 4k）
  - 刘畊宏爆火背后（BV1kY411w7jj 8k）
  - MBTI 赛博玄学（BV12t4y1s7xT 7k）

**对比 FAIL 组**：BOT 的 13 条 FAIL 基本都是"大家好我是狗狗，今天想聊聊..."的空泛开场。话疗系列 ep.01-ep.06 全都 C2 FAIL，且全部落在 BOT/mid 底部。

**边界条件**：
- 具名**案例**也算（恰饭方法论系列开场"朋友们，有一说一啊，在 MCN 待久了..."配合后续甲乙丙三个故事）
- 具名**品牌**也算（恰饭方法论总结"抖音/B站/小红书"这种具体平台名）
- **不算**：概念/理论/方法论（"冷门高潜赛道" / "内容分层四步法" / "泛流量毒药"）

## 反向规律（Δ 负值）

### 规律 R1：C1 反差开场（Δ=−16%）

**表述**：狗勾的 TOP 视频**反而不用**数据反差/极端对比开场。

**证据**：
- TOP 26%（5/19）
- MID 45%（25/55）
- BOT 42%（8/19）

**解读**：狗勾的 TOP 更偏"故事开场"和"系列开场"：
- "大家好我是网红小狗狗，欢迎来到新一期的从业者深扒系列"（系列型）
- "朋友们，有一说一啊，在 MCN 待久了吧..."（故事型）
- MID/BOT 反而有些视频尝试用"最近 AI 这么火 / 流量红利消失 / 2024 全网万粉超 1500 万"这种数据开场，但没有转化成爆款

→ **对狗勾而言，数据开场和爆款是不相关甚至轻微负相关的**。

## 弱规律（仅作观察）

### C3 你/我代词（Δ=+21%，上限饱和）
- TOP 100%（19/19）/ BOT 79%（15/19）
- TOP 全通过但 BOT 也 79% → 这是狗勾的 baseline 口头禅
- **不作为独立规律**

### C4 争议感（Δ=+21%）
- TOP 63% / MID 53% / BOT 42%
- 差值存在但弱
- **MID 内部无区分力**（C4 PASS 10,026 views vs C4 FAIL 9,940 views，ratio 1.01）
- **不作为独立规律**

### C5 题材出圈（Δ=+16%，狗勾的最大差异点）
- TOP 21% / MID 13% / BOT 5%
- 差值存在但狗勾**不以热点为主**：TOP 79% FAIL

- 和伦巴第宝姐 Δ=+83% 形成鲜明对比

## 非单调规律

### C6 数字密度（Δ=+5%，U 型）
- TOP 21% / MID 40% / BOT 16%
- MID 最高，不是单调关系
- **解读**：
  - TOP 用故事开场，数字往后放（所以前 60s 不满 3 个）
  - MID 有一批"报告解读/数据复盘"视频数字密集（但没突破 TOP 门槛）
  - BOT 是 vlog/话疗/直播回放，天然无数据
- **C6 对狗勾不是正向差异源**

- BV1T14y1H7RT 75k 小红书如何做爆款

**特征**：C2 弱（没具体人物）但**标题里含平台名**（小红书/抖音/B站）+ **方法论索引**（从 0 起步/恰饭方法论/百大深度）

这 9 条中 **6 条 C4+C5 都 FAIL**，但依然是 TOP。说明它们不靠 hook 驱动，靠 **SEO 长尾**——B 站搜索"小红书如何做爆款"、"如何做恰饭"等长尾词时反复被搜到。

**这两条路径对 preset 的暗示**：
- bilibili-creator preset 当前的 6 个 check **完全不考虑 SEO 长尾信号**（标题中的常青查询词）
- 对狗勾这种"教程库型"创作者，SEO 是她的主要爆款机制，hook 质量只对"故事型"路径有效
- 需要**增加 Check C7: 标题是否命中常青长尾查询**（"平台名+如何/为什么/做什么"）才能解释 Path B

## 重要的 outlier

### BV1nB4y1K7yj 中血糕（2021-07, 4,127 views, C4+C5 都 PASS）

唯一一条 C4+C5 同时 PASS 但落在 BOT 的视频。
- 发布时间 2021-07 — **狗勾账号最早期**
- 标题含"编瞎话、割韭菜、收智商税"（C4 争议感最强）
- 选题是当时的社会新闻（中血糕虚假宣传）
- hook 质量满分但 views 只有 4k

→ 和伦巴的特朗普币 outlier 一样，**hook 质量不是爆款的充分条件**。2021 年狗勾还没有足够的粉丝基数来放大这条视频。

## 规律提炼：狗勾的爆款公式

**不是乘法公式，是两条独立路径**：

```
爆款路径 A (故事型) = C2 具名案例 + 故事开场 + 不依赖数据堆砌
爆款路径 B (长尾型) = 系列名 + 常青平台话题 + 方法论索引 (preset 当前不测这个)
```

**非爆款的反面例子**：话疗系列 ep.01-ep.06、vlog、直播回放 —— 全部无具名、无系列索引、无故事感。

## Preset 层面的反思

本次 93 视频分析暴露了 **bilibili-creator preset v0.1 的三个缺陷**：

1. **没有 SEO 长尾信号维度**：狗勾的 Path B 视频靠标题查询词爆，preset 测不到。需要加 **C7: 标题含常青平台词** 或 **C8: 系列化索引**
2. **C5 的"大众出圈"定义太窄**：狗勾的 TOP 多是圈内热点（MCN 从业者圈），不是大众热搜，但依然能爆。应该区分"大众出圈"vs"圈内出圈"
3. **C1 的解读要分语境**：对伦巴（财经博主）是弱相关，对狗勾（方法论博主）是**反向相关**。单一 preset 不能普遍适用

## 对 Mason / Growth Memo 的含义

1. **狗勾的打法不是"蹭热点"**，是"**系列化 + 长尾查询词 + 具名案例**"。Growth Memo 如果走狗勾路线，应该：
   - 起系列名（例如"独立开发复盘"系列）
   - 标题含常青查询词（"独立开发 / 副业 / 个人项目"）
   - 每条视频用**具体人物/项目**作锚点，不用抽象概念
2. **不需要蹭全网热点**（和伦巴的结论相反）。圈内深度内容靠 SEO 长尾慢慢发酵
3. **避免话疗/vlog/闲聊**：狗勾 6 条话疗全部落在 BOT
4. **避免纯方法论命名的视频**：如"内容分层四步法"、"泛流量毒药"这种视频都 BOT。需要换成"XX 博主实操案例"或"我花 8 万块的教训"
