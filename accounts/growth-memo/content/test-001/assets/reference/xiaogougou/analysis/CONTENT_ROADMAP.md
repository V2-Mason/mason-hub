## 核心策略：B+D 双人群 / #1+#5 起步组合 / 三集递进

### 主攻人群（已在 AUDIENCE_PERSONAS 锁定）

- **B 35+ 转型者** (~20%) — 变现支柱，焦虑深+付费意愿强
- **D 行动力 0 观望者** (~20%) — 流量基本盘，"成长备忘录"连载格式天然适配
- 共同点："需要一个真实可信的同路人"

### 第一条：板块 #1 + #5 组合

**为什么是 #1+#5：**
- #1 (AI 编程实操痛点) 商业化得分最高 14/15，AI 工具品牌都想投
- #1 的痛点 Mason 亲身经历过（token 消耗、上下文管理、AI 绕进去）
- #5 (求资料) 让视频天然带福利（PRD 模板、CLAUDE.md 配置 → 触发充电/收藏）
- 形态：单点突破，节奏紧凑

**首推选题：**
《AI 不是不行，是你不会带它 — 我用 Cursor / Claude Code 一周的 8 个真实坑》

**结构骨架：**
1. **钩子 (0:00-0:15)**：用最高赞评论 [129] "AI 给我的代码写了句注释：这里逻辑很奇怪，但不要动" 当冷开场
2. **承诺**：8 个真实坑 + 8 个对应解法 + 1 套 PRD 模板（充电福利）
3. **主体**：每个坑 30-45 秒，配截图/录屏
4. **收尾**：成长备忘录定位 + 下期预告（暗扣 #3 35+ 路径图）

### 第二条：板块 #3（35+ 路径图）

**作用**：人群 B 的"招聘启事"，把 #1 钓上来的精准流量沉淀成订阅

**首推选题：**
《35 岁转 AI 开发：6 个月路径图（亲历版）》

**关键元素：**
- 真实时间线（不夸张）
- 每个月的具体动作 + 真实结果
- 走过的弯路 + 关键拐点
- 评论最高赞 [54] "35 岁大叔...想入行 AI 工程师怎么做" 直接回应

### 第三条：板块 #7（真实收入曲线）

**作用**：人群 D 的"信任锚点"，把观望者推过行动门槛

**首推选题：**
《我的真实独立开发收入：一个月 0 → 2k → 1 万 → ?》

**核心反差**：用户更想听"小钱→大钱"的真实曲线，而不是"4.5 万美元"神话

**关键证据：**
- "去年这个时候我自己也在做，一个月也能有个 1-2W 的效益" [130 赞]
- "之前失业好久找不到工作，现在靠这个也能养活自己了" [119 赞]
- "刚做第二个月，现在已经赚了 2k 多了" [32 赞]
