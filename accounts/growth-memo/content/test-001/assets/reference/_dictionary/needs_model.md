# Mason 目标受众需求模型

> 这是从 B 站 272 条真实评论里提炼的"需求清单", 每个需求带证据 + 置信度 + 证据数量。

## 需求 1: AI 代码不能直接用 (置信度: 高 ★★★★★)

**首次发现**: 2026-04-06 (round1)
**证据数量**: 17+ 条高赞评论
**关联人群**: A 在职程序员 / E 精英开发者

**典型证据**:
- [358 赞] "AI 简单的代码可以处理, 但逻辑复杂的东西就差强人意了, 多数时候 ai 会把自己绕进去, 代码量越写越复杂"
- [272 赞] "Cursor 并不像想象中那样可以一步到位, 我们依旧需要和 Cursor 进行反复的拉扯"
- [176 赞] "上下文都给的齐齐全全, 生成个 sql, 传的是 endTime, sql 里是 eTime, 我找了半小时"
- [158 赞] "以前怕带实习生, 现在怕带 AI, 因为它犯错的时候比实习生自信多了"
- [129 赞] "AI 居然给我的代码写了句注释: '这里逻辑很奇怪, 但不要动, 动了会崩'"

**相关关键词**: AI 编程, Cursor 编程

**对 Mason 的含义**: 这是受众**最大的痛点**, 商业化评分 14/15 (最高)。任何"我用 AI 写代码的避坑指南"都会有观众。
