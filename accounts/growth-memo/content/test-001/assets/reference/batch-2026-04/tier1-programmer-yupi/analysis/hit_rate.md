## 关键观测 (Data Only)

### 1. 没有任何 check 达到强规律 (|Δ|≥0.4)
- 最大 |Δ| = 25% (C7)，远低于强规律阈值 40%
- 连伦巴的 C5=+83% 或狗勾的 C3=+53% 这种量级都不存在

### 2. 只有 1 个弱规律 (C7)，且方向与 preset 预期相反
- C7 实操产出型标题: Top=50%, Bot=75%, Δ=-25%
- Preset 设计 C7 作为狗勾路径 A 的正向信号，但鱼皮 Top 反而**更少**用"我做了 X / X 个坑 / 完整指南"类实操标题
- 同时中腰违反率 64%，按 skill 规则仍然 WEAK (|Δ|≥0.2)

### 3. 平均每行 PASS 数：Top < Mid < Bot
- Top 12 平均每条 PASS 3.92/9
- Mid 33 平均每条 PASS 4.33/9
- Bot 12 平均每条 PASS 4.58/9
- **Top 视频命中的 preset check 数量反而最少**。这直接说明 preset 的 9 个维度与爆款无相关

### 4. C1 反向规律与狗勾一致但量级不够
- 狗勾 C1 Δ ≈ -16% (原 preset 验证数据)
- 鱼皮 C1 Δ = -17%
- 方向一致，但量级都达不到 20% WEAK 阈值
- 说明"反差开场"对 dev content 赛道整体弱

### 5. C3 系列索引几乎全 0
- 鱼皮 57 条中只有 1 条 (#2 "b站大学" 系列，且转录缺失)
- Top/Mid/Bot 全部 ≤ 1
- **鱼皮的内容组织完全不依赖系列化** — 与狗勾 (恰饭方法论 01-09)、ezindie (周刊 149 期) 完全相反

### 6. C2 / C8 普遍高但无区分度
- C2 具名主角 83%-92% 全账号普遍高 (鱼皮内容普遍提及具体工具/产品)
- C8 你/我代词 83%-97% 全账号普遍高 (中文 UP 主通用习惯)
- 这两项是"鱼皮的 baseline 风格"，不是"爆款因子"

### 7. C9 可抄作业 全账号偏低
- Top 1/12, Mid 4/33, Bot 2/12 (Bot 比例最高 17%)
- 鱼皮很少在标题/开场明确承诺"福利/模板/源码"
- 与"狗勾 C4 = 具体案例 + 真实数字"的内容承诺机制不同
