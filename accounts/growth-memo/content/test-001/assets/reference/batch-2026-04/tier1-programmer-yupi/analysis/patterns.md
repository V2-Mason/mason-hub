## 弱规律 (|Δ| ≥ 0.2, 或 |Δ|≥0.4 中腰违反率 30-50%)

### 规律 1 (弱, 反向)：C7 实操产出型标题

**方向**: Top 视频 **更少** 使用实操产出型标题。Preset 原设计 C7 为狗勾路径 A 的正向信号，鱼皮数据上**反向**。

- Top 12 命中 6/12 = 50%
- Mid 33 命中 21/33 = 64%
- Bot 12 命中 9/12 = 75%
- Δ = Top − Bot = **-25%**
- 中腰违反率 (按反向规律 = 中腰 PASS 比例 = 64%) — 偏高

**证据 Top (C7 FAIL 的高播放视频)**：
- #1 BV1sQBPBmEGU "突发，快手被色情直播刷屏" (3.08M) — 事件报道
- #5 BV1aM411K7tD "我开业啦" (1.14M) — 宣告
- #6 BV1iM411T7ey "再见了，腾讯" (968K) — 离职宣告
- #7 BV1xp2hYHEVn "程序员攻占小猿口算" (965K) — 事件报道
- #12 BV1Tb411Q7V4 "没想到又被攻击了赔了1.5万" (677K) — 事件报告

**证据 Bot (C7 PASS 的低播放视频)**：
- BV1MnpVzdETW "用 AI 帮我读文档...Claude Code+Kimi开发文档助手网站" (24K) — "开发...网站" 实操产出
- BV11hx5euEbD "我做了个程序员面试刷题工具" (19K) — "我做了" 实操标志
- BV15M4m127dV "99%的网站，都死在了这件事上！网站开发经验分享" (28K) — "经验分享"
- BV1tf4y1E7H3 "自己搭建写文档最佳利器？手把手教程" (21K) — "手把手教程"

**边界条件**:
- 这不是"实操标题会扑"，而是"实操标题在鱼皮账号里不足以推上百万播放"
- Top 12 里 **事件/宣告类** (#1, #4, #5, #6, #7, #12, 共 6/12 = 50%) 贡献了半壁江山
- Mid 里 C7 PASS 的视频 (21/33 = 64%) 播放量分布广，说明"实操标题"在中腰是 baseline 操作
- Bot 里 C7 PASS 率最高 (75%)，意味着 **"实操型教程"** 在鱼皮账号里**是 Bot 的典型形态**

**结论**: 鱼皮的"实操教程模板"(我做了X / 保姆级 / 手把手 / X个工具分享) 是**中腰和 bot 的填充内容**，不是 Top 催化剂。

## 不成立 (|Δ| < 0.2)

### C1 反差/极端开场 — Δ = -17% (弱反向, 阈值不达)

- Top 3/12 (25%), Mid 14/33 (42%), Bot 5/12 (42%)
- 方向与 preset 预期 (dev content 反向) 一致，但量级不足 20% 阈值
- **备注**: 中腰 (42%) 反而比 Top (25%) 高，说明"反差开场"是中腰的常规打法，不是爆款因子
- 与狗勾 C1=-16% 量级相近，印证了 "dev content 整体反差开场弱" 的 preset 假设

### C2 具名主角 — Δ = -8%
- Top 83%, Mid 82%, Bot 92% — **全账号高普遍值**
- 鱼皮内容天然高频提及具体工具/产品 (Cursor/Java/Notion/GitHub...)，这是 baseline 不是区分度
- Bot 比 Top 高 8%，与 preset 预期 (C2 为狗勾型正向 +30~+50%) 完全不符

### C3 系列索引 — Δ = +8% (但 Top 仅 1, 样本量极低)
- Top 1/12 (#2 b站大学 系列，且转录缺失)，Mid 0/33, Bot 0/12
- **鱼皮几乎不做系列化内容**，这是本账号与狗勾 (恰饭方法论系列)、ezindie (独立开发变现周刊 149 期)、小 Lin 说 (系列科普) 最大的风格差异
- **preset C3 对鱼皮类账号完全无效**

### C4 常青长尾查询词 — Δ = -8%
- Top 67%, Mid 76%, Bot 75%
- **Bot 反而比 Top 高 8%**，与 preset 预期 (C4 为狗勾型正向) 完全反向
- 鱼皮 Top 标题多是 **一次性热点词** (突发/开业/离职/被攻击) 而非"Java/Python/怎么/为什么"长尾

### C5 故事/事件开场 — Δ = 0% (完全无差异)

- **鱼皮的视频约 40% 用故事开场、约 40% 用自介/陈述/教程中段切入、约 20% 其它**
- 本 check 对鱼皮账号**无区分力**

- 鱼皮 Top 并不比 Bot 更"数字密度高"。即使是 #12 "赔了1.5万" 级别的数字密集视频，也只是 Top 之一

### C8 你/我代词 — Δ = -8%

## Phase 5 总结

按 skill 硬门控规则：
1. **强规律数量 = 0**
2. **弱规律数量 = 1 (C7, 且反向)**
3. 平均 PASS/行: Top 3.92 < Mid 4.33 < Bot 4.58 **(反向递增)** — Bot 反而更多命中 preset checks

**结论**: 现有 preset (bilibili-dev-content v0.1) 的 9 个 check **无法解释鱼皮的爆款分布**。鱼皮既不是狗勾型 (路径 B 长尾型)，也不是伦巴型 (路径 A 反差型)，是一个**第三种赛道**。

**第三种赛道特征** (来自 Top 12 的 qualitative 观察，不是 Phase 5 的数据规律)：
- 事件/时效驱动 (快手直播/小猿口算/网站被攻击/IDEA免费)
- 个人故事驱动 (开业/离职/被黑)
- 老牌 SEO 清单 (早期 2021 年的 Java 学习路线、编程语言对比等，靠"B 站大学"流量红利积累)
- 炫技/创意 (AI 女友、春晚魔术)
- 这些类别与"开场结构/标题模板"弱相关，与 **话题热度 + 账号历史流量权重** 强相关

**建议升级 preset**:
- 新增 C10: 标题是否含"事件热点词" (突发/又/竟然/离谱/火了/紧急/刚刚)
- 新增 C11: 账号流量因素 (首播 30天 view 曲线 → 但这需要 recon 数据，不在 transcript 里)
- 新增 C12: 标题是否含"个人故事词" (我开业/我辞职/我被/我做了 X 年/我花了)
- 这些迭代留给主对话 F 对比后决策
