**样本**: 57 条 (Top-12 / Mid-33 / Bot-12)
**转录齐整度**: 51/57 (6 条 2026 年新视频缺转录, 仅能从标题打分)

## 执行摘要

ezindie 全库 57 条视频只支持 **3 条规律** (C1 / C6 / C8 三条都是 **同一个机制** 的三种表达, 不是独立规律):

**核心机制** = **"主角独白 + 前 2 句带具体美金数字 + 第一人称自述"** (即经典 ezindie 周刊模板)

其余 6 条 check (C2/C3/C4/C5/C7/C9) 都因 **无区分度** / **低信号** / **反向 (格式分层)** 而不成立.

**关键诊断**: ezindie 全库基本只有 **一个爆款机制**, 而且这个机制正在衰减 (2026 新视频换了风格但只有 1 条进入 Top 段). 这不是 "狗勾型可抄" 而是 "**单路径历史红利已过**".

## 规律 1 (强): C1 反差/极端开场 — 实际上就是"美金数字 tagline"

- **命中率**: Top 12/12 (1.00), Bot 3/12 (0.25), Δ = **+0.75**
- **中腰违反率**: 24% (8/33 Mid 条目 FAIL)
- **证据**:
  - Top PASS 例: BV1uj411h7H2 "两年内从 0 到月收入 4.5 万美元" / BV1th411K7ZQ "年收入 350 万美元" / BV1NUHuemEMz "月收入 12 万美元"
  - Bot FAIL 例: BV1tr4y1z7VE "业余项目成功的秘密" (纯概念无数字) / BV1zQ4y1e7wJ "快速创建 NFT 的在线工具" (功能陈述无数字) / BV1jm4y1X7Lz "最好的播客搜索引擎, 从副业到被投资经历了什么" (程度词但无具体数字)
  - Bot 反例 3 条 PASS: BV1bq4y1z7bf "月收入 1 万美金" / BV1Pu411S79P "4 万/60 天/2 千" / BV1rL411j77L "2.5 万美元" → 说明有美金数字但是其他维度翻车 (C6/C8 都 FAIL)
- **边界条件**: 只有当开场是"主角独白 + 美金 tagline"才算 PASS. 2026 新风格的反问数字开场 (BV1CWPqzKE44 "15000 美金") 也算, 但那是独立一类.
- **现实解读**: 这条规律的本质不是 "反差开场" 而是 "**ezindie 周刊格式常量**"—— 标题里带 "月收入 X 美元", 开场再复述一遍, 就天然 PASS 了. 对非周刊格式 (课程/训练营) 无效.

## 规律 4 (弱): C2 具名主角 — 几乎全库 PASS, 区分度弱

- **命中率**: Top 12/12 (1.00), Bot 9/12 (0.75), Δ = **+0.25**
- **中腰违反率**: 9% (3/33)

## 不成立的规律

### C3 系列索引 — **无区分度失效** (预期验证成功)

- Top 12/12, Bot 11/12 (只有 #54 BV1VTrJ FAIL), Δ = **+0.08**
- **57 条里 54 条带系列索引** (第 N 期 / #YYY / 人物志第 N 篇 / 训练营第 N 期). 几乎 100% PASS.
- **这不是规律, 这是格式常量**. 对 ezindie, C3 失去区分度, 跟判别爆款无关.
- **这验证了任务预期**: ezindie 的 C3 确实无区分度. 但并非 100% PASS (54/57 而非 57/57), 因为 #23 Tabhub/#37 课程/#54 揭秘 AI 暴利 App 不带系列索引.

### C4 常青长尾查询词 — 近无区分度

- Top 12/12, Bot 10/12, Δ = **+0.17**
- 几乎所有标题都含 "独立开发" / "变现" / "月收入" / 平台名, 天然覆盖长尾词 → 失去区分力.
- 只有 3 条 FAIL: BV1bq4y1z7bf 第31期 (纯 "第31期") / BV13v421r74r "每周热点小产品变现第1期" (无具体平台/工具) / BV1tr4y1z7VE "业余项目成功的秘密" ("秘密" 非长尾词).

### C5 故事/事件开场 — 低信号弱规律

- Top 3/12 (0.25), Bot 0/12, Mid 2/33 (0.06), Δ = **+0.25**
- **Top 仅 3 条 PASS** (#1 BV1uj 失业锚点 / #11 BV1CWPqz 2026 拆解 / #12 BV1NUHuemEMz 2012 年 11 月 6 日锚点), 其余 9 条 Top 都是陈述式"嗨我是 X".
- **Mid 仅 2 条 PASS** (#15 BV1Xh4y177xk "2015 年 12 月 我躲在房间里" / #43 BV1dD9wBeESP 2026 新风格)
- 信号太弱, Top 本身 PASS 率只有 25%, 不足以支持 "故事开场 = 爆款" 的结论. 标注为弱规律但不建议作为复刻信号.

### C7 实操产出型标题 — 反向规律 (格式分层副产品)

- Top 0/12 (0.00), Bot 4/12 (0.33), Δ = **−0.33**
- Top 全部 FAIL 因为周刊是 **转述他人故事** (主语是 Tony/Matt/Dimitro), 没有 "我做了/我踩了坑" 的实操标志.
- Bot 4 条 PASS 全部是非周刊格式: #46 "搞钱实录" / #50 "淘金框架" / #51 "50 万复盘" / #54 "复刻逻辑".
- **不是有价值的规律**, 是格式分层的副产品. 实操标题的主创是凯凯自己, 恰好集中在尾部.

### C9 可抄作业 — 全库几乎不具备

- Top 0/12, Bot 0/12, Mid 3/33, Δ = **0**
- 全库只有 3 条 PASS (都是凯凯训练营/课程 promo). **周刊赛道不提供任何可抄作业产物** (没有 prompt / 模板 / 配置清单).
- **格式不具备**. ezindie 的爆款机制完全靠 "数字故事" 而非 "实操交付物".

## 关键结论 (给主对话)

### 1. ezindie 账号类型归属

**ezindie = 单路径"信源编译器"型, 历史红利已过**

- **不是狗勾型**: 狗勾有路径 A (故事爆款) + 路径 B (SEO 长尾) 双机制, ezindie 只有一个单机制 "主角独白周刊模板".
- **不是伦巴型**: 伦巴靠反差数据出圈热点, ezindie 不追热点只讲历史案例.
- **是纯"国外案例编译器"**: 所有 Top 爆款都是翻译 indie hackers / micro-conf / Twitter 上的国外独立开发者故事. **看不到任何国内原创思考**.
- **红利过期证据**:
  - probe P50 4.7k, Top-Bot 差距 125x
  - 2026 年 7 条新视频只有 1 条进入 Top-12 (BV1CWPqzKE44 #165)
  - 2026 年其余 6 条全部在 Bot-12 (观看 1000-1539 区间)
  - 频道在 2024 年底到 2026 年这个过渡期流量塌陷, 新格式未能补位

### 2. "可抄手法" vs "方法论提取"

**基本没有可抄手法**. ezindie 的爆款机制 = **"国外故事信源 + 标准美金 tagline 模板 + 单主角独白"**, 这三件套对 Growth Memo 无直接借鉴价值, 因为:

- **Growth Memo 不想做国外故事搬运**, 会变成二手信源
- **标准美金 tagline 模板** 在 Growth Memo 这样的方法论沉淀账号不适用 (没那么多具体美金数字)
- **单主角独白** 本质上依赖找到真实主角进行访谈, Growth Memo 是 Mason 自己

### 3. 可提取的方法论 (3 条历史教训)

1. **单路径依赖的脆弱性**: ezindie 157 期周刊只押注一个爆款机制, 当 2024 底受众对 "美金故事" 脱敏后整个频道就塌陷了. 方法论教训: **任何内容账号都应该有 2+ 独立爆款路径**, 单路径必然衰减.
2. **"格式常量"检测法**: 当某个 check (如 C3 系列索引 + C2 具名 + C4 长尾) 在账号内 90%+ 都 PASS 时, 这个 check 对该账号**失去判别力**. 它是格式常量, 不是爆款规律. 这条是 **grid 方法论的一般化结论**, 不只适用 ezindie.
3. **"主角独白 vs 目录式" 是 ezindie 内部的 hit/flop 分水岭**: 57 条里, 单主角独白格式平均 views 远超目录式. 给任何"编译器"类账号的建议: **宁可一期只讲一个主角深度, 不要一期列 5 个浅度项目**.

### 4. 对 Growth Memo 路线图的建议

- **不走 ezindie 信源编译型路线**: 国外故事搬运不是 Mason 的竞争力
- **参考 ezindie 的"极端数字 tagline"**: 虽然机制背后的人物故事不可抄, 但"标题里带具体数字"的做法在全平台都有效. Growth Memo 标题里应该带具体数字 (时长/产品数/收入数等)
- **规避 "目录式浅度" 反模板**: ezindie 的目录式 flop 实证 "一期讲 5 个项目" 是反模板, Growth Memo 单期应聚焦 1 个主题深度
- **避免 "C3 系列索引" 陷阱**: 不要为了做系列而做系列. ezindie 做了 157 期系列, 后期观看量仍塌陷. 系列索引不是爆款保险.

## 边界条件和不确定性

1. **6 条 2026 新视频缺转录**, C1/C5/C6/C8 按 FAIL 处理. 这 6 条全部在 Bot 段, 即使数据齐整也不太可能翻转 Bot 段结论, 但会略微提升 Bot 段的 C1/C5/C6/C8 命中率. 保守估计: 影响 Δ < 0.05, 不改变强/弱规律判断.
2. **C6 的"真实锚点"判断带主观性**: 我已在 grid.md 备注里逐条写明数字数量. 重跑边界会在 C6 ±1 条范围变动, 不改变规律强度.
3. **Top 段 11/12 是经典周刊 + 1/12 是 2026 新格式**: 样本偏向历史格式. 如果 Mason 想看"2026 新格式能不能救活 ezindie", 当前样本不足以下结论 (新格式样本量只有 7 条).
4. **不做 Phase 6**: 按任务要求跳过 VP 提炼 / 跨账号对比 / 偷手法清单. 留给主对话 F 对比.

## Lessons (Gap 类型分类)

### Lesson 1 (Pure knowledge)
**C3/C4 在编译器类账号上会出现"格式常量失效"**. 当某账号的内容模板化程度高时, preset 的部分 check 会因全库 PASS 失去区分度. 本次在 ezindie 上验证了 C3, 同时发现 C4 也有同样问题.

### Lesson 2 (System capability gap)
**preset 的强规律阈值 (Δ≥0.4) 对于"单机制账号"会产生 3 条高度相关的 "假三规律"**. C1/C6/C8 在 ezindie 上全部过阈值, 但背后是同一个机制 "主角独白 + 美金 tagline". Preset 可能需要加 "规律去相关化" 步骤 (例如: 当 C1 和 C6 的 PASS/FAIL 在同一条视频上的相关系数 > 0.7 时, 合并为一条规律). → **file trigger action, triage needed**: preset 迭代建议, 加去相关化.

### Lesson 3 (Documentation update)
grid.md 格式里需要补一列 "格式类型" (周刊独白 / 目录式 / 2026 新风格 / 自家产品 / 自家课程 / 训练营 promo), 可以提前把格式异常条目标出来, 不必在每条备注里重复说. → **更新 creator-hit-factor-grid skill 的输出模板**.

### Lesson 4 (Integration gap)
**缺转录条目的处理规则在 skill 里未定义**. 本次遇到 6/57 缺转录, 我自主决定: C1/C5/C6/C8 (开场类) FAIL, C2/C3/C4/C7/C9 (标题类) 从标题打分. 这个处理规则应该写进 skill. → **file trigger action, triage needed**: skill 补一节 "缺数据降级规则".

### Lesson 5 (Pure knowledge)
**衰减期账号的 Grid 分析要特别标注时间维度**. ezindie 57 条跨度 2021-12 → 2026-04, 前半段 (-2024) 周刊红利期, 后半段 (2024-) 衰减期. 如果不考虑时间维度, "Top 段" 会天然倾向早期视频, 混淆"爆款机制"和"早期红利". 建议 grid 分析补一个"近 1 年子样本"复核.
