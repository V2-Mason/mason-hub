# Batch Recon 2026-04 — 4 账号横向 F 对比

**生成时间**: 2026-04-08
**样本**: 4 个 Tier 1 账号 × 57 条 = 228 条视频, 双 preset 总打分 ~2700 格
**目的**: 找出"独立开发 vs 财经叙事"双赛道里头部账号的爆款公式共性和差异，为 Mason 的 Growth Memo 路线图做决策依据

---

## 一句话核心结论

**没有任何一个 Tier 1 账号符合现有 preset 设计的"狗勾路径 A+B"模板**。4/4 都是"第三种规律"或弱化变体。**最重要的发现不是规律共性，而是 4/4 共同的市场空白：C9 可抄作业 ≈ 0**——这恰好是 Mason 受众的最强需求信号。

## 4. 4/4 共性发现 (黄金 ⭐⭐⭐)

### 共性 1: **C9 可抄作业 ≈ 0** (4/4) ⭐⭐⭐

| 账号 | C9 PASS 数 | 比例 |
|---|---|---|
| 鱼皮 | ~5/57 | 8% |
| ezindie | 0/57 | 0% |
| 小Lin 说 | 1/57 | 1.8% (出书宣告) |
| 巫师财经 | 0/57 | 0% |

**解读**: B 站头部 dev/财经 UP 主**全部不提供可复刻产物**（模板/PRD/Prompt/源码/工具清单）。

**对比 Mason 的 AUDIENCE_PERSONAS**:
- [37 赞] "求资料 / 求模板"
- [35 赞] "有没有完整的 Prompt 配置"
- [197 赞] "可以分享一下源码吗"
- 多条高赞评论都在向 UP 主索要可抄作业

**这是一个明确的 product-market fit 缺口**。头部不做 + 用户在求 = 完整市场空白。Growth Memo 在每期末尾附"本期 Prompt + 工具清单 + Notion 模板" 立刻和 4 个头部账号区分开。

### 共性 2: **C7 实操产出型标题 4/4 反向** ⭐⭐

| 账号 | C7 Δ | Top PASS / Bot PASS |
|---|---|---|
| 鱼皮 | -0.25 | 6/12 vs 9/12 |
| ezindie | -0.33 | 0/12 vs 4/12 |
| 小Lin 说 | -0.25 | 0/12 vs 3/12 |
| 巫师财经 | -0.25 | 0/12 vs 3/12 |

**解读**: 头部账号的 Top 段几乎不出"我做了 X / 实操踩坑 / 完整指南" 这类标题，相反 Bot 段反而有更多。

**两种可能解释**:
1. **头部已经退出实操赛道** → 实操标题被中腰和 bot 占据，头部转向"评论 / 解读 / 故事"
2. **实操是新手赛道** → 但因为 4/4 头部都反向，更可能是 #1

**对 Mason 的意义**: 实操赛道**对头部 UP 主不再是爆款来源, 但对新进场的 Mason 可能反而是机会**——头部退出留下了空白带。

### 共性 3: **3/4 不符合狗勾 preset 路径 A+B 结构** ⭐⭐

只有狗勾自己（Session 25 的 93×6 网格）符合"路径 A 故事开场 + C7 实操 + 路径 B SEO 长尾 + C3 系列"。

4 个 Tier 1 账号里：
- 鱼皮: 9 check 里**没有任何**强规律
- ezindie: 3 个"假强规律"实际是单一机制
- 小Lin 说: 唯一强规律 C3 但仅限于"一口气了解 XX" 一个特定模板
- 巫师: C5 强信号但 MidV 高，且 C3 反向 + C7 反向

**这意味着 `bilibili-dev-content` preset 的外部效度有限**——它是从狗勾 1 个样本反推的 9 check，能解释狗勾自己 (dogfood)，但外推到其他 dev/财经账号几乎全失灵。

### 共性 4: **C2 具名主角和 C8 你我代词都是频道常量** ⭐

| Check | 鱼皮 | ezindie | 小Lin 说 | 巫师 |
|---|---|---|---|---|
| C2 全库 PASS 率 | 86% | 88% | 99% | 91% |
| C8 全库 PASS 率 | 91% | 16%* | 100% | 87% |

*ezindie 是个例外: C8 整体 PASS 率低但 Top vs Bot 差异极大 (Top 100% vs Bot 0%, Δ=+1.0)

**解读**: 财经/dev 内容**默认会带具名主角和你我代词**，这是基线门槛而不是区分爆款的因子。除非像 ezindie 那样有奇特的内部分化，否则 C2/C8 高 PASS 率不能用来打分。

## 5. 4 账号独有机制 (独立观察, 不可互相套用)

### 鱼皮 — "无 preset 可解释的混合型"

Top 12 共性 (主对话观察, 非 grid 机械结论):
- **事件时效性**: 快手色情直播 / 全球服务器挖矿入侵 / CSDN 离谱操作 / 攻击事件 (5/12 是当时正在发生的科技/安全事件)
- **个人故事**: "我开业啦" / "再见了腾讯" / "网站又被攻击了" / "我用 OpenClaw 做了女朋友" (4/12)
- **老 SEO 积累**: "2025 年最新 Java 学习路线" / "10+ 主流编程语言对比" / "30 个编程工具" (3/12 是 2021-2022 发布的长尾视频持续涨)
- **炫技创意**: "程序员攻占小猿口算" / "26 年春晚魔术揭秘"

**为什么鱼皮 9 check 全失灵**: 这 4 类 Top 视频在 9 个 check 上的命中率分布**接近随机**——因为它们的爆款机制不在 9 check 描述的"开场结构"层面，而在"题材选择 + 时机 + 账号权重"层面。

**Mason 不可抄**: 需要 877k 粉丝基数 + 多年 SEO 积累 + 实时事件追踪能力。

### ezindie — "国外开发者独白编译器，红利已过"

- **机制**: 全是"独立开发变现周刊 第 X 期" + 单个国外开发者主角 + 美金 tagline (Pieter Levels / Tony Dean / Joel Griffith)
- **3 假强规律**: C1 反差 +0.75, C6 数据 +0.58, C8 你我 +1.00 — 这三条**在同一批视频上一起 PASS**, 本质是 "单主角独白 + 美金 tagline" 一个机制
- **2026 年塌陷**: 7 条 2026 新视频里 6 条进 Bot 12 (1000-1539 区间), 红利完全消失
- **C9 = 0/57**: 周刊赛道完全不提供可抄作业

**Mason 不可抄**:
1. 国外故事搬运不是 Mason 竞争力 (语言 + 时差 + 信源深度)
2. 红利已过，模板本身也没用了

### 小Lin 说 — "降级科普长视频 + 品牌化系列 prefix"

- **唯一强规律**: C3 系列索引 +0.42, 但**仅限于"一口气了解 XX"** 这一个特定模板 (Top 12 里 5 条都是"一口气了解" 系列)
- **品牌商标 ≠ SEO 长尾**: 用户搜"一口气了解 XX" 直接找小Lin 说，这是品牌效应而不是 SEO
- **Top 平均 25 分钟长视频**: 远超狗勾 10 分钟和伦巴 18 分钟的基准
- **C5/C7/C9 全反向或为零**: 主动放弃故事开场、实操教学、可抄作业

**Mason 不可抄**:
1. 19-35 分钟长视频对新账号是重成本壁垒
2. 宏观经济/国家级题材需要多年知识储备
3. 品牌化 prefix 需要先有品牌再谈 prefix

**可偷的抽象手法**: "品牌化系列 prefix" 比纯 SEO 长尾更易让用户记住。但需要先有品牌。

### 巫师财经 — "弱化版伦巴 / C5 一项独大"

- **C5 题材出圈 +0.917** 是所有账号所有 check 里最大的单项 Δ (Top 11/12 vs Bot 0/12 近完美分界)
- **C2/C5/C6 三连 PASS** 在 Top 12 里 9/12 (75%) — 巫师爆款门票 = "全民话题 + 具名主角 + 开场数字"
- **两层门槛**:
  - 避免 Bot 的基础: C2 + C6 (基本财经叙事能力)
  - 进 Top 的额外条件: C5 一级热点 (非二级、非历史深度)
- **Mid 段 13 条出圈题材没爆**: "二级热度"或"被限流" (赵露思/吴亦凡/关税战 05/崩了)

**Mason 不可抄**:
1. 蹭全民话题 (杨幂/蔡徐坤/春晚/关税) 和 Mason 的 35+ 转型程序员受众完全不匹配
2. 题材深度 + 历史储备需要长期积累
3. 限流风险高 (敏感话题为主)

## 6. 现有 preset 的边界和失灵原因

### `bilibili-dev-content.md` v0.1 (狗勾型 9 check) 的失灵证据

| 失灵原因 | 数据证据 | 影响 |
|---|---|---|
| **C5/C7 反向**: 假设"故事开场 + 实操产出"是路径 A 的爆款信号 | 4/4 账号 C7 反向, 3/4 C5 反向 | Path A 在 4 账号上不存在 |
| **C4 长尾全 ≈ 0**: 假设"常青查询词"是路径 B 的爆款信号 | 4/4 账号 C4 都 +0.08 ~ +0.17 | Path B SEO 长尾对头部账号无区分力 |
| **C3 系列索引方向不一**: 假设系列 = 爆款 | 鱼皮/ezindie 接近 0, 小Lin "一口气" 强 +0.42, 巫师反向 -0.17 | "系列" 是 4 种不同语义, 一个 check 抓不住 |
| **C2 全库高 PASS**: 假设具名 = 爆款 | 4/4 账号 C2 全库 PASS 率 86-99% | 是基线门槛, 不是区分因子 |
| **C9 全 0**: 假设可抄作业是"充电转化信号" | 4/4 账号 C9 ≈ 0 | 头部不做这件事, 但 Mason 受众在求 |

**Bottom line**: 9 check 里能有效区分 Top vs Bot 的只有 **C6 数字密度** (3/4 账号是最强或次强信号)。其他 8 个 check 在 4 账号上要么反向、要么常量、要么各异。

### 为什么会失灵?

**Hypothesis**: `bilibili-dev-content.md` 是从狗勾 1 个样本 dogfood 反推的 9 check，但狗勾在 B 站头部 dev/财经赛道是**真异类**——他刚好同时具备路径 A 故事 + 路径 B SEO 长尾两套能力，是个"混合型 + 模板化输出" 的特例。其他头部账号要么单路径深度 (鱼皮/小Lin/巫师)，要么衰减期 (ezindie)，preset 都解释不了。

## 方法论限制 (2026-04-08 末尾补充)

**诚实交代**: 本报告的 F 对比**不是**主对话亲眼看 228 条视频转录后得出的结论, 而是基于 4 个 subagent 的二级产物 (patterns.md) + 主对话 parse 巫师 grid.md 的统计。

### 分析链条的 7 层 (可追溯)

| 层 | 判断者 | 判断内容 |
|---|---|---|
| L0 | Whisper | 音频 → 文字 (有错听率) |
| L1 | preset 设计者 (Session 25-26) | 9 check 是否能捕获爆款机制 |
| L2 | subagent (Line B1-B4) | 每条视频是否 PASS 每个 check (主观判断) |
| L3 | subagent | 命中率统计 + 规律提炼 → patterns.md |
| L4 | 主对话 | 读 patterns.md 拼横向矩阵 |
| L5 | 主对话 | "4/4 共性" 这个 meta 观察 |
| L6 | 主对话 | 把共性反向构造成 Mason 的差异化公式 |
| L7 | 主对话 | 把公式具象化为 3 个钩子题材 |

**L2 是最容易出错的一层** (subagent 主观打分), 但**主对话没有 spot check**。

### 可信度上限

**F 对比的可信度上限 = subagent 打分准确率**, 而这个准确率**没有被验证**。如果 subagent 的 PASS/FAIL 打错了 30%, 横向矩阵和"4/4 共性"可能都是幻觉。

**事后验证**: 2026-04-08 晚 event-driven preset 的 Phase 0.5 validation FAIL (2/2 账号方向一致率 <50%), 证实:
- **C6 数字密度**确实是**通用强信号** (鱼皮 0 / 何同学 +80% / 马克 +60% / ezindie +58% / 小Lin +33% / 巫师 +58% — **5/6 强信号**, 不只是 F_comparison 写的 3/4)
- 鱼皮 C6=0 是单账号 outlier, 不代表通用规律
- 主对话的 "4/4 共性" 观察是有局部偏差的 (因为鱼皮是 outlier)

### 3 个具体的可能错误 (未 spot check, 2026-04-08 末提出)

1. **C9 ≈ 0 可能是 subagent 漏读简介** — subagent 只读开场 60 秒 + 标题, 可能漏掉简介里的 "GitHub 链接 / 资料包"。鱼皮 8% 可能实际更高。建议: spot check 鱼皮 Top 5 的 B 站简介, 看是否有可抄作业承诺
2. **巫师 C5 +0.917 可能有 subagent 偏差** — C5 "题材已出圈"需要判断"发布前 2 周大众视野", subagent 用 LLM 知识库判断, 但 LLM 知识库可能不知道 2025-2026 年的出圈标准, 可能系统性偏向"已知名人 = PASS"
3. **小Lin 说 C3 "一口气了解 XX" 强规律可能是统计假象** — Top 12 里只有 5 条 PASS (42%), Bot 12 是 0/12 (0%), Δ 主要来自 Bot 的全 0 而不是 Top 的高 PASS。可能是恰好 5 条长视频早出 + 长视频更易爆, 不是"系列 prefix → 爆款"的因果

### 建议的 spot check (下次 session 可选)

如果要提升 F 对比可信度, 可以:

1. **抽 5-10 条 BV 重新读 full_text.txt 开场 + 标题, 自己打 PASS/FAIL**, 和 subagent 的判断对比, 算准确率
2. **特别 verify C9** (这是 Mason 差异化定位的核心, 错的代价最高)
3. **跑统计显著性检验** (Fisher's exact test 或 Chi-square) 验证 Δ 是否真的不是随机

**但现实是**: event-driven validation FAIL 这个"反向实证" 已经帮我们捕获了最严重的偏差 (C6 的鱼皮 outlier), 所以 spot check 的边际价值降低了。建议把时间花在**Growth Memo 第一期发布后的 D7 dogfood** 上, 用真实数据反向验证 preset。
