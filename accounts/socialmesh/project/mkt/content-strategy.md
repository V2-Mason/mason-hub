# 内容策略框架

> 内化自 shared/mkt/content-strategy.md。
> PM (EMP_0008) 用此框架制定每周内容方向，产出 weekly-direction.md 给 Creator。

## 内容分类：搜索型 vs 传播型

每条内容必须至少属于一种，否则不值得发。

### 搜索型（Searchable）-- 接住已有需求

用户已经在找答案，你的内容出现在搜索结果里。

特征：
- 标题含搜索关键词
- 内容结构清晰（分点/对比/排行）
- 长尾价值高（发出去 3 个月后还有自然流量）

适合内容：测评、教程、合集、攻略、对比

**识别信号**：采集数据中 collected > liked（藏赞比高 = 用户觉得实用，在收藏备用）

### 传播型（Shareable）-- 制造新需求

用户没在找，但看到了想转发/收藏/讨论。

特征：
- 情绪驱动（惊讶/共鸣/争议/实用）
- 强社交属性
- 爆发式流量（前 24 小时决定生死）

适合内容：故事、反常识观点、幕后日常、热点借势

**识别信号**：采集数据中 comment > collected（评赞比高 = 话题有争议/讨论度）

### 判断标准

| 信号 | 做搜索型 | 做传播型 |
|------|---------|---------|
| 采集数据关键词热度高 | V | |
| 评论区高频问同一个问题 | V | |
| 最近有热点/争议 | | V |
| 有独特经历/幕后故事可讲 | | V |
| 藏赞比高（collected/liked > 0.5） | V | |
| 评赞比高（comment/liked > 0.1） | | V |

## 内容支柱（Content Pillars）

每个账号 3-5 个核心主题方向，所有内容围绕这些方向。

### 怎么定支柱

1. **产品出发** -- 卖什么品类？每个品类一个支柱
2. **用户出发** -- 目标用户关心什么？痛点归类
3. **数据出发** -- xhs-analyze.sh 的 keyword_insights 中哪些关键词互动最高
4. **竞品空白** -- 采集数据里哪些话题没人做好

## 选题优先级

当有多个选题时，用 4 维打分排序（详见 `scoring.md`）。

快速判断法：

```
必须做: 策略简报中 hot_posts Top 10 + 跟品牌品类相关
应该做: 评论区反复问的问题（customer-language.md 方法采集）
可以做: 采集数据中竞品做了效果不错，我们能做更好
不要做: 纯蹭热点但跟品牌无关
```

## 发布节奏

| 账号类型 | 建议频率 | 搜索:传播 比例 |
|---------|---------|---------------|
| 品牌号 | 每周 3-5 条 | 7:3 |
| 种草号 | 每周 5-7 条 | 5:5 |
| 人设号 | 每周 3-4 条 | 3:7 |

高频不等于好 -- 宁可一周 3 条高质量，不要一天 3 条凑数。

注意：XHS 发帖当前为半自动模式（SocialMesh 准备内容 -> READY 状态 -> Mason 手动发布），每日排程需考虑 Mason 的操作窗口。

## 从采集数据到选题（自动化管道对接）

```
xhs-analyze.sh 产出 weekly_analysis.json:
  → keyword_insights（哪些关键词热度高 + trend_direction）
  → hot_posts（爆帖 Top 20，含互动数据 + fake_traffic_flags）

xhs-strategy-briefing.sh 产出 briefings/YYYY-MM-DD.json:
  → content_recommendations（3 个号各自的内容建议）
  → fake_traffic_report（假流量概况）

PM 判断（你读策略简报后做）:
  → 哪些趋势跟品牌相关？（对照 context.md）
  → 爆帖里哪些 pattern 可以复刻？（藏赞比/评赞比分析）
  → 过滤假流量数据（参考 fake_traffic_flags + 长期记忆中的假流量信号）

产出 weekly-direction.md:
  → 本周 3 个号各自的选题方向 + 参考爆帖链接
  → Creator 直接读取执行
```

### 策略简报 schema 参考

策略简报结构定义见 `~/mason-hub/shared/xhs-briefing-schema.json`，关键字段：
- `hot_posts[].score`: 互动评分（赞 + 藏x3 + 评x5 + 转x8）
- `hot_posts[].engagement_ratio`: 互动比（藏+评+转）/赞
- `hot_posts[].fake_traffic_flags`: 假流量标记
- `keyword_insights[].trend_direction`: rising/stable/declining/new
- `content_recommendations[].account`: 号 1/号 2/号 3

## 复盘方法

每月 1 次，看上月内容数据：

1. **哪些帖互动最高？为什么？** -- 提炼可复制的 pattern
2. **哪些帖没流量？为什么？** -- 避免重复踩坑
3. **藏赞比高的帖** -- 内容实用，加大同类产出
4. **评赞比高的帖** -- 话题有讨论度，可做系列
5. **转化数据**（待官方 API 接通）-- 帖子发布后 72h 窗口内相关商品订单变化（与 EMP_0001 配合）

核心原则：不靠赞数判断成败，靠实际订单转化。评论中的购买意图（"怎么买""求链接"）比点赞数更有参考价值。
