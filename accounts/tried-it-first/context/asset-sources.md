# 先试为敬 — 素材库资源清单

> 更新：2026-03-29

## 免费起步套餐（$0）

| 用途 | 推荐 | 授权 |
|------|------|------|
| 视频素材 | Pexels + Mixkit | 免费商用，无需署名 |
| 图片 | Unsplash + Pexels | 免费商用，无需署名 |
| BGM | YouTube Audio Library + Pixabay Music | 免费，需注册下载 |
| 音效 | Mixkit SFX | 免费商用 |
| 图标 | Flaticon（需署名）+ iconfont（阿里） | 免费 |
| 中文字体 | 思源黑体 + 阿里巴巴普惠体 + 得意黑 | 全部免费商用 |
| AI 生图 | DALL-E 3（ChatGPT Plus 内含） | 可商用 |

## 进阶付费套餐（$30-50/月）

| 升级项 | 推荐 | 价格 |
|--------|------|------|
| BGM + 音效 | Epidemic Sound 或 Artlist | ~$15/月 |
| 综合素材 | Envato Elements | ~$16.5/月 |
| 封面/缩略图 | Midjourney | $10/月 |

## 视频下载工具

| 工具 | 用途 | 备注 |
|------|------|------|
| yt-dlp | 全平台视频下载，支持指定分辨率 | `pip install yt-dlp` |
| GreenVideo | 在线下载（B站只有低清） | greenvideo.cc |
| download.py | mason-hub 内置脚本，基于 GreenVideo | skills/video/video-download/ |

## 字体版权陷阱

不能免费商用：微软雅黑、方正系列、汉仪系列、华文系列（方正维权活跃）。
安全的：思源黑体/宋体、阿里巴巴普惠体、得意黑、霞鹜文楷、OPPO Sans、站酷系列。

## B站/YouTube 双平台音乐版权

- B站：用B站自带音频库最安全；正版订阅（Epidemic/Artlist）也安全
- YouTube：Content ID 极严格，必须用 YouTube Audio Library 或正版订阅
- 同时发两平台：统一用 Epidemic Sound 或 Artlist
