# 先试为敬 — 内容创作基调

> 定稿日期：2026-03-30
> 来源：brainstorm session，脚本复盘后重新定位

## 定位

先试为敬 = **AI时代的试毒官**。5分钟告诉你一个东西跟你有没有关系。
重点是**结论**，不是过程。

## 和 Growth Memo 的互补关系

| | 先试为敬 | Growth Memo |
|--|---------|-------------|
| 核心 | 我替你试了，告诉你结论 | 我是怎么试的，完整过程 |
| 时长 | 5分钟，快节奏 | 长视频，有深度 |
| 人设 | 匿名试毒官，不提Mason | Mason本人，M面罩 |
| 观众获得 | 判断：这事跟我有没有关系 | 方法：怎么做的、踩了什么坑 |
| 风格参考 | 小Lin说（essay+案例） | 绵羊料理/何同学（过程记录+故事） |

同一个项目可以出两个版本：
- 先试为敬：「5分钟，3D定制网站，跟你有什么关系」
- Growth Memo：「我花了两个月用AI做了个3D网站，完整过程」

## Growth Memo 内容结构

```
生活中遇到问题 → 想用AI解决 → 折腾踩坑过程 → 解决 → 成果展示 → 分享
```

制作要求：全程录屏，过程就是素材。

## 先试为敬 内容结构

```
这个东西是什么 → 跟普通人有什么关系 → 我试了一下 → 结论
```

## 口吻

学长分享（小Lin式）：
- 不说教，"我发现了一个有意思的事"
- 每句话有信息增量
- 比喻降维，让不懂的人秒懂
- 金句从故事里长出来，不硬塞

## 禁用词/句式

- "打破信息差"（太抽象）
- "你应该..."（说教感）
- "在这个时代"（空话）
- 连续超过 3 个反问句（观众被问烦）
- 没有信息增量的排比句

## 每段检验标准

写完每一段问：**观众看完这段，获得了什么他之前不知道的东西？**
答案是"没有" → 砍掉或重写。

## 信息密度标准

每分钟至少一个观众不知道的：具体事实 / 数据 / 踩坑细节 / 洞察。

## 结尾标准

观众看完最后一秒，应该：
- 知道了一个之前不知道的事
- 想做一个具体的行动（不是"我要努力"，是"我要去试一下XX"）
