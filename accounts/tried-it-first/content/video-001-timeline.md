## BGM1: 克制叙事钢琴（0:00 - 1:05）

情绪走向：`安静进入 → 缓慢铺开 → 在"至少知道真实情况"处短暂静默过渡`

```
0:00 ─── BGM1 轻起，钢琴，几乎听不到 ───

[0:00-0:03] 黑屏渐入 + 张雪峰讲台画面
  「最近，张雪峰老师走了。」

[0:03-0:13] 张雪峰名场面快剪 + 热搜截图
  「全网都在发悼念视频。有人翻出他当年的金句，
    有人盘点他改变了多少人的命运，
    有人说他是这个时代最被需要的人。」

[0:13-0:18] 文字卡：但今天，我想聊一个更大的问题
  「但今天我不想聊他说过什么。我想聊一个更大的问题：」

[0:18-0:22] 文字卡：他做了十年的事，到底是什么？
  「他做了十年的事，到底是什么？」
                                          ← BGM1 音量微升
[0:22-0:28] 争议截图 + 粉丝截图
  「有人说他是骗子，他推荐过的专业现在也没什么前途。
    有人说他是救星，改变了无数小镇做题家的命运。」

[0:28-0:32] 文字卡：打破信息差（红色下划线）
  「但抛开这些争议，他做的事情其实只有一件——打破信息差。」
                                          ← BGM1 情绪小高点
[0:32-0:44] 小镇高中 → 志愿表 → 土木工地 → 城市饭桌
  「一个小镇的高中生，家里没人上过大学，
    他不知道"生物工程"毕业以后能干什么，
    不知道"土木工程"这个行业已经在走下坡路。
    这些信息，大城市的孩子从小饭桌上就听到了，但他没有。」

[0:44-0:50] 张雪峰讲课画面
  「张雪峰做的事，就是把这些信息，用最直接的方式，塞到了他面前。」

[0:50-0:55] 文字卡：他不是先知
  「他不是先知，不可能每次都对。但他能做的是，
    在当下用他掌握的信息，帮你规避掉最大的风险。」

[0:55-1:02] 文字卡：让你在做选择之前，至少知道真实情况是什么
  「不是预测未来，是让你在做选择之前，至少知道真实情况是什么。」

1:02 ─── BGM1 渐弱至静默，留 3 秒空白过渡 ───

[1:02-1:05] （静默过渡，准备转折）
```

```

                                          ← BGM2 保持低沉
[1:19-1:27] 手机通知 → AI新闻 → 裁员 → 岗位取代
  「每天醒来，手机里全是新消息：
    某某AI又更新了，某某公司又裁员了，某个岗位可能要没了。」

[1:27-1:29] 文字卡：然后呢？
  「然后呢？」

[1:29-1:35] AI 课程广告截图 ×3
  「紧接着就有人跳出来：你还不学AI？
    再不上车就晚了？你想被时代抛弃？」

[1:35-1:38] 文字卡：听着耳熟吗？
  「这些话......是不是听着有点耳熟？」

[1:38-1:44] 旧新闻截图 vs 新新闻截图
  「"报错专业毁一生"——这是当年的版本。
    "不学AI毁一生"——这是现在的版本。」

[1:44-1:48] 文字卡：先吓你，再卖课（红色下划线）
  「换了个包装，逻辑还是一样的：先吓你，再卖课。」

[1:48-1:52] 思考的人 + 问号
  「但你有没有停下来想过：他们说的，到底是真的吗？」

[1:52-1:56] AI 场景 → 暗画面
  「AI真的要取代你了吗？还是说......有些人需要你相信这件事？」

                                          ← BGM2 变得更私密、安静
[1:56-1:59] 文字卡：说实话，我自己也一样。
  「说实话，我自己也一样。」

[1:59-2:04] Claude 界面截图
  「我刚开始用 Claude 的时候很兴奋。
    作为一个非技术背景出身的人，每天更新迭代的快感让我沉溺其中无法自拔。」

[2:04-2:10] 代码界面 → 竞品产品页面
  「但当我花了一个礼拜、甚至几个礼拜才做出来的东西，
    发现别的团队用更快更好的方式做了出来......我陷入了沉思。」

[2:10-2:16] 技术框架时间线 + 日历翻页
  「你今天学的框架，明天会不会就被推翻了？
    你花了三个月学的东西，会不会三个月后就没人用了？」

[2:16-2:19] 文字卡：越想搞清楚，反而越焦虑。（红色下划线）
  「越想搞清楚，反而越焦虑。」
                                          ← BGM2 到最低音量
[2:19-2:24] 评论拼贴
  「这些问题，好像没人给你答案。
    因为给你答案的人，不是想卖你东西，就是自己也还在找答案。」

[2:24-2:29] 跑步被超越画面
  「于是焦虑变成了无力。
    感觉自己怎么追，也追不上那些跑在前面、或者从身边超过去的人。」

[2:29-2:33] 文字卡：但就是在那个时候——
  「但就是在那个最无力的时候，我开始想一个问题——」

2:33 ─── BGM2 渐弱，开始转调 ───

[2:33-2:40] （过渡，BGM2 淡出 → BGM3 淡入）
```
