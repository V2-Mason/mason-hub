# 素仁轩 — 技术栈与设计原则

> 提取自原 surenxuan/docs/specs/00-PROJECT-OVERVIEW.md (2026-02)

## 技术栈

- **前端**: React + Tailwind CSS
- **后端**: FastAPI (Python)
- **数据库**: SQLite (WAL 模式, 单机运行)
- **AI**: OpenAI/Gemini API (文本LLM + 图像生成 + 视觉理解)
- **运行环境**: 本地运行 / 阿里云部署

## 设计原则

1. **人机协作不是全自动** — AI 做数据处理和建议生成，Mason 做决策和客户沟通
2. **先简单后复杂** — 先用最简单实现验证业务逻辑，再升级架构
3. **模块化** — 每个 Agent 是独立模块，通过接口通信
4. **成本敏感** — API 调用需精打细算，翻译/分类先查缓存
5. **移动端友好** — 销售录入、Copilot 等关键页面必须移动端可用
