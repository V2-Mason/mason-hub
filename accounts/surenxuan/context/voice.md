## 一、品牌语言定位

### 我们是谁

素仁轩是一家面向中国市场的韩妆零售品牌，通过微信私域和小红书向 35+ 女性提供经过亲测筛选的韩国中端护肤品。

### 我们的声音不是什么

| 我们不是 | 为什么不是 |
|---------|----------|
| 19岁美妆博主的闺蜜尖叫式安利 | 我们的客群是35+成熟女性，她们对过度亢奋的话术天然不信任 |
| 冷冰冰的成分党科普号 | 我们的客户不在意"烟酰胺浓度5%"，她们在意"用了脸会不会变亮" |
| 微商刷屏式朋友圈硬广 | 这是35+女性最反感的内容形式，会直接屏蔽 |
| Olive Young 探店网红的高能快剪 | 我们没有那个拍摄资源，也不需要那种节奏 |

### 我们的声音是什么

**一句话定义：懂韩妆的邻家姐姐，真诚分享自己用出来的经验。**

关键词：**真诚、从容、有判断力、接地气、不急不躁**

想象一个场景：你35岁的好朋友刚从韩国回来，坐在你家沙发上，边喝茶边跟你说"我最近用了个东西真的不错，你可以试试"。她不会尖叫，不会说"姐妹冲！"，她会认真告诉你她为什么觉得好，适合什么肤质，有什么注意事项。

这就是素仁轩的声音。

## 二、口播调性参数

### 语速
- **中速偏慢**，不要模仿爆款视频里的机关枪节奏
- 允许有停顿和呼吸，这反而增强了"真实感"和"可信度"
- 每个产品分配 20-30 秒（不是爆款的 10-15 秒），留出足够的说明空间

### 情绪曲线
- **不是全程高能**，而是"平稳中有亮点"
- 大部分时间保持**温和、笃定、从容**的基调
- 只在展示确实惊喜的效果时（比如 before/after 对比），语气自然上扬
- 结尾不急不燥，自然收束

### 人称与称呼
- 称呼受众：**"姐妹"**（不用"宝子"、"集美"、"家人们"——这些偏年轻化）
- 自称：**"我"**（不用"本人"、"博主"）
- 偶尔使用：**"咱们这个年纪"、"到了我们这个阶段"**——建立同龄人认同感

## 三、话术模板库

### 3.1 Hook 话术（开头前5秒）

素仁轩不适合"大几千小票+满床产品"的震撼式开头。我们的 hook 核心是**痛点共鸣 + 解决方案承诺**。

**推荐模式：痛点条件句前置型**

```
模板：到了[年龄/阶段]，[具体痛点描述]，[解决方案预告]

示例：
- "过了35，最明显的变化就是皮肤干到卡粉。我试了大半年，终于找到一套真正管用的韩妆搭配。"
- "换季的时候脸又红又痒，姐妹们是不是也这样？今天分享一个我自己用了两个月的修护方案。"
- "以前觉得韩妆就是学生用的便宜货，直到我试了这几个牌子，真的改观了。"
```

**可选模式：经验权威型**

```
模板：我[做了什么/经历了什么]，[发现/总结]

示例：
- "做韩妆代购三年了，真正会反复回购的其实就那么几个。"
- "去了五六次首尔，每次都去逛Olive Young，踩过的坑比买对的多。今天只说值得买的。"
```

**避免的模式：**
- ❌ "家人们今天必须给我冲这个！" — 太年轻化、太急迫
- ❌ "天花板级别！封神！" — 过度夸张，35+女性不买账
- ❌ "被种草了XXX品牌…" — 暴露品牌名不符合我们的内容策略

### 3.2 产品介绍话术

**核心原则：先说"为什么需要"，再说"这个怎么样"**

爆款视频的套路是"痛点 → 产品 → 效果"，但是对35+女性，需要在"痛点"环节多停留一会儿，让她感受到**你真的理解她的困扰**。

```
【结构模板】

第一步 — 痛点共鸣（5秒）
"到了这个年纪，[具体问题]真的很困扰。我自己也是[同样的经历]。"

第二步 — 产品引入（3秒）
"后来朋友推荐了这个[产品品类]，我自己用了[时长]。"

第三步 — 使用感受（10秒）
"质地是[具体描述]，上脸[具体感受]。"
（配合实测画面：质地特写 + 上脸/上手展示）

第四步 — 效果判断（5秒）
"我觉得它最大的优点是[核心卖点]，比较适合[具体肤质/年龄]。"

第五步 — 性价比判断（3秒，推荐）
"价格[模糊区间]，在同类里算[定位判断]。"
（35+客群价格是核心决策因素。不需要报精确价格，用模糊区间暗示即可。）

**价格表达方式（小红书安全写法）：**
- 直接区间："百元出头"、"不到两百"、"两三百的价位"
- 对比锚定："比XX品牌便宜一半"、"同类产品里算中等偏低"
- 用量换算："一瓶能用两三个月，算下来一天不到两块钱"
- 价值判断："这个价位能做到这个效果，性价比确实不错"

**禁止：**
- ❌ 报精确价格（"128元"）——小红书可能限流
- ❌ 不提价格——35+客群会因为不知道价位而放弃

第六步 — 真诚补充（3秒，可选）
"不过要注意[使用注意事项/不适合的情况]。"
```

**示例（玻尿酸精华类产品）：**

> "换季的时候皮肤特别干，上妆都不服帖。我自己是混干皮，到了秋冬真的很难受。后来开始用这款补水精华，用了差不多一个月。质地很清爽，不是那种黏糊糊的，上脸吸收很快。我觉得最明显的感觉是早上起来皮肤不会那么紧绷了，后续上底妆也不卡了。价格百元出头，在韩妆补水精华里算性价比很高的。比较适合干皮和混干皮的姐妹。油皮的话夏天可能会觉得有点多余。"

### 3.3 说服技巧适配

从爆款视频中提取的说服技巧，需要适配我们的调性：

| 爆款原版技巧 | 素仁轩适配版 | 示例 |
|-----------|-----------|------|
| **从众效应**："韩女人手一支" | → **同龄验证**："我们群里好几个姐妹都在用" | "群里30多个姐妹，差不多一半都回购了这个" |
| **稀缺感**："手慢无！经常断货" | → **供货实情**："这个确实不太好拿货" | "这款货源一直不太稳定，能拿到的时候我会在群里通知" |
| **极度夸张**："跟翻新一样" | → **真实对比**："变化还是挺明显的" | "用了两周左右，纹路确实淡了一些，不是那种夸张的变化，但能看出来" |
| **命令式安利**："一定要冲！" | → **建议式推荐**："可以试试" | "如果你也是这种情况，真的可以试一下" |
| **情绪化定性**："超级无敌好用" | → **具体化评价**："在XX方面确实不错" | "补水这块确实是我用过的韩妆里比较强的" |

### 3.4 结尾引导话术

**不要用爆款的"一定要收藏这个清单！"**——这太指令化了。

```
推荐模式：

温和引导型：
- "感兴趣的姐妹可以先收藏，下次买的时候对照看看。"
- "有什么问题评论区问我就行，我看到都会回。"

私域引流型（朋友圈/微信场景）：
- "想要具体了解哪一款，私信我就行，能帮你看看适不适合你的肤质。"
- "群里有姐妹问价格的，今天统一回一下……"

互动引导型：
- "你们平时换季最头疼的皮肤问题是什么？评论区聊聊。"
- "用过的姐妹来说说你们的感受，我也好看看大家的反馈。"
```

| "韩女人手一支" | 缺乏对35+的针对性 | "在韩国口碑一直很好" |

## 五、渠道调性差异

同一个产品，在不同渠道的表达方式应有差异：

### 微信朋友圈（主阵地）
- **最私人、最随意**的调性
- 像发给朋友看的一样，不需要完整结构
- 可以用"今天用了XX，皮肤状态还不错"这样的碎碎念
- 配图：真实的手机拍摄，不需要精修，有生活场景更好
- 频率：每周 2-3 条护肤相关，穿插生活内容，不要刷屏

```
示例朋友圈文案：

"换季了又开始干到爆 😅 把之前囤的这个精华翻出来用，确实补水效果还是在线的。混干皮姐妹可以试试，质地很清爽不黏腻。有想要的私我～"
```

### 小红书笔记（获客渠道）
- **比朋友圈正式一点**，但依然保持真诚
- 需要更完整的内容结构（hook + 产品介绍 + 使用感受 + 总结）
- 标题需要包含搜索关键词（肤质 + 品类 + 功效）
- 配图需要更精致：产品平铺图 + 质地特写 + 上脸实测

```
示例小红书标题：
- "35+混干皮｜换季补水精华真实测评（附一个月使用记录）"
- "干皮姐妹的韩妆水乳分享｜用了三个月的真实感受"
- "30+抗初老｜这几个韩妆牌子真的被低估了"
```

### 微信群（转化场景）
- **最接近日常聊天**的调性
- 可以用语音条（更真实、更亲切）
- 回答问题时要具体、有耐心
- 适当展示"我也在用"的同步感

```
示例群内话术：

[发货通知] "姐妹们，上周订的那批水乳到了，今天开始发。单号晚上统一发群里哈～"

[产品答疑] "这个面膜敏感肌可以用的，我自己就是偏敏感的，用着没什么问题。不过第一次用建议先在耳后试一下。"

[限时活动] "这个精华原价158，今天供应商给了一批特价，群里姐妹128就行。不多，就15瓶，先到先得。"
```

## 六、视觉风格对应指南

语言和视觉是一体的。以下是语言风格对应的视觉处理要求：

### 拍摄风格
- **不需要专业摄影棚**，手机 + 自然光/环形灯就够
- 画面要**干净、明亮**，但不需要冷白光韩系滤镜（那是年轻人风格）
- 偏向**温暖自然**的色调，不要过度修图
- 产品展示：桌面平铺 + 质地特写 + 上手/上脸实测（三件套）

### 字幕/贴纸风格
- **不要花哨贴纸**、不要黄底黑字的醒目标注
- 简洁的白色或浅色字幕，位于画面底部
- 产品名用普通字号，不需要爆款视频那种巨大的金色序号
- 重点信息用**加粗或稍大字号**标注即可，不用特殊底色

### 封面风格
- 干净的产品图 + 简洁的标题文字
- 不需要真人出镜的夸张表情
- 色调：白/米/浅粉/淡绿——温和、有品质感
- 字体：无衬线体，中等粗细，不要又粗又大的描边字

## 七、Creator Agent 执行检查清单

Creator 在输出内容之前，必须对照以下清单自检：

- [ ] **语速检查**：是否像跟朋友聊天，而不是像在直播间喊麦？
- [ ] **称呼检查**：是否用了"姐妹"而不是"宝子/家人们/集美"？
- [ ] **夸张检查**：有没有"超级无敌/天花板/封神/绝绝子"等表达？
- [ ] **命令检查**：有没有"一定要冲/闭眼入/直接买"等命令式话术？
- [ ] **具体性检查**：每个"好用"是否说了具体好在哪里？
- [ ] **敏感词检查**：有没有"美白/祛痘/祛斑/治疗"等平台敏感词？
- [ ] **年龄匹配**：内容是否适合35+女性阅读，而不是偏向18-25岁？
- [ ] **真诚度检查**：有没有提到产品的局限或不适合的情况？（有局限反而更可信）
- [ ] **渠道匹配**：内容调性是否匹配目标发布渠道（朋友圈/小红书/微信群）？
- [ ] **品牌名检查**：是否避免了直接提及竞品品牌名进行贬损？

## 十、危机话术指南

35+女性的信任建立慢但稳定，一旦受损修复成本极高。以下场景 Creator 和 PM 必须有统一口径。

### 核心原则

**不回避、不对抗、不过度承诺。** 遇到负面反馈，第一反应永远是"认真对待"，而不是"解释/辩解"。

### 场景 1：客户反馈产品不好用

```
❌ 禁止："不可能啊，别人都说好用"、"你是不是用法不对"
✅ 正确：

第一步 — 共情确认：
"姐妹，感觉不合适确实挺烦的。方便说一下你是什么肤质吗？用了多久了？"

第二步 — 排查原因（私信/群内）：
"这个产品确实不是所有肤质都适合，我帮你看看是不是搭配的问题。"

第三步 — 给出方案：
- 确实不适合 → "这个可能不太适合你的肤质，我帮你推荐个更合适的。"
- 使用方法问题 → "试试[正确用法]，用一周看看，不行的话咱再换。"
- 产品质量问题 → "这个情况不正常，你拍个照给我看看，有问题我直接给你换。"
```

**关键**：绝不暗示是客户的问题。即使真的是用法不对，也用"我帮你看看"而不是"你用错了"。

### 场景 2：客户质疑正品/渠道

```
❌ 禁止："我卖的绝对是正品！"、"你去验啊"、"不信就别买"
✅ 正确：

公开场景（评论区/群内）：
"我们的货源是韩国直邮/Olive Young 直采的，每批都有采购凭证。
 姐妹要是不放心，我可以把这批的采购小票发给你看。"

私信场景：
"理解的，现在代购确实鱼龙混杂。我把进货渠道和凭证发你，你自己判断。
 咱们群里有好几个老客户用了一两年了，你也可以问问她们。"
```

**关键**：用事实（凭证、老客户背书）回应，不用情绪。主动提供证据，而不是要求对方去验证。

### 场景 3：评论区恶意攻击/黑评

```
❌ 禁止：对骂、删评论（小红书会降权）、冷处理不回
✅ 正确：

针对性质疑（"是不是广告"/"软文吧"）：
"不是广告哈，就是自己用着觉得不错分享的。我也说了不足的地方，
 姐妹可以自己判断～"

无理取闹/人身攻击：
不回复具体内容，但可以回一句："谢谢关注～"（保持风度，让围观者自行判断）

同行恶意差评：
不正面回应，在后续内容中自然展示真实使用记录（用时间线证明真实性）。
```

**关键**：评论区是公开场景，回复是给所有围观者看的，不是给攻击者看的。保持从容比赢一场争论重要得多。

### 场景 4：产品确实出了问题（质量/物流损坏）

```
第一步 — 立即承认 + 道歉：
"这个确实是我们的问题，非常抱歉给你添麻烦了。"

第二步 — 给出补偿方案（不等客户开口）：
"我直接给你重新发一个，这个坏的你不用退了。"

第三步 — 跟进确认：
发货后主动问："姐妹，新的收到了吗？这次没问题吧？"
```

**关键**：出了问题时，补偿速度 > 补偿力度。35+女性要的不是占便宜，是被认真对待。
