# 视频脚本 #001 — 毛毛姐的第一条小红书

> 状态：定稿
> 创建日期：2026-03-27
> 类型：A 情感钩子
> 坐标系：传播 × 涨粉 × 常青
> 预计时长：70-90秒

## 标题
忙了几十年，去年才学会一件事

## 封面
妈妈微笑照 + 标题文字（白色大字+半透明底色条）

## 标签
#50岁重新开始 #中年觉醒 #70后的生活 #人生感悟 #小红书新人 #湖南人

## 脚本

### 【开场】

> "大家好，这是我的第一条小红书，如果做得不好，希望多多指教。"

### 【第一幕：前半生】

> "我是70后，湖南人。因为家里条件不好，高中没读完就出来了，十几岁一个人进厂打工。
>
> 后来从长沙周边的一个小县城跑到岳阳，谁都不认识，就想着自己干点什么。
>
> 从一家小精品店，慢慢做到几家皮具店，跟皮料打了几十年交道。
>
> 为了家庭一直在拼，从来没想过要停下来。"

### 【第二幕：停下来】

> "直到去年，生了场大病。
>
> ……
>
> 生活一下子就停了。"

### 【第三幕：低谷】

> "换做以前，任何事情我都觉得可以咬咬牙过去，无非是咬一口还是两口的事。用我们湖南话说，我这个人就是霸得蛮。
>
> 但那段时间，我发现自己什么都做不了了。"

> "以前每天忙忙碌碌的，我以为是充实，其实是不知道停下来该面对什么。"

> "除了工作，我什么都不会。
>
> 不会穿搭，不会玩手机，连电视都不会开、电影都不会看。
>
> 连自己喜欢什么……好像都忘了。"

### 【第四幕：觉醒】

> "但也是因为这场病，我想明白了——我想重新开始。
>
> 跟你们年轻人学学，学穿搭、学拍照、学看看这个世界到底有多好看。"

> "其实我很早就想用小红书，但不知道是出于对未知事物的恐惧，还是什么原因，总是没有开始。
>
> 直到前段时间，儿子跟我说：'妈，52岁正是闯荡江湖的好年纪。'"

*（妈妈笑了）*

> "我才有了开始学习的勇气。"

### 【收尾】

> "后来也是儿子教了我一些基本操作，怎么录视频、怎么发小红书，才有了今天这第一条内容。
>
> 我叫毛毛姐，很高兴认识你们。"

*（微微点头，笑，停留2秒，淡出）*

## 拍摄指南

| 项 | 要求 |
|---|------|
| 场地 | 家里客厅或阳台，背景干净，自然光 |
| 机位 | 手机固定，半身，眼睛平视镜头 |
| 穿着 | 日常好看的穿搭，不刻意隆重 |
| 收音 | 安静环境，关窗关空调，手机离人1米内 |
| 提词 | 每段关键词大字打印贴镜头旁，不用背词 |
| 拍摄方式 | 分段拍，每段多拍几遍选最自然的 |

## 画面参考

| 段落 | 画面 |
|------|------|
| 开场 | 妈妈看镜头，自然微笑 |
| 第一幕 | 口述 + 穿插老照片（如果有） |
| 第二幕 | 节奏放慢，"停了"之后停顿2秒 |
| 第三幕 | 可切窗外空镜，"忘了"单独一屏字幕停留2秒 |
| 第四幕 | 画面变亮，切现在的生活画面（散步/咖啡/风景） |
| 收尾 | 回到开场位置，首尾呼应 |

## 后期制作

- 剪辑：剪映，分段拼接
- 字幕：全程加，关键句加粗放大
- BGM：轻钢琴曲，音量20%以下
- 转场：淡入淡出
- 滤镜：不加或极淡暖色
- 总时长：控制60-90秒
